本季必看 · 两个"看穿"：GAAP EPS 大降 vs 调整后 EPS 增长、分部利润 vs 现金流

迪士尼这份财报有两个必须"看穿"的地方，看不穿就会误读它的真实状态。

看穿一：GAAP EPS -30% 是假象，调整后 EPS +8% 才是真相。 很多人一眼看到 GAAP 摊薄 EPS 从 $1.81 降到 $1.27（-30%）就吓退——但这几乎全部来自去年同期含一笔 +$1.02/股（约 $10.16 亿）的一次性税务和解利好，是高基数作祟；今年又背了 NFL 交易的非现金税务费用。剔除收购摊销（$0.12）、重组减值（$0.12）、NFL 非现金税费（$0.05）后，调整后 EPS $1.57、同比 +8% 才反映真实经营。业绩没有崩，只是会计噪音很大。

看穿二：分部利润在涨，自由现金流却被"重投资周期"压扁了。 本季单季 FCF $4.94B 看着健康（去年 $4.89B），但上半年（H1）经营现金流 $76.5 亿、同比降 $23 亿（高额所得税缴纳含加州山火递延税补缴 + 内容支出增加），资本开支飙到 $49.9 亿（去年 $43.3 亿），FCF 只剩 $26.6 亿（去年 $56.3 亿，腰斩）。这是"为未来花钱"——邮轮（Disney Adventure/Destiny）、新景点、$600 亿十年扩园计划正在花钱。成长性 capex 短期确实吃掉了现金，也让资本返还暂时超过 FCF，这是理解迪士尼当下"利润在涨、现金却紧"的钥匙。

模块 1 · 公司概览与背景

The Walt Disney Company（NYSE: DIS），总部加州伯班克，成立于 1923 年，是全球最大的多元化媒体与娱乐集团。财年截至 9 月底/10 月初，故 Q2 FY2026 = 2025-12-28 至 2026-03-28。FY2025 全年营收约 $94B。

核心叙事：迪士尼是一台"IP 飞轮"——把米老鼠、漫威、星球大战、皮克斯、迪士尼动画、ESPN 这些独一无二的内容资产创造一次，然后在流媒体、影院、线性电视、主题乐园、邮轮、消费品上反复变现。同一个 IP 既能拍电影、上流媒体，又能进乐园做游乐设施、做周边商品——这是竞争对手极难复制的"内容-体验"闭环。

三大报告分部（FY2024 重组后）：

  • 娱乐（Entertainment）——含流媒体 SVOD（Disney+/Hulu）、线性电视网络、影视工作室内容销售。Q2 营收 $11.72B（+10%），占毛营收最大
  • 体验（Experiences）——国内外主题乐园、度假区、邮轮、消费品授权。Q2 营收 $9.49B（+7%），利润引擎（占分部利润 57%）
  • 体育（Sports）——以 ESPN 为核心的体育媒体。Q2 营收 $4.61B（+2%），正从线性向直连（DTC，ESPN Unlimited）转型

治理与换帅：本季度发生 CEO 更替——Josh D'Amaro 于 2026-03-18 接任 CEO（此前掌管体验/乐园分部），Bob Iger 转任高级顾问及董事至 2026-12-31 退休，Dana Walden 升任总裁兼首席创意官统一内容业务。股权结构分散、机构主导，摊薄股数约 17.72 亿。

能力圈检验：IP 飞轮 + 乐园印钞机的部分极其清晰（看得懂的一流生意）。但三块需要持续跟踪：(1) 线性电视的衰退速度——旧钱袋在退潮；(2) 流媒体从"扭亏"到"高利润率"的爬坡能否兑现；(3) ESPN 全面 DTC 化 + 体育版权成本通胀的博弈。这三点决定迪士尼未来 5 年是"利润复利机器"还是"转型泥潭"。

模块 2 · 管理层评估
B+

Josh D'Amaro · CEO（2026-03 至今，首次任上市公司 CEO）

此前长期掌管迪士尼体验/乐园分部（公司最赚钱、执行最强的板块），是深耕运营的实干派。$600 亿十年扩园计划、新邮轮下水、乐园人均消费持续提升，很大程度是他的手笔。挑战在于：作为首次执掌整个上市公司的 CEO，他在流媒体、体育版权、内容创意、资本市场沟通上的能力尚未经历完整周期检验。海图判断：强运营基因是加分项，但"乐园高手能否驾驭全局"需要 2-3 个季度观察——这是本报告给管理层维度打 B+ 而非 A 的核心原因。

A-

Bob Iger 的收尾 + 资本配置纪律

Iger 2022 年回归后完成了三件大事：把流媒体从巨亏拉到盈利（本季 SVOD 经营利润 +88%）、2024 年重启股息与回购（COVID 后停发四年）、ESPN 战略清晰化（NFL 交易换 ESPN 控股权至有效 72%）。
资本返还回归正轨：FY2024 派息 $13.66 亿 + 回购 $29.92 亿；FY2025 派息 $18.03 亿 + 回购 $35 亿；本季上调 FY2026 回购目标至至少 $80 亿（原 $70 亿），400M 股回购授权剩余 288M 股（无到期日）。
纪律瑕疵：重 capex 周期下 H1 资本返还（派息 $13.37 亿 + 回购 $55 亿）已超过 H1 FCF $26.6 亿，靠资产负债表 + 现金支撑——需留意在净负债 $417 亿的背景下的返还节奏。另：果断放弃对 OpenAI/Sora 的原定投资，体现纪律。

长期主义测试：✅ 管理层以"IP 飞轮 + 乐园超级周期 + 流媒体利润率爬坡"的长期复利为主线，$600 亿扩园计划是典型的长期资本部署，而非短期财报博弈。坦诚度：电话会主动披露 Q3 体育分部利润将同比约 -14%、国内乐园客流 -1%、宏观不确定性下的谨慎态度——不粉饰。转型风险：从 FY2026 起停止披露 Disney+/Hulu 订户数（转向利润/利润率口径，类似奈飞）——逻辑上合理，但客观上降低了透明度，是需要标注的一点。利益绑定：管理层持股比例不高（成熟大盘股常态），薪酬与调整后 EPS / 分部利润挂钩。

模块 3 · 商业模式深度解析

海图"一句话测试"：迪士尼把独一无二的 IP 创造一次，然后在流媒体、影院、线性电视、主题乐园、邮轮、消费品上反复变现——内容是种子，乐园与体验是收成，一颗种子结好几茬果。

IP 飞轮（Franchise Flywheel）：一部《疯狂动物城 2》（全球票房 $19 亿，中国史上最高外语片）先在影院赚一笔，再上 Disney+ 赚订阅（流媒体播放破 10 亿小时），角色进乐园做游乐设施拉客流，衍生品进消费品渠道收授权费——同一 IP 的多次货币化，是迪士尼区别于纯流媒体（奈飞）、纯乐园（区域游乐园）、纯影视（工作室）的根本护城河。

模块 4 · 经济护城河分析（5 维）
1. 无形资产 / IP 品牌
极宽

全球无可匹敌的 IP 宝库：迪士尼动画 + 皮克斯 + 漫威 + 星战 + ESPN。近百年积累、几乎不可复制，是核心护城河。趋势：稳定/加宽（每部爆款都在加厚）。

2. 有效规模（乐园）
宽

主题乐园需巨额资本 + 土地 + IP 三重壁垒，全球能建"迪士尼级"乐园的玩家屈指可数（Universal 是唯一强对手）。趋势：加宽（$600 亿扩园）。

3. 成本 / 规模优势
宽

内容制作成本可跨全球流媒体 + 影院 + 乐园 + 消费品多次摊销；ESPN 在体育版权采购上有规模。趋势：稳定。

4. 转换成本
窄

流媒体订户可轻易退订/切换（churn 风险）；但乐园年卡持有者、深度粉丝黏性强。整体转换成本是迪士尼最弱的一维。趋势：稳定。

5. 网络效应
中

流媒体的内容-用户飞轮 + ESPN 体育版权聚合有一定网络效应，但弱于平台型双边网络。趋势：随流媒体规模缓慢增强。

10 年后护城河会更宽还是更窄？ IP + 乐园的核心护城河仍会更宽，但传媒分发端在被侵蚀：(1) 线性电视——剪线是不可逆的结构性衰退，这块旧钱袋会持续缩水；(2) 流媒体竞争——奈飞、亚马逊、苹果、YouTube 都在抢时长，转换成本低；(3) 乐园竞争加剧——Comcast 的 Epic Universe（2025 开业）是数十年来最强的新对手。迪士尼的对冲是把护城河"从分发管道转移到 IP 与体验"——只要 IP 常青、乐园无可替代，飞轮就能持续转动。定价权强（国内人均消费 +5%、消费品利润率 49%），是最硬的护城河证据。

5.4 所有者盈余（价值投资口径 · FY2025 正常化）

所有者盈余 = 净利润 + 折旧摊销 + 非现金费用 − 维护性 Capex ± 营运资金

迪士尼的复杂之处在于 capex 分"维护性"（乐园翻新、设备更新）与"扩张性"（新邮轮、新园区）。以 FY2025 正常化：调整后净利约 $107 亿（调整后 EPS $5.93 × ~18.1 亿股）+ D&A 约 $54 亿 − 维护性 capex 估约 $45 亿（总 capex ~$80 亿中扣除扩张部分）± 营运资金 ≈ 所有者盈余约 $110-115 亿。

所有者盈余收益率 = 约 $112 亿 / 市值 $166B ≈ 6.7%——对一家拥有全球最强 IP + 乐园护城河、流媒体刚转正的公司，这是一个"中高质量 + 合理偏低估值"的收益率。关键洞察：迪士尼当前 FCF 被扩张性 capex 压低（H1 仅 $26.6 亿），但正常化所有者盈余收益率约 6.7% 显示——市场把重投资周期的短期现金紧张，误读成了长期盈利能力下降。这正是价值可能被低估的地方。

波特五力：

  • 新进入者：乐园极低（资本+IP+土地三重壁垒）；流媒体高（科技巨头持续入局）
  • 替代品：中高（短视频/游戏抢占娱乐时长；剪线替代线性）
  • 供应商议价：中高（体育版权方 NFL/NBA 议价力强，推高 ESPN 成本；明星/制作成本）
  • 买家议价：中（流媒体用户可轻易退订；乐园客户对涨价有一定接受度）
  • 同业竞争：高（流媒体与体育直播是红海，乐园相对理性）

颠覆风险：线性电视的剪线是不可逆的结构性衰退，这块会持续缩水；短视频（TikTok/YouTube）分流娱乐时长是长期慢变量。但迪士尼的对冲是"把价值从分发管道转移到 IP 与不可替代的乐园体验"——只要飞轮里的 IP 常青，就能穿越分发形态的变化。

3 个黑天鹅情景：

  1. 深度消费衰退冲击乐园——概率 15% · 体验分部（占分部利润 57%）利润大跌 · 股价跌至 $75-80

模块 12 · 股东回报分析

迪士尼的股东回报是一个"从零重启、快速加码"的故事——但要看清它是在重资本周期下"边投资边返还"。COVID 期间（2020）停发股息与回购，2024 年才重启，之后力度逐年加大。本节把它拆到可验证的颗粒度。

Trailing Shareholder Yield：以最近完整财年 FY2025 计 = 返还 $5,303M / 市值 $166B ≈ 3.2%（回购 ~2.1% + 股息 ~1.1%）。但 FY2026 明显加速——仅 H1 就返还 $6,837M（已超 FY2025 全年），按 FY2026 指引（回购至少 $80 亿 + 股息约 $27 亿）前瞻股东收益率约 6.4%，返还力度进入历史高档。

12.2 给的方式好不好？

  • 真实缩股 · 含金量较高：摊薄股数从 FY2023 的约 18.27 亿 → FY2024 18.31 亿 → FY2025 18.11 亿 → Q2 FY2026 17.72 亿。FY2026 随回购加码股数明显下降，回购是"真减少股本"，而非仅抵消股权激励（SBC）
  • 库存股结构（美股常态）：回购股份入库存股（treasury stock 成本 $12,990M、130M 股，去年 79M）——美股典型，部分用于对冲 SBC，但当前回购规模远超 SBC，净缩股效果真实
  • 回购择时中性偏优：H1 FY2026 回购均价约 $108/股（$55 亿 / 5,100 万股），当前 $95.62——近期回购价略高于现价，但若股价在低位持续回购，择时会改善

12.3 能不能继续给、给多少？

  • 授权额度充裕：400M 股回购计划（2024-02-07 生效）剩余 288M 股（无到期日），按 $95 计约 $274 亿（约占市值 16.5%）· 提供强支撑
  • 股息重启且低派息率：$1.50/股、派息率仅约净利 25%，增息空间充足，但目前收益率仅 1.6%（迪士尼是"回购为主、股息为辅"）
  • (股息 + 回购) / FCF 覆盖度是当前最大关注点：FY2025 返还 $5.3B / FCF $10.1B ≈ 52%（健康）；但 FY2026 指引返还约 $10.7B vs FY2026E FCF ~$80-90 亿（被 capex 压制）→ 覆盖度 >100%，短期靠资产负债表 + 现金/杠杆支撑
  • 重资本周期是双刃剑：$600 亿扩园 + $80 亿回购同时进行，在净负债 $417 亿背景下，短期是"边投资边返还、覆盖度暂时超 FCF"；随 capex 在 FY2027+ 退坡、FCF 回升，覆盖度将改善——是可控的时点错配，非结构性不可持续

模块小结：积极且含金量较高，但处于重投资周期、短期覆盖度暂超 FCF——连续加码回购（FY2026 至少 $80 亿）+ 真实缩股（17.72 亿股逐年下降）+ $274 亿可用额度构成积极的一面；但在重 capex + 净负债背景下，当前资本返还靠动用现金/杠杆而非 FCF 覆盖，需在 FY2027 FCF 回升前保持关注。这不是"象征性回报"，而是"力度足、择时待优化、可持续性依赖 capex 退坡"的中上等股东回报。

夜读手记 · 1160 字

价值投资里最考验耐心的，不是烂生意配低价格，而是好资产配着一堆待解的问号。迪士尼现在就是这样：全球最强的 IP 宝库、创纪录的乐园、终于赚钱的流媒体，可股价却趴在 52 周低点 $95 附近，前瞻市盈率只有 13.9 倍——市场把它当成了一家衰退的传统媒体，而不是一台正在换挡的印钞机。

迪士尼靠一件事赚钱：把米老鼠、漫威、星战、皮克斯、ESPN 这些独一无二的 IP 创造一次，然后在流媒体、影院、乐园、邮轮、消费品上反复变现。这个"IP 飞轮"里，乐园与体验是利润引擎（Q2 贡献 57% 分部利润），流媒体是刚扭亏的新增长极，线性电视则是正在退潮的旧钱袋。

几个研判要点

一、流媒体真的转正了。 娱乐 SVOD（Disney+/Hulu）本季经营利润 $5.82 亿、同比 +88%，利润率首次上双位数到 10.6%，营收 +13%。这不是昙花一现——管理层指引全年 SVOD 利润率至少 10%。当年那个"烧钱换订户"的故事，正在变成"利润率爬坡"的故事，逻辑和奈飞如出一辙。

二、乐园还是那台印钞机。 Experiences 本季营收 $94.9 亿、利润 $26.2 亿双双创 Q2 历史新高，国内人均消费 +5%。新邮轮 Disney Adventure 在新加坡下水、预订强劲。虽然国内客流 -1%、且新项目开业前费用拖累约 2 个百分点，但需求底子健康，管理层预期 Q3 客流环比改善。

三、别被 GAAP 吓到，也别被它骗到。 GAAP 摊薄 EPS $1.27、同比 -30%，吓人——但去年同期含一笔 +$1.02/股的一次性税务和解利好，是高基数作祟。看调整后 EPS $1.57、+8% 才是真相。反过来，别忘了迪士尼是净负债公司：现金 $56.8 亿 vs 有息负债 $473.6 亿，真实净负债约 $417 亿，不是"现金堡垒"。

四、自由现金流在重投资周期里被压扁了。 H1 经营现金流 $76.5 亿、同比降 $23 亿（高额税款 + 内容支出），FCF 只剩 $26.6 亿（去年 $56.3 亿），主因资本开支飙到 $49.9 亿——邮轮、新景点、$600 亿十年扩园计划正在花钱。这是"为未来花钱"的成长性 capex，但短期确实吃掉了现金，也让资本返还暂时超过 FCF。

五、便宜，但要的是耐心不是勇气。 前瞻市盈率 13.9 倍，对一家拥有全球最强 IP + 乐园护城河、流媒体刚转正的公司，明显不贵；分析师平均目标价 $129.67 也远在现价之上。但独立估值中位数约 $108，距现价只有约 12% 空间——够便宜到"有意思"，还不够便宜到"安全边际 25%"的买入门槛。叠加 CEO 刚换届（D'Amaro 三月接任）、重 capex 周期、线性衰退，我不给它"买入"，只给"有条件买入"。

海图研判

评级：有条件买入（IP 飞轮 + 创纪录乐园 + 流媒体扭亏为盈的一流资产，对垒线性电视衰退 + 重资本周期压 FCF + CEO 换届未验证 + 估值未达 25% 安全边际）。12 个月概率加权目标价 $108（+13%），叠加 ~1.6% 股息。

操作：独立估值中位数 $108，机械首仓 = $108×80% ≈ $86，二仓 ×70% ≈ $76，三仓 ×60% ≈ $65。当前 $95.62 在首仓上方——建仓的"条件"有二：等回调至 $86 附近给出安全边际，或等 FCF 回升 + 流媒体利润率兑现的确认信号。已持有者可穿越 capex 周期继续持有。止盈三档 $125 / $145 / $165，最后 25% 长期持有。建议仓位 3-5%（换挡期的一流资产，宜小仓起步、确认加仓），持有周期 3-5 年。

风险提示

线性电视加速衰退、乐园遭遇消费衰退、Sports 版权费上升挤压 ESPN 利润（Q3 指引 -14%）、重 capex 拖累 FCF 更久、CEO 换届执行不及预期——任一项都可能把股价压回 $82 附近。但全球最强 IP + 创纪录乐园 + $417 亿资产净值托底，$85-90 是较硬的估值底（52 周低 $92.19 + 前瞻 P/E 11x 下限）。

关键叙事：一台"IP 飞轮 + 乐园印钞机 + 流媒体扭亏"的一流复利机器，正在为线性衰退、重投资周期与新帅换届支付"转型折价"——这折价里，藏着耐心投资者的机会。迪士尼不是给追热点的人，它是给愿意在低位分批、留足安全边际、然后陪它把多引擎慢慢跑顺的长期投资者。下次催化剂：约 2026-08-05 Q3 FY2026 财报。
