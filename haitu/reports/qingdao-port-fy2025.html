模块 1 · 公司概览与背景

青岛港国际股份有限公司（HKEX: 06198，2014-06 H股上市；SH: 601298，2024-01 A股上市），位于山东青岛，是中国北方第一大综合性港口、全球货物吞吐量前五大港口。前身可追溯至 1892 年清政府始建的青岛港，百年老港。

业务版图：四大主业——集装箱、干散杂货（金属矿石 / 煤炭 / 粮食）、液体散货（原油及液体化工）、物流及港口增值服务，加港口配套（供电供油）。集团运营青岛大港、前湾港区、董家口港区三大港区，是"一带一路"海陆枢纽 + 中国铁矿石 / 原油进口第一大口岸之一。

股权结构：控股股东为山东省港口集团（省属国资），通过青岛港（集团）持股约 50%+。2019 年山东省整合青岛港、日照港、烟台港、渤海湾港成立山东港口集团——青岛港是其旗舰上市平台。A+H 双重上市，H股流通盘约 10.99 亿股。

能力圈检验：商业模式极其清晰——港口是"收过路费"的基础设施生意，靠吞吐量 × 费率赚钱，重资产、强区位垄断、现金流稳定，是典型的"看得懂"的公用事业型标的。唯一的黑箱在两处：(1) 大量利润来自联营合营企业（QQCT 等），并表外的 JV 经营细节披露有限；(2) 86% 的货币资金存放在控股股东体系的"山东港口财务公司"——这两点是理解青岛港利润质量与治理结构的关键。

模块 2 · 管理层评估

治理结构：青岛港是山东省港口集团旗下的国有控股上市公司，管理层为职业经理人 + 国资委任命的董事长 / 总经理体系。核心团队稳定，深耕港口运营。

资本配置历史（满分 5 分制）：

  • 持续派息 + 连续三年增息：每股股息 ¥0.2927（2023）→ ¥0.3141（2024）→ ¥0.3454（2025）· 派息率稳定在归母净利约 39-43% · 评 4 分
  • 资产负债率连续九年下降至 24.7% · 财务纪律优秀 · 评 5 分
  • 外延扩张审慎：FY2025 投资 ¥17.3 亿（含收购日照港油品 / 日照实华股权）· 围绕主业的产业整合 · 评 4 分
  • 从不回购：连续多年零回购 · 但作为高派息国企港口，回购非主流工具 · 评 3 分
  • 巨额现金存放关联财务公司：¥124.66 亿（占货币资金 86%）存于山东港口财务公司 · 评 2 分（治理关注点）

长期主义测试：✅ 港口是百年资产，管理层以"降本增效 + 提升毛利率 + 稳定高派息"为主线，FY2025 在营收微降下做出毛利率 +1.2pct、净利 +0.7%、增息 10%——体现了成熟资产的精细化运营能力。但作为国企，小股东利益排序在国资战略之后，是结构性约束。

坦诚度：年报披露规范（信永中和标准无保留意见），运营数据详尽。但对关联交易（财务公司存款、与母公司及兄弟港口的业务往来）的风险提示偏简略——这是国企共性。

模块 3 · 商业模式深度解析

海图"一句话测试"：青岛港是"中国北方进出口货物的必经收费闸口"——靠区位垄断收取装卸费、仓储费、增值服务费，是一门重资产、强区位壁垒、现金流极稳的过路费生意。

议价能力：对货主（强 · 区位垄断 + 腹地经济刚需）· 对航运公司（中 · 大客户有费率谈判力）· 港口费率受发改委指导（弱定价权——这是公用事业属性的代价）。

模块 4 · 经济护城河分析
1. 有效规模（区位垄断）
宽

青岛港是山东半岛 + 黄河流域腹地唯一的深水大港 · 新建港口需巨额资本 + 岸线审批 + 数十年培育，几无新进入者。趋势：稳定。

2. 成本优势（重资产规模）
宽

全自动化码头（全球领先的"无人码头"）+ 规模效应 · 单箱成本行业最低之一 · 资产负债率仅 24.7%。趋势：加宽（自动化持续降本）。

3. 转换成本
窄

大货主理论上可改走日照港 / 天津港 · 但腹地物流半径 + 既有航线网络形成黏性。趋势：稳定。

4. 无形资产（牌照/区位）
窄-中

港口经营牌照 + 深水岸线资源是稀缺的政府授予资产 · 但费率受发改委管制，无品牌溢价。趋势：稳定。

5. 网络效应
窄

航线越多对货主越有吸引力（中转枢纽效应）· 但弱于互联网平台的网络效应。趋势：略加宽（一带一路航线扩张）。

10 年后护城河会更宽还是更窄？ 稳定偏宽——区位垄断 + 重资产壁垒是港口生意的根本，10 年内难被颠覆。真正的风险不在竞争，而在腹地经济周期（钢铁/原油/外贸需求）+ 山东港口集团内部的同质化竞争协调（青岛港 vs 日照港 vs 烟台港）。

定价权：弱。港口费率受国家发改委指导，不能自由提价——这是公用事业属性的双刃剑：稳定但天花板低。增长主要靠吞吐量增长 + 降本增效，而非提价。

5.4 所有者盈余（价值投资口径 · FY2025）

所有者盈余 = 净利润 + 折旧摊销 − 维护性 Capex ± 营运资金变动 + JV 现金分红调整

港口是重资产折旧大户。OCF ¥55.49 亿已含折旧加回。维护性 Capex 估约 ¥15-18 亿（总 Capex ¥24.64 亿中含董家口港区扩建等扩张性支出）。

所有者盈余 ≈ OCF ¥55.49 − 维护性 Capex ¥16 ≈ ¥39.5 亿（归属全体股东），归母口径约 ¥36 亿。

所有者盈余收益率 = ¥36 亿 / H股市值 ¥398 亿 ≈ 9.0%——对一个区位垄断、零债务压力的港口公用事业而言，这是相当有吸引力的收益率。

12.2 给的方式好不好？

  • 纯现金分红，无回购：作为高股息国企港口，现金分红是主要回报方式 · 对追求现金流的红利投资者友好
  • 年内两次派息（中期 + 末期）：FY2025 中期 ¥9.52 亿已于 2025-12-24 派发，末期 ¥12.90 亿待股东会批准——现金回流节奏对股东更友好
  • 无 SBC 稀释：国企无股权激励大规模稀释问题，总股本 64.911 亿股稳定 · 每股权益持续增厚（每股净资产 ¥6.20→¥6.55→¥7.04）
  • 未做回购：H股破净（P/B 0.87x）时不回购，是一个"错过的低价回购机会"——若能在破净时回购注销，对股东价值增厚明显。这是可改进项

12.3 能不能继续给、给多少？

  • 分红政策：明确"现金分红不低于可分配利润的 45%"——政策清晰、可预期
  • (股息) / FCF 覆盖度：FY2025 分红 ¥22.42 亿 / FCF ¥30.85 亿 = 73%——FCF 完全覆盖分红，可持续性强，不靠举债分红
  • 净现金 ¥104 亿 + 零债务压力：分红能力有充足的资产负债表支撑，未来增息空间大
  • 潜在改进：若提高派息率至 50%+ 或在破净时启动 H 股回购，股东回报含金量将进一步提升

周期择时：当前 H 股破净 + 净现金充裕，是"高股息防守 + 估值修复"的良好买点。分红可持续性优秀（FCF 覆盖 73%）。

模块小结：积极且高含金量——纯现金分红、连续三年增息、派息率稳定 42%、FCF 覆盖 73%、政策清晰可预期、无 SBC 稀释。唯一可改进项是"破净时未启动回购"。对红利型投资者而言，这是一份稳定可靠、可预期的股东回报记录。

几个研判要点

一、H股 P/B 0.87x 破净 + 7.5x P/E，是看得懂的低估值红利标的。 一个 ROE 12%、区位垄断、净现金占市值 26% 的港口，市场给的估值低于其净资产——这本身就是安全边际。剔除净现金后核心 P/E 仅 5.6x。更关键的是，H 股较 A 股折价 31%——同一份资产，港股是更便宜的入口。8 种估值法中位数 HK$9.2，对当前 HK$7.08 有 23% 折价。

五、12 个月目标价 HK$8.9，上行 +26% + 5.6% 股息 = 总回报 ~32%。 悲观 HK$6.5（-8%，腹地经济走弱）、基准 HK$9.0（+27%，估值修复至 P/B 1.0x + 增息）、乐观 HK$11.0（+55%，AH 溢价收敛 + 红利重估）。概率加权 HK$8.9。当前 HK$7.08 已接近机械首仓 HK$7.4——进入合理建仓窗口。

海图研判

评级：买入（H股破净 P/B 0.87x + P/E 7.5x + 净现金占市值 26% + 前瞻股息率 5.6% + 连续三年增息 + 区位垄断护城河的稳健组合，但利润依赖 QQCT 单一 JV + 86% 现金存放关联财务公司 + 费率受管制 + 国企小股东利益排序靠后）。12 个月概率加权目标价 HK$8.9（+26%），叠加 5.6% 股息 = 总回报 ~32%。

操作建议：当前 HK$7.08 已接近机械首仓 HK$7.4。首仓 HK$7.4（×80%·距现价 +5%·可建仓）、二仓 HK$6.4（×70%·-10%）、三仓 HK$5.5（×60%·-22%·52 周低附近）。止盈三档 HK$10.5 / HK$12.0 / HK$14.0，每档减仓 25%，最后 25% 长期收息持有。建议总仓位 4-8%（中等仓位 · 红利型防守标的 · 组合的现金流压舱石）。持有周期 3-5 年。关键纪律：把它当"收息 + 估值修复"标的，不要期待成长爆发；持续监控关联现金安全 + JV 分红回款。

风险提示

关联方现金集中（¥124.66 亿存放山东港口财务公司）/ 腹地经济与大宗需求下行 / JV 利润含金量下降 / 国企治理与不利关联交易 / 港口费率管制——任一项都可能压制估值。但 H股 P/B 0.87x（破净）+ 净现金 ¥104 亿（市值 26%）+ 5.6% 股息率构成硬底，HK$5.5-6.0 是较硬的估值底（P/B ~0.7x + 股息率 6.5%+，南向红利资金会托底）。

关键叙事："H股破净 P/B 0.87x + P/E 7.5x + 净现金占市值 26% + 前瞻股息率 5.6% + 连续三年增息 + 全球前五大港区位垄断"的低估值红利组合，对垒"利润依赖 QQCT 单一 JV + 86% 现金存放关联财务公司 + 费率管制 + 国企治理"的结构性约束。青岛港不是一笔成长股，是一座"区位垄断现金牛 + 持续高分红 + 破净修复"的红利压舱石——给在风浪年份里需要稳定现金流、愿意用耐心换收息复利、能容忍低增长的价值投资者。下次催化剂：2026-08 中期业绩 + 中期分红。
