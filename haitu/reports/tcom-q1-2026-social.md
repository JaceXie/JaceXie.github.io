# 携程集团 Trip.com（NASDAQ: TCOM / HKEX: 09961）Q1 2026 · 海图夜读

同一面镜子，半年前照出虚高的利润，半年后照出虚低的亏损——携程的财报，是"看穿投资损益"原则最生动的一堂课。FY2025 年报里 GAAP 净利被 ¥199 亿投资收益虚高，TTM P/E 只有 7 倍像捡钱；Q1 2026 里同一个投资组合反过来把净利砸出 -41.6% 的大坑。可两次你都会被骗，只要你盯着 GAAP 净利看。

携程是中国最大的在线旅游平台——撮合酒店、航司与旅客，赚 ~79.5% 毛利率的轻资产佣金。Q1 2026 营收 ¥162.1 亿（+17.2%）· 经营利润 ¥39.5 亿（+10.7%）· 调整后 EBITDA ¥48.3 亿（+13.7%）· Non-GAAP 归母净利 ¥39.1 亿（仅 -6.8%）。但 GAAP 归母净利只有 ¥25.0 亿（-41.6%）——这 -41.6% 不是主业坏了，是权益法联营亏损扩大、投资组合公允价值由盈转亏、去年同期高基数三件事叠加的会计噪音。**主业还在稳健增长，市场却在为一面会被骗两次的镜子定价。**

## 几个研判要点

**一、GAAP 净利 -41.6% 是投资噪音，经营利润 +10.7% 才是真相。** 这是携程财报永恒的陷阱：投资组合（MakeMyTrip、同程等股权 + 可交换债）的公允价值变动让 GAAP 利润年年大幅失真。**分析携程，永远先把投资噪音剥干净，再看核心 OTA**。本季经营利润 +10.7%、调整后 EBITDA +13.7%、Non-GAAP 净利仅 -6.8%——主业健康。TTM GAAP P/E 6.1x 是假象，真正可信的是 Forward P/E 12-13x、核心业务 P/E ~8x。

**二、真正的剑是 SAMR 反垄断，而且实质恶化了。** 2026-01 携程收到 SAMR 正式立案通知，调查其是否"滥用市场支配地位"。管理层明言"无法预测时间、结果或后果"，并把合规整改成本量化进 Q2 指引——**Q2 营收增速从 Q1 的 +17% 骤降至 +3-8%**。这比 Q4 报告时的"传闻/早期"严重得多。梁建章把它淡化为"一种正常化"，但承认了对 KPI 的短期拖累。**这是本季评级保持"有条件买入"而非"买入"的核心原因——便宜不足以抵消监管的不确定性。**

**三、双增长引擎依旧强劲，是穿越监管的底气。** 入境游毛订单 +90%（管理层定下"5 年服务 2 亿入境游客"目标，2025 年才 2000 万，10 倍空间）· 国际 OTA 平台 Trip.com 毛订单 +65%（较 Q3 的 ~60% 还在加速）。**这两个结构性引擎与监管几乎无关**——监管压的是国内变现，压不住出入境的人流复苏。

**四、$50 亿回购终于从"授权"走向"放量"。** 本工具历史上曾把携程的回购授权误判为"力度温和"，这次用现金流量表硬核对：FY2025 实际执行回购 $6.29亿（10M ADS），**摊薄 ADS 股数从 7.02 亿首次实质降到 6.82 亿**——回购终于从"抵消 SBC 稀释"转向"真减少股本"。叠加 2025 年向 MakeMyTrip 回售注销 $30 亿 Class B 股，资本配置正在改善。真实净现金 $10.6B（占市值 36%，注意是扣掉 ¥308 亿有息负债后的**净**现金，不是公司口径的 $15.1B 总现金）。

**五、12 个月目标价 $60，上行 +30%。** 悲观 $42（30%，SAMR 重罚 + 整改 + 减速）、基准 $60（45%，监管可控收尾 + H2 恢复 + 回购放量）、乐观 $78（25%，轻罚结案 + 双引擎复利）。概率加权 $60。**当前 $46.30 已低于机械首仓 $48——进入合理建仓窗口**，反向 DCF 显示市场只给核心业务 ~3% 长期增长，过度悲观。

## 海图研判

**评级：有条件买入**（中国 OTA 龙头 + 入境/国际双引擎 + 真实净现金占市值 36% + $50 亿回购放量 + Forward P/E 12-13x 全球 OTA 低端的组合，对垒 SAMR 反垄断正式立案 + Q2 增速骤降至 3-8% + GAAP 利润被投资噪音扭曲 + 中概身份的真实折价）

12 个月概率加权目标价：**$60**（+30%）

- 乐观（25%）：$78 — SAMR 轻罚结案 + 双引擎复利 + 回购激进执行 + 估值重估
- 基准（45%）：$60 — 监管可控收尾 + H2 增速恢复 + 回购放量 + 核心 P/E 修复
- 悲观（30%）：$42 — SAMR 重罚 + 业务模式被迫整改 + 增速持续低迷

**操作建议**（独立估值中位数 $60，加权公允 $60）：

当前价 $46.30 已低于机械首仓 $48，进入合理建仓窗口：

- 首仓 **$48**（估值中位数 × 80%，距现价 +4%，已过——可建仓）
- 二仓 **$42**（× 70%，距现价 -9%，回调加仓·接近悲观情景）
- 三仓 **$36**（× 60%，距现价 -22%，52 周低附近·净现金底）

止盈三档：**$72 / $85 / $100**（每档减仓 25%，最后 25% 视监管 + 国际化定）

建议总仓位 **3-5%**（中等偏低 · 反映 SAMR 监管 + 减速 + 中概身份三重折价 · 小仓位起步、等监管明朗加仓）。这是一笔"好生意被监管悬剑打折"的逆向标的——不是给追求确定性的人，是给愿意看穿投资损益噪音、能承受 SAMR 监管悬剑、并相信入境/国际双引擎与回购长期兑现的逆向价值投资者。**持有周期 2-4 年**，目标是"穿越监管周期 + 兑现双引擎 + 回购放量"。关键纪律：先把投资噪音从 GAAP 净利里剥干净再估值；不在 SAMR 利空时恐慌割肉，也不在监管明朗前重仓。

## 风险提示

1. **SAMR 反垄断重罚 / 强制业务模式整改** → 概率 15%，股价跌至 $35-38
2. **增速持续减速（Q2 +3-8%，合规成本侵蚀利润率）** → 海外投放压制经营利润率
3. **投资组合波动让 GAAP 利润失真** → 财报"看不清"困扰估值
4. **中概 ADR 退市** → 但港股 09961 提供转换通道对冲
5. **火车票务监管** → 交通票务分部（占 37%）增速已最慢
6. **地缘/出入境政策波动** → 入境/出境游引擎受挫

但真实净现金 $10.6B（市值 36%）+ 投资组合 + P/B 1.06x（接近账面价值）+ 核心 OTA 仍 +17% 增长构成**硬底**，$38-42 是较硬的估值底（52 周低 + 账面价值支撑）。

关键叙事：**"中国 OTA 龙头 + 入境游 +90% / 国际 +65% 双引擎 + 真实净现金占市值 36% + $50 亿回购终于放量 + Forward P/E 12-13x"的优质组合，对垒"SAMR 反垄断正式立案 + Q2 增速骤降至 3-8% + GAAP 利润被投资噪音扭曲 + 中概身份"的真实风险**。携程不是给追求确定性的人——是给愿意看穿投资损益噪音、能承受 SAMR 监管悬剑、并相信入境/国际双引擎与回购长期兑现的逆向价值投资者。下次催化剂：2026-08 Q2 2026 财报 + SAMR 调查任何进展。
