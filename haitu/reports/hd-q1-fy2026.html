本季必看 · 两个"看穿"：并购增长 vs 内生停滞、毛利率结构性下移

家得宝这份财报的关键，藏在"+4.8% 营收增长"与"+0.6% 可比销售"之间的落差里，看不穿这道落差就会高估它的增长质量。

看穿一：4.8% 的营收增长，几乎全是并购买来的。 净销售 +4.8%（$39.86B → $41.77B）里，可比销售只贡献 +0.6%（美国仅 +0.4%），其余大部分来自 SRS（约 $182 亿收购的专业建材分销）与 GMS（约 $1,000 亿 HVAC 分销市场）的并表——本季 GMS 约贡献 $13 亿。换句话说，剔除并购，家得宝的内生生意几乎原地踏步。这不是做错了什么，而是它绑定的房地产周期还没转向。

模块 1 · 公司概览与背景

The Home Depot, Inc.（NYSE: HD），总部亚特兰大，成立于 1978 年，全球最大的家居改善（home improvement）零售商。财年错位——在每年 1 月底/2 月初结束。最新已发布财季为 Q1 FY2026（截至 2026-05-03，2026-05-19 发布）。

核心叙事：家得宝是给专业施工队（Pro）与 DIY 业主供货的"家居改善收费站"——赚的是全美约 1.4 亿套存量住宅每一次翻新、维修、扩建的钱。2,361 家零售大卖场 + 1,280+ 个 SRS 分销点，覆盖全美 50 州及加拿大、墨西哥，约 47 万名员工。FY2025 全年净销售 $1,646.8 亿。这是一门 25.4% ROIC、密集门店网络 + 强大品牌 + 规模采购 的宽护城河生意，但天花板由房屋换手率与利率决定。

增长战略（管理层框架）：

  • Pro 生态扩张——以 SRS（屋顶/景观/泳池专业分销）+ GMS（石膏板/建材分销）+ tuck-in 并购切入约 $7,000 亿的 Pro 专业市场，新增 HVAC 分销再打开约 $1,000 亿，总可及市场（TAM）提升至约 $1.2 万亿
  • 互联零售（interconnected retail）——线上与门店打通，本季线上可比 +10% 以上，连续第 4 个季度双位数增长
  • 门店密度 + 供应链——FY2026 计划新开约 15 家门店 + 40-50 个 SRS 网点，持续加密最后一公里配送

股权结构与治理：单一类别普通股，机构持股占绝大多数（Vanguard、BlackRock、State Street 等指数巨头为前列股东），无控股股东、无双层股权，属高度分散的成熟大盘蓝筹。单一可报告分部（家居改善零售），仅按产品线/地区做营收分解。

能力圈检验：生意极其清晰（看得懂的顶级零售商）——两句话能说清怎么赚钱。主要不确定性在宏观而非公司：(1) 利率何时回落、房屋成交何时回暖，决定内生需求拐点；(2) SRS/GMS 并购整合与协同兑现节奏，决定利润率能否止跌回升。这两点是研判的核心变量。

模块 2 · 管理层评估
B+

Ted Decker · 董事长兼 CEO（2022 至今）

1990 年代末加入家得宝，历任采购、供应链、COO，2022 年接任 CEO。Decker 时代的主线是把家得宝从"以 DIY 为主的大卖场"重构为"Pro 专业客户 + DIY 双轮"——用 SRS（$182 亿）、GMS 及一系列 tuck-in 并购搭建专业建材分销生态，切入更大、更黏、复购更强的施工队市场。战略逻辑清晰、执行坚决。海图判断：这是一位深谙零售运营、以长期市占率扩张为纲的掌舵人，但代价是短期利润率被并购稀释、杠杆抬升。

B

资本配置纪律 · 进入"防守 + 去杠杆"阶段

股息：连续派息自 1987 年 6 月从未间断，2026-02 上调 1.3% 至 $2.33/季（$9.32 年化）——但 1.3% 的增幅是近年最小，反映现金优先去杠杆。
回购：已暂停。回购从 FY2023 的 $79.5 亿断崖式降至 FY2024 的 $6.5 亿，FY2025 与 Q1 FY2026 直接归零。$150 亿回购授权（2023-08）基本未动用。摊薄股数因此不降反升（FY2024 9.93 亿 → Q1 FY2026 9.96 亿），EPS 少了缩股这条增长腿。
并购：SRS/GMS 逻辑正确但推高杠杆，真实净负债 -$519 亿。管理层指引杠杆回落至约 2 倍后、FY2026 末前后重启回购。

长期主义测试：✅ 管理层以 Pro 生态 + 市占率长期扩张为主线，宁可短期牺牲利润率与回购、也要卡位 $1.2 万亿 TAM，是长期视角而非季度博弈。坦诚度：电话会披露详尽——逐月可比销售（含 4 月转负）、毛利率稀释来源、ROIC 下滑、回购暂停原因都主动说明，不粉饰。前几季度（尤其 Q3 FY2025）敢于下调指引并归因于"缺乏风暴 + 需求回升未兑现"，诚实度好。利益绑定：管理层持股比例不高（成熟大盘股常态），薪酬与营收/营业利润/ROIC 挂钩。

模块 3 · 商业模式深度解析

海图"一句话测试"：家得宝是全美最大的家居改善零售商——通过 2,361 家大卖场 + Pro 专业分销网络，把建材、五金、家电、装修用品卖给专业施工队和 DIY 业主，靠规模采购的成本优势 + 密集门店网络 + 强大品牌赚取零售价差，是全美存量住宅翻新维修的"总供货商"。

收入结构（Q1 FY2026）：家得宝为单一可报告分部，不按业务分部拆分。本季净销售 $417.7 亿，量价拆解——客均单价 $92.76（可比 +2.2%）+ 客户交易 391.1mm 笔（可比 -1.3%），是典型的"量减价增"格局，反映通胀传导 + 大额低频装修承压。16 个商品部门中 9 个可比转正（含存储、电动工具、五金、水暖、电气、卫浴、室内园艺、油漆、厨房）。

单位经济与议价能力：

  • 对供应商议价能力：强——$1,600 亿+ 采购规模 + 存货周转 4.2 次，对制造商有强议价力，是成本优势的来源
  • 对客户定价权：中——与 Lowe's 双寡头竞争 + 亚马逊在标准品类蚕食，限制了终端加价空间，可比单价靠通胀而非提价
  • Pro 客户黏性：中-强——专业施工队看重库存深度、信用账期、配送时效与批量供货，SRS/GMS 的分销网络正在提高这部分黏性
  • 周期敏感性：高——生意与房屋换手率、房价、利率强相关，是本模式最大的软肋
模块 4 · 经济护城河分析（5 维）
1. 网络效应
窄

零售本身网络效应弱，但 Pro 生态 + 互联零售形成弱双边效应（施工队越多、库存/配送越密、越吸引供应商）。趋势：Pro 生态缓慢加宽。

2. 规模/成本优势
宽

$1,646 亿营收 + 全球采购 + 密集供应链，单位采购与物流成本行业最低。25.4% ROIC 是规模优势的直接证据。趋势：稳定。

3. 转换成本
窄-中

DIY 客户切换成本极低；Pro 客户因信用账期、库存深度、配送集成有一定黏性。趋势：Pro 端提升、DIY 端仍低。

4. 无形资产/品牌
宽

家得宝品牌是全美家居改善的心智首选 + 橙色大卖场的国民认知度 + 数十年信任积累。趋势：稳定（品牌是最硬的护城河）。

5. 有效规模
中-宽

大卖场家居改善本质是 HD/Lowe's 双寡头，新建全国性门店网络几无经济性。但亚马逊在标准品类、专业分销商在 Pro 端持续蚕食。趋势：稳定偏承压。

10 年后护城河会更宽还是更窄？ 核心护城河（规模成本 + 品牌 + 门店密度）10 年后大概率仍宽，Pro 生态还可能加宽——家得宝用 SRS/GMS/tuck-in 并购从"卖场"向"专业建材总分销"延伸，这块生意更大、更黏、更抗周期。但两个侵蚀点需盯住：(1) 亚马逊与垂直电商在标准五金/家电品类的价格与配送优势；(2) Lowe's 的贴身竞争——LOW 更偏 DIY、估值折让约 15%、增速略快，双寡头理性竞争但边际份额之争持续。总体：护城河宽且稳，趋势中性偏正面，核心变量是执行而非结构性颠覆。

定价权：中等——受双寡头竞争 + 电商比价压制，终端加价空间有限，可比单价增长主要来自通胀传导而非主动提价。

5.5 所有者盈余（价值投资口径 · FY2025）

所有者盈余 = 净利润 + 折旧摊销 + 股权激励 − 维护性 Capex ± 营运资金 ≈ FCF

FY2025：净利 $141.6 亿 + D&A（约 $30 亿）+ SBC（约 $7 亿）− 维护性 Capex（估约 $25 亿，剔除新店扩张部分）± 营运资金 ≈ 自由现金流 $126.5 亿。家得宝 Capex 仅占营收 2.2%，多为维护性，故 FCF 与所有者盈余高度接近。

所有者盈余收益率 = FCF $126.5 亿 / 市值约 $3,420 亿 ≈ 3.7%——这是一个"优质龙头 + 偏满估值"的收益率。3.7% 的 FCF Yield 对一个 EPS 正在同比下滑、可比销售接近停滞、回购暂停的公司并不算便宜，反映市场仍给予家得宝质量溢价 + 提前定价了一场尚未发生的房屋复苏。换句话说：家得宝的问题不是生意不好，而是当前价格已把复苏预期算了进去，安全边际不足。

  • 同业竞争：中（HD/LOW 理性双寡头，不打全面价格战，但边际份额之争持续）

颠覆风险：家居改善的实体属性（大件、即时、专业服务）为 HD 提供了对抗纯电商的天然缓冲，颠覆风险中等偏低。真正的周期风险来自宏观——房屋换手率与利率，而非结构性技术颠覆。

  • 2026-08-18 Q2 FY2026 财报——旺季表现 + 可比销售是否随天气/装修季回暖，是最近的验证点（日期基于历史节奏估计，尚未确认）

  • 回购重启信号——若杠杆回落至约 2 倍、管理层宣布重启回购，将补上 EPS 增长的一条腿

长期展望（3-5 年）：

  • 房屋周期正常化——存量住宅老龄化（美国房龄中位数已超 40 年）+ 递延装修需求释放，是长期结构性顺风
  • Pro 生态成第二增长极——$7,000 亿 Pro 市场 + $1,000 亿 HVAC，SRS/GMS 把 HD 从"卖场"升级为"专业建材总分销"
  • 互联零售 + 供应链——线上双位数增长 + 最后一公里配送密度，提升 Pro 与大件履约能力
  • 回购重启——杠杆正常化后恢复缩股，EPS 增长引擎回归
  • 风险情景：利率长期高企 / 房市持续冰封 / 并购协同不及预期 / 利润率进一步下移

TAM 展望：总可及市场约 $1.2 万亿（DIY + Pro $7,000 亿 + HVAC $1,000 亿等），HD 当前 $1,647 亿营收渗透率仍低，长期空间充足。核心问题不是天花板，而是需求何时随利率解冻、并购协同何时兑现——增长的时点由宏观决定。

模块 12 · 股东回报分析

家得宝的股东回报正从"分红 + 回购双管"切换到"分红为主、回购暂停"的防守阶段——要区分授权、执行，以及"为并购去杠杆而牺牲回购"的性质。本季派息 $23.2 亿、回购 $0，值得细拆。

12.2 给的方式好不好？（质 · 摊薄股数 3 年趋势）

  • 摊薄股数不降反升——FY2023 10.02 亿 → FY2024 9.93 亿 → FY2025 9.95 亿 → Q1 FY2026 9.96 亿。回购停摆后，股权激励（SBC）的稀释无对冲，股数从底部微升。这是硬指标：回购引擎一旦熄火，EPS 就失去"缩股增厚"这条腿，本季 EPS 同比 -4.3% 正是净利下滑 + 股数微升的双重结果
  • 注销 vs 库存股：家得宝美股回购历史上以入库存股为主（部分用于员工持股），含金量本就打折；但当前回购为 0，无回购质量可评——问题不在"方式好不好"，而在"根本没在回购"
  • 股息是真金白银：现金股息直接派发、连续增长，这部分含金量高、可验证；但 2026-02 增幅仅 1.3%（近年最小），反映现金优先去杠杆

12.3 能不能继续给、给多少？（前瞻 · 可持续性）

  • 已授权未执行额度：$150 亿回购计划（2023-08 授权）绝大部分未动用，约占市值 4.4%。约束力弱（董事会授权只是上限，非 ASR/自动注销），且已"授权多年、近两年执行率极低"——是暂时冻结的空头支票，重启前不构成实质支撑
  • 股息指引：连续派息自 1987 年 6 月从未间断，2026-02 上调 1.3% 至 $2.33/季（$9.32 年化）· 累进式分红政策 · 但增幅放缓，派息率已达净利 65%、FCF 72%，进一步大幅增息空间有限
  • (股息 + 回购) / FCF 覆盖度：FY2025 = $9,152M / $12,646M ≈ 72%——覆盖充分、无借债回购（现金优先偿债：Q1 净还短债 $9.61 亿 + 还长债 $14.25 亿）· 分红可持续性高
  • 回购重启时点：管理层指引杠杆回落至约 2 倍后、FY2026 末前后重启回购。这是补上 EPS 增长腿的关键，但取决于去杠杆进度 + 现金流
  • 周期择时瑕疵：FY2023 高位大额回购 $79.5 亿后暂停，如今股价回落却无钱回购——高位买、低位停，是资本配置择时的典型瑕疵

模块小结：积极分红但回购缺位，含金量中等偏防守——自 1987 年从未间断的累进式股息是真金白银的底色（trailing yield 2.7% 全来自分红、FCF 覆盖 72% 可持续），但回购归零、摊薄股数不降反升、$150 亿授权常年未动用，使当前股东回报缺少"缩股增厚"这条腿。这是"为并购去杠杆而主动收缩回报"的阶段性选择——待杠杆正常化、回购重启，含金量有望回升；在此之前，股东回报是"稳定但不完整"的。

夜读手记 · 1150 字

价值投资里有一种熟悉的两难——公司足够好，但宏观逆风与并不便宜的价格，让人下不去手。家得宝就是这样一台机器：全美最大的家居改善零售商，2361 家门店 + Pro 专业客户生态 + 25.4% 的 ROIC，可它的引擎正被高利率死死压住。房屋成交低迷、大额装修递延，Q1 可比销售只有 +0.6%，每股收益还在同比下滑。业绩挑不出大错，问题在于：这台机器现在既没顺风，也不便宜。

家得宝是"给专业施工队和 DIY 业主供货的家居改善收费站"——赚的是全美存量住宅每一次翻新、维修、扩建的钱。Q1 FY2026 净销售 $417.7 亿（+4.8%）· 可比销售 +0.6%（美国 +0.4%）· GAAP EPS $3.30（-4.2%）· 调整后 EPS $3.43（-3.7%）· 营业利润率降至 11.9%（上年 12.9%）。增长几乎全来自并购，内生需求接近停滞。

几个研判要点

一、4.8% 的营收增长，几乎全是并购买来的。 这 +4.8% 里，可比销售只贡献 +0.6%，其余大部分来自 SRS（约 $182 亿收购的专业建材分销）和 GMS 的并表，本季 GMS 约贡献 $13 亿。并购同时把毛利率从 33.8% 拉低到 33.0%（降约 75bp，GMS 是低毛利分销），营业利润率从 12.9% 压到 11.9%。家得宝在用并购买营收增长，代价是利润率结构性下移、每股收益同比下滑。这不是坏事，但要清楚：报表上的"增长"含金量，取决于 Pro 生态能否兑现协同。

二、需求被利率锁住，没有明确的加速催化剂。 逐月可比暴露了真实节奏——2 月 +0.7%、3 月 +2.0%、4 月 -0.5%。换厨房、翻新浴室这类大额可选装修仍被高利率和房屋低换手压制，大件商品可比只有 +0.8%。亮点是 Pro（专业客户）可比转正并跑赢 DIY、线上 +10% 以上连续第 4 季双位数。家得宝的困境不是自己做错了什么，而是它绑定的房地产周期还没转向——利率一天不下来，装修需求就一天回不来。

三、别把"净现金"安在它头上——它是高杠杆净负债。 很多人以为龙头零售商都是现金堡垒，家得宝恰恰相反。现金只有 $16 亿，有息负债却高达 $535 亿（短债 $35 亿 + 长债当期 $52 亿 + 长债 $448 亿），真实净负债 -$519 亿；算上经营租赁负债更接近 -$616 亿。股东权益仅 $139 亿——常年大额回购把账面净资产打得很薄，SRS/GMS 并购进一步推高杠杆。这是一家高杠杆公司，不是零负债神话。好在利息覆盖约 8 倍、FCF 强劲，杠杆尚在安全区。

四、回购停了，这是信号。 家得宝过去三年股息稳步增长（FY2023 $83.8 亿 → FY2025 $91.5 亿），但回购从 FY2023 的 $79.5 亿骤降到 FY2024 的 $6.5 亿，FY2025 和 Q1 FY2026 直接归零。原因是并购推高杠杆，管理层优先去杠杆。摊薄股数因此不降反升（FY2024 9.93 亿 → Q1 FY2026 9.96 亿），$150 亿授权基本没动。在杠杆回落、回购重启之前，EPS 少了一条重要的增长腿——这也是它同比下滑的原因之一。

五、估值没有安全边际。 独立估值给出的合理价中位数约 $300（相对 P/E、DCF、所有者盈余收益率、DDM 交叉验证）。当前 $343.30 不是折价，而是相对合理价溢价约 14%。Forward P/E 约 22.9x 对一个 EPS 还在下滑、利润率在压缩、回购暂停的公司偏高。反向 DCF 显示现价已隐含约 5.5-6% 的长期 FCF 增长——等于市场提前定价了一场尚未发生的房地产复苏。

海图研判

评级：持有观望（全美家居改善龙头 + Pro 生态 + 25.4% ROIC + 自 1987 年从未间断派息的顶级生意，对垒高利率锁死房屋成交 + 内生需求停滞 + 并购稀释利润率 + 回购暂停 + Forward P/E 约 23x 无安全边际）。12 个月概率加权目标价 $305（悲观 $265 / 基准 $305 / 乐观 $360），相对现价 -11%——预期回报为负，不在建仓窗口。

操作建议：独立估值中位数 $300。当前 $343.30 无安全边际，耐心等回调。首仓 $240（中位数×80%）、二仓 $210（×70%）、三仓 $180（×60%），分批建立。止盈三档 $400 / $440 / $480，每档减 25%，最后 25% 长期持有。建议总仓位 3-5%（核心质量仓，回调时建，不追高）。持有周期 5-10 年，赌的是利率回落 + 房屋成交回暖 + Pro 生态兑现 + 回购重启。关键纪律：好公司也要好价格，尤其当它的周期还没转、回购还没回来时。

风险提示

高利率持续压制房屋成交与装修需求 / 并购整合不及预期、协同兑现慢 / 利润率进一步下移 / 消费衰退冲击大额可选支出 / 高杠杆下利率上行推高利息费用——任一项都可能让股价跌向 $290（52 周低 $289 附近）甚至更低。但全美龙头地位 + $1.2 万亿 TAM + 大量自有门店地产 + 连续 37 年派息记录构成质量底，$280-290 是较硬的估值支撑。家得宝的"底"比周期建材股高，因为龙头质量溢价难以完全消失。

关键叙事："全美最大家居改善零售收费站 + Pro 生态扩张 + 25.4% ROIC + 自 1987 年从未间断派息"的世界级龙头，对垒"高利率锁死房屋成交 + 内生需求停滞 + 并购稀释利润率 + 回购暂停 + Forward P/E 约 23x 无安全边际"的周期逆风与估值风险。家得宝不缺质量，缺的是一个便宜的价格和一个转向的利率周期。它不是给追高的人——它值得在房市与估值同时给出安全边际时，耐心建仓，然后让一台顶级龙头慢慢滚雪球。下次财报 2026-08-18，届时重新审视需求节奏与去杠杆进度。
