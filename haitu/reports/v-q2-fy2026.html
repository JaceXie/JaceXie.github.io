本季必看 · 两个"看穿"：毛营收 vs 净营收、GAAP vs Non-GAAP

Visa 的利润表有两个必须"看穿"的地方，看不穿就会误读它的增长质量。

看穿一：客户激励是巨额 contra-revenue（抵减项），不是费用。 很多人只看"净营收 $11.23B（+17%）"，却不知道这是毛营收 $15.48B 减去客户激励 $4.25 亿×10（占毛营收 27.4%）之后的净额。客户激励是 Visa 支付给大发卡行/大商户的返利（争夺网络份额的成本），以 contra-revenue 形式直接抵减营收。这一项 +14% 增长，反映网络竞争依然激烈——净营收增速快于客户激励增速，是好信号。

看穿二：GAAP EPS +36% 有水分，Non-GAAP +20% 才是真相。 GAAP 净利 +32%、GAAP EPS +36% 看着惊艳，但其中一大块来自诉讼准备金从去年同期的 $1,000M 骤降到本季 $329M（去年基数高）。剔除诉讼特殊项（+$311M）、无形摊销、股权投资损益后，Non-GAAP 净利 +17%、Non-GAAP EPS +20% 才反映真实经营。EPS +20% 高于净利 +17%，差额来自持续回购（摊薄股数 -2.9%）。这是一台"营收 +17% + 缩股 +3% = EPS +20%"的复利机器。

模块 1 · 公司概览与背景

Visa Inc.（NYSE: V），总部旧金山。源自 1958 年美国银行推出的 BankAmericard，1976 年更名 Visa，2008-03 IPO（当时美国史上最大 IPO）。财年截至 9 月 30 日。

核心叙事：Visa 是全球最大的开放式（open-loop）支付网络，与 Mastercard 构成双寡头——它不是银行、不发卡、不承担持卡人信用风险，而是连接发卡行、收单行、商户与持卡人的"四方模式收费站"，从每一笔交易的金额中抽取极小比例的费用。FY2025 全球总交易额约 $17 万亿。这是一门67% 营业利润率、52% 净利率、93.6% FCF 转化率、Capex 仅占营收 3.7% 的极致轻资产收费桥生意——商业模式质量位居全球公司前列。

三大增长支柱（管理层战略框架）：

  • 消费支付（Consumer Payments）——低双位数支付额增长 + 全球"现金转卡"的长期结构性迁移，是基本盘
  • 新资金流（New Flows）——Visa Direct 实时支付 / B2B 商业支付 / P2P，20%+ 增速，本季 +24%
  • 增值服务（Value-Added Services, VAS）——反欺诈、数据、咨询、发卡科技等，约占净营收 30%，本季 +27%，是增速最快、且被 AI 强化的护城河延伸

股权结构（多类别）：Class A（公众流通，1,660M 股）+ Class B-1/B-2（美国会员银行持有，125M 股，与 interchange 诉讼责任挂钩）+ Class C（国际银行，9M 股）+ 可转换优先股。换算后总摊薄 Class A 等价股约 1,916M。Class B 的转换比率会因 interchange 诉讼责任被下调——这是 Visa 或有诉讼负债的独特机制。

能力圈检验：收费桥生意极其清晰（看得懂的顶级好生意）。但两块黑箱：(1) DOJ 对 Visa 借记业务的反垄断诉讼最终裁决——可能强制开放借记路由，冲击美国借记护城河；(2) 稳定币 / A2A 支付轨道对卡网络的长期脱媒威胁——稳定币链上处理量已超过卡网络合计。这两点决定了 10 年后 Visa 的护城河是加宽还是被侵蚀。

模块 2 · 管理层评估
A-

Ryan McInerney · CEO（2023 至今）

2013 年加入 Visa 任总裁，2023 年接替 Al Kelly 出任 CEO。McInerney 把 Visa 从"消费支付一条腿"重构为"消费支付 + 新资金流 + 增值服务"三支柱增长框架。对稳定币 / AI 的态度务实而清醒——不对抗、而是"收编"：把 Visa 定位为稳定币与真实世界之间的"互操作层"，$7B 稳定币结算跑量 + 160+ 稳定币关联卡计划 + 9 条公链结算，并押注 agentic commerce（AI 代理商务）为下一增长引擎。海图判断：这是一位既守住收费桥基本盘、又主动应对范式变化的掌舵人。

资本配置纪律 · 回购 + 增息双管的教科书

连续 17 年增息（自 2008 IPO，历经疫情从未削减，近 5 年年化增速 ~15%，FY2026 季率升至 $0.670、全年化 $2.68，+13.6%）。
持续大额回购缩股：Q2 单季回购 $7.9B（~2500 万股 @ $320.66），摊薄股数从 FY2021 的 21.9 亿降至当前 19.16 亿（年均缩 2.5-3%），直接放大 EPS。2026-04 新授权 $200 亿多年回购计划（叠加季末剩余 $132 亿 = 可用约 $332 亿）。
一个纪律瑕疵：Q2 返还股东 $9.2B > GAAP 净利 $6.0B，靠动用现金 + 发债（2026-02 发 $30 亿高级债）支撑——是杠杆化资本返还，也是 Visa 呈净负债 -$9.8B 的原因。对一个 FCF 极强的收费桥，适度杠杆化返还合理，但要留意。

长期主义测试：✅ Visa 管理层始终以"网络规模 + 增值服务 + 新资金流"的长期复利为主线，而非短期财报博弈。对稳定币这种潜在颠覆者选择"收编而非对抗"，体现长期视角。坦诚度：电话会披露详尽（分区跨境、CEMEA 中东冲突影响 -2.5pp 都主动说明），Q3 指引偏保守不粉饰。利益绑定：管理层持股比例不高（成熟大盘股常态），但薪酬与 Non-GAAP EPS / 营收增长强挂钩。

模块 3 · 商业模式深度解析

海图"一句话测试"：Visa 是全球刷卡交易的"收费站"——每当有人用 Visa 卡消费，它就从交易金额里抽取极小比例的网络费，不承担信用风险、不持有应收账款，靠 67% 营业利润率的极致轻资产模式赚钱。

四方模式（Four-Party Model）：持卡人 → 发卡行 → Visa 网络（清算 + 结算 + 授权） → 收单行 → 商户。Visa 处于中间，向发卡行 + 收单行两端收取网络费（数据处理费 + 服务费 + 国际交易费）。关键：Visa 不承担信用风险——坏账是发卡行的事，Visa 只赚"过路费"。这是它区别于 American Express（闭环、自担信用）的根本。

模块 4 · 经济护城河分析（5 维）
1. 网络效应
极宽

50 亿张凭证 + 数千万商户 + 200+ 国家的双边网络。持卡人-商户互相吸引，飞轮几乎不可复制。趋势：稳定（稳定币/A2A 是唯一潜在替代轨道）。

2. 规模/成本优势
宽

处理 66.1B 笔/季、日均 9 亿笔，边际成本趋近于零。67% 营业利润率 + 93.6% FCF 转化，规模碾压。趋势：加宽（VAS + AI 强化）。

3. 转换成本
宽

发卡行/收单行深度集成 Visa 的清算结算基础设施 + 反欺诈/代币化服务，切换成本极高。趋势：稳定。

4. 无形资产/监管牌照
中-宽

Visa 品牌全球信任 + 网络规则 + 数十年清算许可。但正因寡头地位招致 DOJ 反垄断 + interchange 费率监管。趋势：监管压制。

5. 有效规模
宽

全球开放式卡网络本质是双寡头（Visa/Mastercard），新进入者几无空间。趋势：稳定（威胁来自体系外的稳定币，非体系内新玩家）。

10 年后护城河会更宽还是更窄？ 核心网络护城河仍宽，但两个体系外变量决定长期走向：(1) DOJ 借记诉讼——若败诉被迫开放借记路由，美国借记护城河会被凿开一个口子；(2) 稳定币 / A2A 脱媒——稳定币链上处理量（~$33 万亿）已超过 Visa+Mastercard 合计（~$25.5 万亿），长期可能在高毛利跨境与借记轨道形成脱媒。Visa 的对冲是"收编"——把自己变成稳定币与真实世界的互操作层。信用卡的授信 + 积分、借记的反欺诈保障，是稳定币短期难以替代的缓冲。

定价权：强但受监管天花板压制。interchange 反垄断和解已锁定未来 5-8 年的费率下调路径。

5.4 所有者盈余（价值投资口径 · FY2025）

所有者盈余 = 净利润 + 折旧摊销 + SBC − 维护性 Capex ± 营运资金 ≈ FCF

Visa 是极轻资产、极高现金转化的收费桥，FCF 几乎等于所有者盈余。FY2025 FCF $21.58B（Capex 仅 $1.48B、占营收 3.7%）。

所有者盈余收益率 = FCF $21.58B / 市值 $650B ≈ 3.3%——这是一个"顶级质量 + 顶级估值"的收益率：3.3% 的 FCF Yield 对一个 +10-11% 营收增长、67% 营业利润率、双寡头护城河的公司不算便宜。它反映市场已充分认可 Visa 的质量。换句话说：Visa 的问题从来不是生意好不好，而是价格贵不贵——当前 3.3% 的 FCF Yield 意味着几乎没有安全边际。

12.2 给的方式好不好？

  • 真实缩股 · 含金量高：摊薄 Class A 等价股从 FY2021 的 21.9 亿降至当前 19.16 亿（年均缩 2.5-3%），回购是"真减少股本、增厚每股内在价值"，而非仅抵消 SBC。Q2 EPS +20% 高于净利 +17%，差额正是缩股贡献
  • 回购择时中性偏优：Q2 回购均价 $320.66，低于当前 $355——在相对合理价位持续回购，纪律性强
  • 杠杆化返还：Q2 返还 $9.2B > GAAP 净利 $6.0B，靠动用现金 + 发债（2026-02 发 $30 亿高级债）支撑，是 Visa 呈净负债 -$9.8B 的原因。对 FCF 极强、融资成本极低的收费桥，这是合理的资本结构优化，但不是"用赚的钱返还"

12.3 能不能继续给、给多少？

  • 已授权额度充裕：季末剩余 $132 亿 + 2026-04 新授权 $200 亿 = 可用约 $332 亿（约占市值 5%）· 执行历史可信（常年足额回购）
  • 连续 17 年增息：自 2008 IPO 从未削减，近 5 年年化增速 ~15%，FY2026 季率 $0.670（+13.6%）· 派息率仅约 20% 净利，增息空间充足
  • (股息 + 回购) / FCF 覆盖度：FY2025 返还约 $22B / FCF $21.6B ≈ 102%——略超 FCF，靠发债补充。对融资成本 3.8-4.7%、FCF 增长 10%+ 的公司，杠杆化返还可持续
  • 不是被动借债回购：Visa 主动优化资本结构（低成本发债 + 缩股），而非因经营不善举债。净负债 -$9.8B 相对 $21.6B 年 FCF 极轻，杠杆安全

模块小结：积极且高含金量——连续 17 年增息 + 真实缩股（年均 2.5-3%）+ 回购择时合理 + $332 亿可用额度 + FCF 充分覆盖。Visa 是美股"回购 + 增息"复利机器的标杆，唯一需注意的是杠杆化返还（返还略超 FCF、呈净负债），但对这种融资成本极低的顶级收费桥完全可持续。

Forward P/E 22x / FCF Yield 3.3% / 折价仅 5% vs 公允 · 无安全边际，当前价已满价。

红旗排查：DOJ 借记反垄断诉讼（2024-09 起诉，驳回动议 2025-06 被否，结构性威胁美国借记护城河）+ 稳定币/A2A 长期脱媒威胁 + 估值无安全边际（Forward P/E 22x、折价仅 5%）。触发"有疑问 + 满估值"——尽管 6 维基础质量顶级（4 个 A），综合评级降至「持有观望」。

综合评级：持有观望。生意质量是全球顶级（6 维有 4 个 A），但估值维度 C+（满价无安全边际）+ DOJ 红旗 → 降至持有观望。核心判断：Visa 的问题从来不是生意好不好，而是价格贵不贵——当前 $355 没有安全边际，现有持仓者继续复利持有，新买入者应等回调至 $300 附近。

海图
夜读手记 · 1180 字

价值投资里有一类最难下手的标的——生意好到无可挑剔，价格贵到没有余地。Visa 就是这样一台机器：全球每一笔刷卡它都抽一点过路费，67% 营业利润率、93.6% 现金转化、连续 17 年增息。可正因为所有人都看懂了它的好，市场从不给它打折。Q2 净营收 +17%、上调全年指引、新批 $200 亿回购，业绩挑不出毛病——问题从来不在生意，在价格。

Visa 是全球最大的开放式支付网络，与 Mastercard 构成双寡头——它不发卡、不担信用风险，只做四方模式中间的"收费站"。Q2 FY2026 净营收 $11.23B（+17%，2022 以来最强）· 增值服务 +27% / 新资金流 +24% 双引擎 · GAAP EPS $3.14（+36%）· Non-GAAP EPS $3.31（+20%）· 营业利润率 64.4%。这是一门商业模式质量位居全球前列的生意。

几个研判要点

一、两个"看穿"是读懂 Visa 增长质量的钥匙。 看穿一：净营收 $11.23B 是毛营收 $15.48B 减去客户激励 $4.25B（占毛营收 27%）后的净额——客户激励是 Visa 支付给大发卡行的返利，以 contra-revenue 抵减营收，净营收增速快于激励增速是好信号。看穿二：GAAP EPS +36% 有水分（诉讼准备金从 $10 亿降到 $3.29 亿助推），Non-GAAP +20% 才是真相。EPS +20% 高于净利 +17%，差额来自缩股 -2.9%——这是"营收 +17% + 缩股 +3% = EPS +20%"的复利机器。

二、增值服务 +27% 与新资金流 +24%，证明 Visa 不只一条腿。 市场曾担心 Visa 就是"消费支付一条腿"，会随现金转卡见顶而减速。但增值服务（反欺诈、数据、发卡科技，约占营收 30%）+27%、新资金流（Visa Direct/B2B/P2P）+24%，这两条新曲线超预期，直接触发全年指引上调。Visa 正在从"刷卡收费站"进化成"支付领域的 hyperscaler"——增值服务的软件属性还会拉高它的估值中枢。

三、真正的长期变量有二：DOJ 借记诉讼 + 稳定币脱媒。 DOJ 2024 年起诉 Visa 垄断美国借记网络，驳回动议 2025-06 被否，若败诉可能被迫开放借记路由，凿开美国借记护城河。更远的是稳定币——稳定币链上量 ~$33 万亿已超过卡网络合计 ~$25.5 万亿，长期可能在高毛利跨境轨道脱媒。Visa 的对冲是"收编"：$7B 稳定币结算跑量、160+ 稳定币卡计划、9 条公链。信用卡的授信/积分、借记的反欺诈是短期缓冲。这些是 10 年维度的慢变量，但决定终局。

四、别把"净现金"安在 Visa 头上——它是净负债。 很多人以为 Visa 是现金堡垒，其实它有息负债 $24.0B > 现金+投资 $14.2B，真实净负债 -$9.8B。Q2 返还股东 $9.2B > GAAP 净利 $6.0B，靠发债 + 动用现金支撑——这是"杠杆化资本返还"。对融资成本 3.8-4.7%、FCF $21.6B 的顶级收费桥，这是合理的资本结构优化，但要清楚这不是"用赚的钱返还"。

五、12 个月目标价 $375，上行仅 +6%。 悲观 $300（30%，DOJ 不利 + 估值压缩）、基准 $380（45%，低 teens 增长 + 估值维持）、乐观 $440（25%，双引擎加速 + DOJ 有利）。概率加权 $375。当前 $355 折价仅 5%，远高于机械首仓 $300——不在合理建仓窗口。反向 DCF 显示市场已定价 ~10% 长期 FCF 增长，与历史一致，是"合理满价"。

海图研判

评级：持有观望（世界级支付网络 + 67% 营业利润率 + 增值服务/新资金流双引擎 + 连续 17 年增息 + 真实缩股的顶级组合，对垒 DOJ 借记反垄断诉讼 + 稳定币长期脱媒 + Forward P/E 22x 无安全边际的满估值）。12 个月概率加权目标价 $375（+6%），叠加 0.75% 股息 = 总回报仅 ~7%。

操作建议：当前 $355 远高于机械首仓 $300，不在合理建仓窗口。耐心等回调至 $300（52 周低附近）建首仓、$263 加二仓、$225 极端机会三仓。止盈三档 $420 / $470 / $530，最后 25% 长期复利持有。建议总仓位 3-5%（核心质量仓 · 回调时建，不追高）。持有周期 5-10 年。关键纪律：现有持仓者继续让它复利，新买入者必须等价格给出安全边际——好生意也要好价格，Visa 尤其如此。

风险提示

DOJ 借记诉讼败诉 / 稳定币加速脱媒 / 满估值下的多重压缩 / interchange 费率监管 / 消费衰退——任一项都可能让股价跌至 $280-300。但世界级生意 + 67% 营业利润率 + FCF $21.6B + 双寡头护城河构成质量底，$290-300 是较硬的估值底（52 周低 $294 + Forward P/E 18x 下限）。Visa 的"底"比多数股票高，因为质量溢价难以完全消失。

关键叙事："全球支付网络双寡头 + 67% 营业利润率 + 增值服务/新资金流双引擎 + 连续 17 年增息 + 真实缩股复利"的世界级生意，对垒"DOJ 借记反垄断诉讼 + 稳定币长期脱媒 + Forward P/E 22x 无安全边际"的估值与结构性风险。Visa 不是给追求便宜货的人——它几乎从不便宜；它是给愿意在回调时耐心建仓、然后让一台顶级复利机器慢慢滚雪球的长期投资者。下次催化剂：2026-08-04 Q3 FY2026 财报。
