# Visa（NYSE: V）FY2026 Q2 · 海图夜读

价值投资里有一类最难下手的标的——生意好到无可挑剔，价格贵到没有余地。Visa 就是这样一台机器：全球每一笔刷卡它都抽一点过路费，67% 营业利润率、93.6% 现金转化、连续 17 年增息。可正因为所有人都看懂了它的好，市场从不给它打折。Q2 净营收 +17%、上调全年指引、新批 $200 亿回购，业绩挑不出毛病——问题从来不在生意，在价格。

Visa 是全球最大的开放式支付网络，与 Mastercard 构成双寡头——它不发卡、不担信用风险，只做四方模式中间的"收费站"。Q2 FY2026 净营收 $11.23B（+17%，2022 以来最强）· 增值服务 +27% / 新资金流 +24% 双引擎 · GAAP EPS $3.14（+36%）· Non-GAAP EPS $3.31（+20%）· 营业利润率 64.4%。这是一门商业模式质量位居全球前列的生意。

## 几个研判要点

**一、两个"看穿"是读懂 Visa 增长质量的钥匙。** 看穿一：净营收 $11.23B 是**毛营收 $15.48B 减去客户激励 $4.25B（占毛营收 27%）**后的净额——客户激励是 Visa 支付给大发卡行的返利，以 contra-revenue 抵减营收，净营收增速快于激励增速是好信号。看穿二：GAAP EPS +36% 有水分（诉讼准备金从 $10 亿降到 $3.29 亿助推），**Non-GAAP +20% 才是真相**。EPS +20% 高于净利 +17%，差额来自缩股 -2.9%——这是"营收 +17% + 缩股 +3% = EPS +20%"的复利机器。

**二、增值服务 +27% 与新资金流 +24%，证明 Visa 不只一条腿。** 市场曾担心 Visa 就是"消费支付一条腿"，会随现金转卡见顶而减速。但增值服务（反欺诈、数据、发卡科技，约占营收 30%）+27%、新资金流（Visa Direct/B2B/P2P）+24%，这两条新曲线超预期，直接触发全年指引上调。**Visa 正在从"刷卡收费站"进化成"支付领域的 hyperscaler"**——增值服务的软件属性还会拉高它的估值中枢。

**三、真正的长期变量有二：DOJ 借记诉讼 + 稳定币脱媒。** DOJ 2024 年起诉 Visa 垄断美国借记网络，驳回动议 2025-06 被否，若败诉可能被迫开放借记路由，凿开美国借记护城河。更远的是稳定币——**稳定币链上量 ~$33 万亿已超过卡网络合计 ~$25.5 万亿**，长期可能在高毛利跨境轨道脱媒。Visa 的对冲是"收编"：$7B 稳定币结算跑量、160+ 稳定币卡计划、9 条公链。信用卡的授信/积分、借记的反欺诈是短期缓冲。这些是 10 年维度的慢变量，但决定终局。

**四、别把"净现金"安在 Visa 头上——它是净负债。** 很多人以为 Visa 是现金堡垒，其实它**有息负债 $24.0B > 现金+投资 $14.2B，真实净负债 -$9.8B**。Q2 返还股东 $9.2B > GAAP 净利 $6.0B，靠发债 + 动用现金支撑——这是"杠杆化资本返还"。对融资成本 3.8-4.7%、FCF $21.6B 的顶级收费桥，这是合理的资本结构优化，但要清楚这不是"用赚的钱返还"。

**五、12 个月目标价 $375，上行仅 +6%。** 悲观 $300（30%，DOJ 不利 + 估值压缩）、基准 $380（45%，低 teens 增长 + 估值维持）、乐观 $440（25%，双引擎加速 + DOJ 有利）。概率加权 $375。**当前 $355 折价仅 5%，远高于机械首仓 $300——不在合理建仓窗口。**反向 DCF 显示市场已定价 ~10% 长期 FCF 增长，与历史一致，是"合理满价"。

## 海图研判

**评级：持有观望**（世界级支付网络 + 67% 营业利润率 + 增值服务/新资金流双引擎 + 连续 17 年增息 + 真实缩股的顶级组合，对垒 DOJ 借记反垄断诉讼 + 稳定币长期脱媒 + Forward P/E 22x 无安全边际的满估值）

12 个月概率加权目标价：**$375**（+6%），叠加 0.75% 股息 = 总回报仅 ~7%

- 乐观（25%）：$440 — 双引擎加速 + DOJ 有利和解 + 估值重估向 MA 靠拢
- 基准（45%）：$380 — 低 teens EPS 增长延续 + 估值维持 ~24x + 持续回购
- 悲观（30%）：$300 — DOJ 借记诉讼不利信号 + 稳定币恐慌 + 估值压缩至 18x

**操作建议**（独立估值中位数 $375，加权公允 $375）：

当前价 $355 远高于机械首仓 $300，**不在合理建仓窗口**：

- 首仓 **$300**（估值中位数 × 80%，距现价 -15%，耐心等回调·52 周低附近）
- 二仓 **$263**（× 70%，距现价 -26%，大幅回调机会）
- 三仓 **$225**（× 60%，距现价 -37%，黑天鹅级机会）

止盈三档：**$420 / $470 / $530**（每档减仓 25%，最后 25% 长期复利持有）

建议总仓位 **3-5%**（核心质量仓 · 但当前价满估值，应在回调时建仓，不追高）。这是一台世界级复利机器——不是给追求便宜货的人（它几乎从不便宜），是给愿意在回调时耐心建仓、然后让顶级收费桥慢慢滚雪球的长期投资者。**持有周期 5-10 年**，目标是"穿越 DOJ 诉讼 + 稳定币范式变化的长期复利"。关键纪律：现有持仓者继续让它复利，新买入者必须等价格给出安全边际——好生意也要好价格，Visa 尤其如此。

## 风险提示

1. **DOJ 借记反垄断诉讼败诉 + 强制开放路由** → 概率 15%，股价跌至 $260-280
2. **稳定币/A2A 在跨境轨道加速脱媒** → 概率 10%（5 年维度），高毛利跨境受侵蚀
3. **满估值下的多重压缩** → Forward P/E 22x + 折价仅 5%，任何利空都可能触发
4. **interchange 费率监管（美国 MDL 和解 + 英国 PSR + 欧盟 IFR）** → 费率天花板持续压制
5. **消费/宏观衰退** → 支付量骤降，CEMEA 地缘冲突已拖累跨境旅游
6. **杠杆化返还 + 净负债 -$9.8B** → 返还略超 FCF，需留意

但世界级生意 + 67% 营业利润率 + FCF $21.6B + 双寡头护城河构成质量底，**$290-300 是较硬的估值底**（52 周低 $294 + Forward P/E 18x 下限）。Visa 的"底"比多数股票高，因为质量溢价难以完全消失。

关键叙事：**"全球支付网络双寡头 + 67% 营业利润率 + 增值服务/新资金流双引擎 + 连续 17 年增息 + 真实缩股复利"的世界级生意，对垒"DOJ 借记反垄断诉讼 + 稳定币长期脱媒 + Forward P/E 22x 无安全边际"的估值与结构性风险**。Visa 不是给追求便宜货的人——它几乎从不便宜；它是给愿意在回调时耐心建仓、然后让一台顶级复利机器慢慢滚雪球的长期投资者。下次催化剂：2026-08-04 Q3 FY2026 财报。
