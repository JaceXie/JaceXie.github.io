本季必看 · 两个"看穿"：报告增长 vs 有机增长、GAAP vs 调整后

雅培本季利润表有两个必须"看穿"的地方，看不穿就会误读它的增长质量与本季的"业绩塌方"假象。

看穿一：报告增长 +7.8% 有水分，有机可比 +3.7% 才是内生动能。 报告口径净销售额 +7.8%，但其中约 +4.1pp 来自汇率顺风（弱美元）+ 精密科学并表——真实的有机可比增长只有 +3.7%。分部层面看得很清楚：医疗器械报告 +13.2% vs 可比 +8.5%（差额多为汇率）、诊断报告 +6.1% vs 可比 +1.8%（差额来自新并入的癌症诊断 Exact 可比 +13.4%，仅并表约 1 周）。3.7% 的有机增长是本季偏软的一面——营养品可比 -7.7%、Rapid/Molecular 诊断可比 -9.6% 两大拖累压低了整体内生动能。

模块 1 · 公司概览与背景

Abbott Laboratories（NYSE: ABT），总部位于美国伊利诺伊州北芝加哥。创立于 1888 年，是全球历史最悠久、最多元化的医疗健康公司之一。2013 年将专利药业务分拆为 AbbVie（艾伯维）独立上市，此后专注于医疗器械、诊断、营养、成熟（仿制）药四大板块。财年为自然年（截至 12 月 31 日）。

核心叙事：雅培是一家"四轮驱动"的多元化医疗平台——医疗器械 + 诊断 + 营养 + 成熟药品，靠业务分散、地域分散（发达 + 新兴市场）、产品线深度形成穿越周期的稳健。它不是单一 blockbuster 药企的"专利悬崖"叙事，而是数万个 SKU、覆盖 160+ 国家的"医疗基础设施"。四大分部中，医疗器械（占比约 50%）是最大增长引擎——FreeStyle Libre 连续血糖监测（CGM）、结构性心脏、电生理（EP）、心衰、心律管理构成一组高增长 franchise。

本季重大事件 · 收购精密科学（Exact Sciences）：2026-03-23 雅培完成对癌症诊断公司 Exact Sciences 的收购，股权对价约 210 亿美元 / 企业价值约 230 亿美元，主要通过发行约 200 亿美元长期债券融资。此举让雅培一跃成为肿瘤 / 癌症早筛诊断领域的领导者（Exact 的 Cologuard 结直肠癌筛查是核心产品），新增一条高增长曲线；但代价是——资产负债表从近乎净现金转为 -268 亿美元大额净负债，并稀释 EPS（管理层测算 $0.20/年）。这是理解本季所有财务变化的钥匙。

股权结构与治理：单一类别普通股（1,998.2M 股已发行 − 256.4M 库存股 = 1,741.8M 流通），无双重股权结构，治理相对透明。股息之王——雅培（含前身）已连续 53 年提高股息，是标普 500 中最稳定的分红贵族之一。

能力圈检验：一句话能说清——雅培是"多元化的医疗收银台"，靠医疗器械 + 诊断 + 营养 + 药品四条腿在 160+ 国家收取稳定的医疗消费。生意本身清晰易懂。但两块需要盯紧：(1) Exact 收购的整合与协同能否兑现——230 亿美元是雅培近年最大手笔，商誉 + 无形资产合计新增约 $23.5B，是未来减值敞口；(2) NEC 早产儿配方奶粉诉讼的最终规模——1,700+ 起类似诉讼是尾部黑箱。

模块 2 · 管理层评估
B+

Robert Ford · 董事长兼 CEO（2020 至今）

Ford 于 1996 年加入雅培，历任糖尿病护理、医疗器械等核心业务负责人，2020 年出任 CEO、2021 年兼任董事长。任内把医疗器械打造成公司增长引擎——FreeStyle Libre CGM 成为全球最畅销的连续血糖监测系统，结构性心脏、电生理持续放量。本季主导完成 230 亿美元收购 Exact Sciences，切入癌症早筛这一高增长赛道。海图判断：Ford 是一位有清晰增长战略、执行力强的经理人；但这笔大额债务融资的并购是他任内最大的一次赌注——若整合顺利将拓宽版图，若协同不及预期则是杠杆与摊薄的双重压力。评级 B+ 而非 A，正因这笔交易的成败尚待验证。

A-

资本配置纪律 · 股息之王的稳健，但本次并购加了杠杆

连续 53 年增息（股息之王，历经多轮衰退从未削减；2025 年股息 $2.40/股、+7.1%，2026 季率升至 $0.63、全年化 $2.52）。
持续回购但力度温和：2024-10-11 授权 $70 亿回购计划，截至 2025-12-31 剩余约 $67 亿；2025 年经授权公开市场回购 4.8M 股共 $604M，现金流量表"购买普通股" $893M（另含税务代扣 / 员工持股计划约 $289M）——雅培回购主要用于抵消股权激励稀释而非大规模缩股，摊薄股数近乎持平。
本季资本配置转向：动用约 200 亿美元发债完成 Exact 收购，从近净现金转为 -$268 亿净负债。对一个 FCF 稳健、投资级信用（A+/Aa3）的公司，适度杠杆化并购可接受，但去杠杆需要数年，短期利息费用（本季净利息支出 $68M）与摊薄是实打实的成本。

长期主义测试：✅ 雅培管理层历来以"多元化 + 长期分红 + 器械创新"为主线，53 年连续增息本身就是长期主义的最好证据。收购 Exact 是着眼于癌症早筛的长期结构性机会，而非短期财报博弈。坦诚度：电话会主动披露了 Exact 的 $0.20 EPS 稀释、下调全年指引、营养 / 诊断分部疲软，不粉饰。利益绑定：管理层持股比例为成熟大盘股常态（不高），薪酬与调整后 EPS / 有机增长强挂钩；值得注意的是，股价低位时管理层与部分内部人有增持动作，是一个信心信号。

模块 3 · 商业模式深度解析

海图"一句话测试"：雅培是一台"多元化的医疗收银台"——医疗器械、诊断、营养、成熟药品四条腿，覆盖 160+ 国家，靠数万个医疗产品的稳定消费与器械创新的高增长组合赚钱，业务与地域的分散让它穿越周期。

单位经济与议价能力：

  • 医疗器械是利润与增长皇冠——Libre CGM 是可复购的"耗材+设备"模式（装机后持续卖传感器），结构性心脏 / 电生理是高值植入器械，毛利率与粘性都高
  • 诊断是"装机+试剂"模式——核心实验室仪器铺设后靠试剂持续变现，抗周期；但呼吸道检测（Rapid/Molecular）随季节与疫情波动大
  • 营养与 EPD 是稳定现金牛——品牌 + 渠道 + 新兴市场深耕，增长温和但现金流稳定，是分红的底盘
  • 对支付方 / 医院议价能力：中——医疗器械靠临床证据 + 医生粘性定价，但受各国医保控费、集采（如中国 VBP）压制

为什么"多元化"是雅培的核心特征：单一分部（如营养 -7.7%、诊断呼吸道 -9.6%）疲软时，医疗器械（+8.5%）+ EPD（+9%）能对冲，整体有机仍 +3.7%。这种"东方不亮西方亮"的分散性，是雅培 53 年不间断增息的底层保障——代价是它很难像纯医疗器械龙头那样享受高估值溢价。

模块 4 · 经济护城河分析（5 维）
1. 无形资产 / 品牌 & 监管
宽

雅培 138 年品牌信任 + FreeStyle Libre / Ensure / Cologuard 等强势品牌 + 全球医疗器械 / 诊断的严格审批壁垒（FDA/CE）。趋势：稳定（Exact 增强癌症诊断品牌）。

2. 转换成本
中-宽

诊断仪器装机后医院锁定试剂供应；Libre 用户 + 医生形成使用习惯；结构性心脏 / EP 依赖术者训练与临床数据。趋势：稳定。

3. 成本 / 规模优势
中

全球规模化制造 + 采购 + 分销网络（160+ 国家），单位成本优于中小玩家。但医疗器械 / 诊断是充分竞争市场，非绝对成本领先。趋势：稳定。

4. 网络效应
窄

医疗产品无典型双边网络效应；仅 Libre / 数字健康平台有弱数据网络效应（用户数据改进算法）。趋势：略增（数字健康）。

5. 有效规模 / 多元化
中

四分部 + 发达 / 新兴市场分散，单点冲击不致命，是"抗脆弱"式护城河。但也意味着没有单一垄断赛道，增长中枢温和。趋势：稳定。

10 年后护城河会更宽还是更窄？ 整体稳定、局部加宽：医疗器械（Libre CGM 全球渗透、结构性心脏创新）+ 癌症诊断（Exact 早筛）是加宽项，数字健康 + AI 诊断提供新增量；营养品（婴配奶粉需求结构性走弱 + NEC 诉讼阴影）是收窄项。雅培护城河的本质是"多元化 + 创新 + 品牌"的组合拳，而非单一深壁垒——它不像支付网络那样有极宽的网络效应，但胜在分散、稳健、可持续 53 年分红。定价权：中——受各国医保控费 / 集采压制，但创新器械（Libre、结构性心脏）仍有溢价能力。

5.4 所有者盈余（价值投资口径 · 正常化）

所有者盈余 = 净利润 + 折旧摊销 + 其他非现金费用（含 SBC）− 维护性 Capex ± 营运资金

雅培调整后年净利约 $9.0-9.6B（FY2025 调整 EPS $5.15、FY2026 指引中值 $5.48 × ~1,747M 股）。扣除维护性 Capex（年 Capex 约 $2B）与营运资金后，正常化年自由现金流约 $7B（Q1 单季 FCF $916M 为季节性低点，全年显著回升）。

所有者盈余收益率 = 正常化 FCF ~$7B / 市值 $164.4B ≈ 4.3%——对一个有机增长 6.5-7.5%、53 年增息、投资级信用的多元化医疗龙头，4.3% 的 FCF Yield 在合理偏便宜区间，反映股价年内 -38% 后估值已明显回落。但注意：正常化 FCF 需覆盖 $4.1B 股息 + 未来去杠杆，可分配给增量回购的余地有限。

模块 8 · 竞争与行业分析

多元化医疗健康格局：雅培所处的是一个由几家巨头分割、各有侧重的分散市场——没有单一垄断者，竞争体现在各细分赛道（医疗器械 vs 美敦力 / 波士顿科学、诊断 vs 罗氏 / 丹纳赫、生命科学工具 vs 赛默飞、多元化医药 vs 强生）。雅培的独特性在于跨器械 + 诊断 + 营养 + 药品的四轮多元化，这是它区别于任何单一赛道纯玩家的核心。

  • 替代品：中（各赛道有替代技术竞争，如 CGM 领域 vs 竞品、结直肠筛查 vs 内镜）
  • 供应商议价：低（雅培规模化采购议价力强）
  • 买家议价：中高（医院 / 支付方 / 各国医保控费 + 集采压制定价，如中国 VBP）
  • 同业竞争：中高（各细分赛道均有强劲对手，创新竞速激烈）

颠覆风险：雅培的多元化本身就是抗颠覆的缓冲——单一技术被替代不致命。核心看点是医疗器械（Libre CGM 面对竞品、结构性心脏创新竞速）能否维持领先，以及 Exact 癌症早筛能否兑现协同。这是渐进式的赛道竞争，非急剧脱媒。

模块 12 · 股东回报分析

雅培是"高股息 + 温和回购"的经典股息贵族——连续 53 年增息是它最硬的招牌，但要看清回购力度温和、且本季资本重心已转向偿债。

Trailing Shareholder Yield ≈ FY2025 返还约 $4.98B / 市值 $164.4B ≈ 3.0%（其中股息 ~2.5% + 回购 ~0.5%）。雅培是"股息为主、回购为辅"的典型分红贵族——2026 季率升至 $0.63、全年化 $2.52（股息率 2.67%）。派息率约 45%（占调整后净利）/ 约 60-65%（占正常化 FCF），留有增息空间。注意 2025 年回购金额 $893M 中，经授权公开市场回购仅 4.8M 股 $604M，其余约 $289M 为税务代扣 / 员工持股计划相关。

12.2 给的方式好不好？

  • 回购主要抵消 SBC 稀释，含金量打折：摊薄股数 FY2023 ~1,753M → FY2024 ~1,748M → FY2025 ~1,746M → Q1 FY2026 1,747.1M，近乎持平、几乎不降。这说明雅培的回购力度只够抵消股权激励稀释，而非真实缩股增厚每股价值——与"高含金量注销型回购"相比含金量打折
  • 股息才是雅培股东回报的主菜：连续 53 年增息、从未削减，是穿越衰退的确定性来源。股息的含金量高、可预期性强，这是股息之王的核心价值
  • 库存股结构（美股常态）：回购入库存股（2026-03-31 库存股 256.4M 股），多用于对冲员工股权激励，而非注销减股本——这符合美股惯例，但含金量不及港股强制注销

12.3 能不能继续给、给多少？

  • 已授权额度充裕但执行温和：2024-10-11 授权 $70 亿回购，截至 2025-12-31 剩余约 $67 亿（约占市值 4%）· 但历史执行率不高（2025 仅动用 $604M 公开市场回购），授权是上限，实际力度温和
  • 股息可持续性强：53 年连增，派息率约 45%（调整后净利）· 即便本季加杠杆，$4.1B 股息相对稳定 FCF 与投资级信用仍稳固，增息大概率延续
  • (股息 + 回购) / FCF 覆盖度：FY2025 返还约 $4.98B / 正常化 FCF ~$7B ≈ 71%——FCF 充分覆盖，可持续。不同于杠杆化超额返还，雅培返还在 FCF 之内
  • 本季资本重心转向偿债：收购后净负债 -$26.75B，未来数年资本配置优先级是去杠杆 > 增量回购——这意味着回购弹性短期受限，股东回报的增量主要靠稳定增息而非放量回购

模块小结：积极但回购含金量打折——股息为王、回购温和。雅培连续 53 年增息的确定性极高（分红贵族的硬招牌），但回购仅够抵消 SBC、摊薄股数几乎不降，含金量不及真实缩股；且收购后资本重心转向去杠杆，短期回购弹性受限。总体是一个"高确定性股息 + 象征性回购"的稳健返还组合，可持续但增量有限。

海图
夜读手记 · 1120 字

一家连续 53 年提高股息的公司，一年内股价跌掉 38%——这中间的落差，往往藏着值得夜读的故事。雅培本季 GAAP 净利同比 -18.7%、EPS 从 $0.76 掉到 $0.61，看着像塌方；可若你只看这一行，就会彻底误读它。真相是：一场 230 亿美元的大收购，正在这一季集中释放它的成本与阴影。

雅培是一台"多元化的医疗收银台"——医疗器械（Libre 血糖监测 / 结构性心脏 / 电生理）+ 诊断 + 营养 + 成熟药品四条腿，覆盖 160+ 国家。Q1 FY2026 净销售额 $11.16B（报告 +7.8% / 有机可比 +3.7%）· 医疗器械 $5.54B 可比 +8.5% 领跑 · GAAP EPS $0.61（-19.7%）但调整后 EPS $1.15（+5.5%）· 调整后毛利率 56.3%。这是一门业务分散、地域分散、53 年不间断增息的世界级生意。

几个研判要点

一、两个"看穿"，才能读懂本季的真相。 看穿一：报告增长 +7.8% 有水分，有机可比只有 +3.7%，差额来自汇率顺风 + Exact 并表；营养可比 -7.7%、Rapid/Molecular 诊断 -9.6% 两大拖累压低了内生动能。看穿二：GAAP EPS -19.7% 是假象，调整后 +5.5% 才是经营真相——GAAP 与调整后差额高达 $0.54/股，几乎全部是 3 月 23 日完成收购精密科学（Exact Sciences）的一次性成本 + 无形摊销 + SG&A +22% + 新债利息。基本盘没崩，是收购在这一季集中"记账"。

二、这次收购，把资产负债表从"净现金"改写成"-268 亿净负债"。 这是本季最深刻的变化。为收购 Exact，雅培发行约 200 亿美元长债，有息负债从约 $12.9B 飙到 $34.05B，现金+短投仅 $7.30B，真实净负债 -$26.75B；商誉 +$11.2B、无形 +$12.3B，合计新增约 $23.5B 减值敞口。切入癌症早筛这条高增长曲线是好战略，但代价是摊薄（$0.20/年 EPS）+ 加杠杆 + 未来数年的去杠杆。管理层也据此把全年调整后 EPS 指引从 $5.55-$5.80 下调到 $5.38-$5.58——这正是股价年内大跌的核心导火索。

三、还有一柄悬着的剑：NEC 诉讼。 芝加哥陪审团判赔约 $70M，这已是雅培第二次在早产儿配方奶粉致坏死性小肠结肠炎（NEC）诉讼中败诉，背后还有 1,700+ 起类似诉讼待审。若走向系统性批量判赔，累计赔偿可能达数十亿美元，并冲击营养业务与品牌。这是最难定价的尾部风险，也是压制估值的现实因素之一。

四、但别忘了另一面：质地仍是世界级。 医疗器械可比 +8.5%、Libre CGM +7.6%、EPD 新兴市场 +9.4%，增长引擎稳健；调整后经营利润率维持 ~22-23%；投资级信用 A+/Aa3；连续 53 年增息的股息之王身份未动摇。多元化"东方不亮西方亮"，正是它穿越周期的底层保障。股价 -38% 后，Forward P/E 从历史 22-24x 压缩到 17.2x，从"贵"回到"合理偏便宜"——管理层与部分内部人也在低位增持。

五、估值已回落，但安全边际还差一口气。 8 种方法独立加权，公允价中位数约 $108（区间 $103-112），反向 DCF 显示当前价只隐含 ~4-5% 的悲观长期增速。当前 $94.40 对公允折价约 13%——吸引，但未达价值投资 25% 的安全边际门槛，机械首仓 $86.40 还在下方。这是一只"好生意刚回到合理价、但还没到深度打折"的标的。

海图研判

评级：有条件买入（世界级多元化医疗 + 医疗器械双位数增长 + 53 年增息股息之王的顶级质地，对垒 210 亿收购消化 + 268 亿净负债 + NEC 诉讼 + 安全边际不足 25% 的四重逆风）。12 个月概率加权目标价 $108（+14%），叠加 2.67% 股息 = 总回报约 +17%。

操作建议：当前 $94.40 略高于机械首仓 $86.40，不在最理想的建仓窗口，但已进入可分批试探区间。可先小仓位（1-2%）试探 + 回调至 $86 附近加至首仓、$75.6 加二仓、$64.8 极端机会（NEC 最坏情形）三仓。止盈三档 $120 / $132 / $145，最后 25% 长期复利持有。建议总仓位 3-5%（中等质量分红仓，分批建、勿追高）。持有周期 3-7 年。关键条件：等 Q2 财报（7/16）验证基本盘企稳 + 跟踪 NEC 诉讼与去杠杆进度——好生意回到合理价是机会，但要等安全边际再厚一点、不确定性再落地一些。

风险提示

NEC 诉讼系统性败诉 / Exact 整合失败与商誉减值 / 医疗器械核心 franchise 遇竞争 / 营养 - 诊断持续疲软 / 医保控费加剧——任一项都可能让股价回到 $80 附近甚至更低。但世界级多元化 + 53 年增息 + 医疗器械双位数增长 + 投资级信用构成质量底，$80-82（52 周低附近）是较硬的估值底（Forward P/E ~15x 下限 + 股息率升至 ~3.1% 支撑）。除非 NEC 走向最坏情形，跌破 $80 需要基本盘实质恶化。

关键叙事："四轮驱动多元化医疗 + 医疗器械双位数增长 + 连续 53 年增息的股息之王"的世界级生意，对垒"210 亿收购消化 + 268 亿净负债 + EPS 摊薄 + NEC 诉讼 + 安全边际不足 25%"的消化期与尾部风险。雅培的问题从来不是生意好不好，而是这次买贵了没有、消化期多长、诉讼多重。它不是给追短线的人——它是给愿意在合理价耐心分批、收着 53 年不断的股息、等收购协同与估值修复慢慢兑现的长期投资者。下次催化剂：2026-07-16 Q2 FY2026 财报。
