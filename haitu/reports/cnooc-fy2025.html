模块 1 · 公司概览与背景

公司全称：中国海洋石油有限公司 / CNOOC Limited
上市：HKEX: 0883（2001-02-28 香港+纽约同步上市）+ SH: 600938（2022-04-21 A 股回归）+ NYSE: CEO（已 2022-10 退市）
总部：北京 / 香港
主营：海上原油+天然气勘探+开发+生产+销售（纯上游）

核心叙事：中海油是中国最大、全球桶油成本最低的纯上游石油商——FY2025 桶油成本仅 $27.9（vs Exxon $40 / Chevron $45 / 沙特阿美 $10-15），是中国少数同时具备"低成本 + 高储量 + 持续增产"的能源公司。与中石油（一体化油气）、中石化（炼化为主）形成鲜明对比——纯上游纯资源股的业绩弹性最大。FY25 因 OPEC+ 增产油价跌 13% 拖累净利 -11.5%，但 Q1 2026 营收 +8.6% / 净利 +7.1% 强势反弹，说明这是一家"成本控制极强、产量持续增长"的核心资产。

简史与里程碑：

1. 1982 年成立——中国海洋石油集团成立，海上石油专营权
2. 2001-02-28 港股+美股双上市——HKEX: 0883 + NYSE: CEO
3. 2008 年蓬莱 19-3 重大油田投产——成为全球十大海上油气公司
4. 2018 年储量替代率连续超 100%——勘探储量持续补充
5. 2022-04-21 A 股回归——SH: 600938 上市，发行价 ¥10.80
6. 2022-10 NYSE 退市——美中科技脱钩压力
7. 2024-2025 产量 7 连增——FY24 +7.2%, FY25 +7%
8. 2026 Q1 强势反弹——营收 +8.6% / 净利 +7.1%

股权结构（2025-12-31 末）：

中国海洋石油集团（母公司）——~64.4% 股权（国资委 100% 控股）
香港公众股东——~16% H 股流通
A 股公众股东——~19.6% A 股流通
这是典型的"国家队 + 国资委监管"治理结构，中国海上石油专营权牌照

模块 2 · 管理层评估
B+

汪东进 · 董事长（2024 至今 · 国资委轮换制）

1962 年生，2024 年任董事长（前董事长汪东进于 2018-2023 任职后回归）。中海油管理层是国资委轮换制——CEO/董事长 5 年一换，没有"创始人主义"。但产量增长、桶油成本控制、派息率纪律都在管理层轮换中保持稳定。海图判断这是"制度优于个人"的治理结构——任何 CEO 上任后都要执行国资委的"产量增长 + 高质量发展 + 股东回报"三重要求。

A-

资本配置纪律 · 国企标杆

FY2025 派息率约 44%、股息率 4.34%——略低于三大运营商但高于全球油气同行。
过去 5 年股息保持稳定增长，FY25 末期 + 中期合计股息有所提升。
Capex 也展现纪律：FY24 ¥1,322 → FY25 ¥1,205（-9%）。FY26 指引 ¥1,120-1,220 亿（持平至略降）。
不足之处：未启动股票回购计划，仅靠股息回报股东。

A

战略执行能力 · 全球桶油成本最低

FY25 桶油成本 $27.9，远低于 Exxon $40、Chevron $45、Shell $35、BP $40、沙特阿美 $10-15。在油价下跌 13% 的环境下仍能保持高利润率（净利率 31%），是全球纯上游石油商中"最能扛周期"的核心资产。海图判断："国企里少有的极致经营能力"。

长期主义测试：3 年前（FY22 财报）管理层承诺"产量持续增长 + 桶油成本控制在 $30 以下 + 储量替代率超 100%"——3 年后每条都兑现并超额：产量 FY22 624 → FY25 777 百万桶（CAGR 7.6%）、桶油成本 $30.39 → $27.9（-8%）、储量替代率连续 5 年超 100%。这是国企运营中"言行一致"的优秀代表。

薪酬与利益绑定：管理层薪酬遵循国企"限薪令"，董事长年薪 ~¥120 万 + 业绩奖金。激励机制弱，但战略执行力强。

模块 4 · 经济护城河分析（5 维）
1. 网络效应
窄

石油是大宗商品，几乎无网络效应。但海上钻井平台 + 输油管网 + LNG 接收站构成基础设施网络效应——客户越多越便宜。趋势：稳定。

2. 转换成本
窄

石油是同质化产品，买家可轻松切换。但政府订单（中石化炼厂、华能电厂等）合同期 3-5 年 + 长期 LNG 合同提供锁定。趋势：稳定。

3. 成本优势
宽

桶油成本 $27.9 是全球最低之一——远低于 Exxon $40、Chevron $45、Shell $35、BP $40。海上规模效应 + 自动化作业 + 自有钻井平台 + 长期与中海油服合作。趋势：稳定+。

4. 无形资产 (牌照+储量)
宽

中国海上石油专营权——中海油独占中国海上石油勘探开发权（中石油主要陆上）。证实储量 77.7 亿桶油当量（国内最大海上储量）。这是政府授权的法定护城河。趋势：稳定。

5. 有效规模
宽

中国海上原油 + 天然气产量市场份额 ~70%。"赢者通吃"型寡头——中海油 + 中石油海洋分公司构成 95%+ 市场。趋势：稳定。

护城河综合评估：中海油在 5 维护城河上 3 项宽 + 2 项窄。整体属于"宽护城河 + 政府授权"型公司，与电网、铁路、银行同档。但护城河来自垄断 + 资源禀赋而非创新。

10 年后的护城河会更宽还是更窄？—— 海图判断略加宽。理由：(1) 桶油成本继续下降（自动化 + 数字化）；(2) 海上风电+CCS+氢能逐步成型；(3) 储量持续补充（2025 替代率 100%+）。但要警惕：能源转型加速 + 全球电动车渗透 + 化石燃料长期需求下降。

5.3 杜邦分析

FY2025 ROE 14% 拆解：
净利率（36.4%）× 总资产周转率（0.27x）× 财务杠杆（1.43x）= 14.0%

对比 FY2022 高油价峰值（ROE 22%）：
净利率从 37.7% 降至 36.4%（→ 主因油价从 $96.59 跌至 $66.47）
总资产周转率从 0.36x 降至 0.27x（→ 资产规模扩张快于营收）
财务杠杆从 1.41x 升至 1.43x（→ 微调）
ROE 主要受油价驱动，与桶油成本控制无关——这是周期股的典型特征。

5.6 所有者盈余计算（价值投资核心估值法）

FY2025 所有者盈余 = ¥1,221亿（净利）+ ¥1,000亿（折旧摊销）+ ¥80亿（其他非现金）- ¥800亿（维护性 Capex 估，约总 Capex ¥1,205亿 的 66%）+ 营运资金 -¥100亿 = ¥1,401亿（约 $200亿）

注：中海油的 Capex 中约 60-65% 是维护性 Capex（油田维护 + 钻井 + 现有平台升级），约 35-40% 是扩张性 Capex（新油田勘探 + 新平台建设 + 新储量获取）。

所有者盈余收益率 = $200亿 / $1,840亿市值（A+H 合计）= 10.9%

对比无风险利率 4.3%（10Y 美债），超额收益率 6.6 个百分点。这意味着：

1. 即使 0 增长，中海油给股东的回报已经是无风险利率的 2.5 倍
2. 隐含合理 P/E 18x（按 4% 永续无风险利率）—— 远高于当前 10.3x
3. 这是港股大蓝筹中所有者盈余收益率最高的"高股息防御 + 周期赔率"标的

P = D₁ / (r - g)

夜读手记 · 1100 字

石油是周期股，但不是所有石油股都一样。当全球都在谈论能源转型、电动车渗透时，中海油是少有的还能"产量七连增、桶油成本全球第二低、资产负债率行业最低"的核心资产。FY25 净利 -11.5% 看似下滑，但 Q1 26 营收 +8.6%、净利 +7.1% 强势反弹——这告诉你：周期低点已过。

FY2025 油气销售收入 ¥3,357 亿（-5.6%）、归母净利 ¥1,221 亿（-11.5%）、油气净产量 777.3 百万桶（+7%）、桶油成本 $27.9（全球最低之一）——这是一份"油价拖累、产量+成本对冲"的全年财报。但 Q1 2026 营收 ¥1,161 亿（+8.6%）、净利 ¥391 亿（+7.1%）、产量 205.1 百万桶（+8.6% 单季历史新高）——这不是恢复，是反弹。市场对中海油的悲观（H 股 P/E 仅 10.3x、AH 折价 35%）与公司的运营优秀形成鲜明反差。

几个研判要点

一、桶油成本 $27.9 是真正的护城河。对比全球同行：Exxon $40、Chevron $45、Shell $35、BP $40——只有沙特阿美 $10-15 比中海油低。这意味着：即便油价跌至 $40，中海油仍能保持盈利，而 Exxon/Chevron 已亏损。这是"全周期穿越能力"的核心。FY25 油价 -13.4%、产量 +7%、桶油成本 -2.2%——三者对冲后净利仅 -11.5%（如果是 Exxon 同样油价跌幅可能净利 -30%+）。

二、产量 7 连增 + 储量替代率 100%+ = 罕见的"成长型石油股"。FY18→FY25 产量 CAGR 约 6%，是全球石油大公司中唯一持续高速增产的（Exxon CAGR 1%、Chevron CAGR 3%、Shell 持平）。Q1 26 单季产量 205.1 百万桶，超过 FY25 全年 26%——证明产量增长动能强劲。圭亚那 Stabroek 区块继续爆发，国内渤海+南海持续发力。

三、AH 折价 35% + 4.34% 股息率 = 港股极致低估。H 股 HKD 28.98 vs A 股 ¥40.93（折算 HKD 44.6）——H 股相对 A 股折价 35%。同样资产，港股投资者花同样的钱可以多买 35% 的股份。配合 4.34% 股息率（vs 中国移动 6.4% / 中国电信 5.83% 略低，但产量增长更快），是"高股息 + 周期赔率"组合最佳的港股。

四、Q1 26 强势反弹打破"周期股"刻板印象。Q1 营收 +8.6%、净利 +7.1%、产量 +8.6%、销售费用 -86.8% 大降——这是标准的"量价齐升 + 成本控制"教科书案例。Q1 平均实现油价 $72.5（vs FY25 $66.47 反弹 +9%）。如果 FY26 油价维持在 $65-75 区间（OPEC+ 配额维持、需求恢复），FY26 净利可能 +5-10%。

五、12 个月目标价 HKD 35，上行 +21%。悲观 HKD 22（-24%，油价跌至 $50）、基准 HKD 35（+21%，油价 $65-75 + 产量 +5%）、乐观 HKD 48（+66%，油价 $80+ + 派息率升至 50%）。当前价 HKD 28.98 已位于"首仓"附近 —— 是合理建仓窗口。海图的判断：未来 3-5 年预期年化回报 8-15%（含股息），优于绝大多数大盘股。

风险提示

OPEC+ 增产油价跌至 $50 / 全球衰退能源需求骤降 / 美国对中海油新一轮制裁 / 电动车渗透率超预期 / 资源税大幅上调 / 储量减值——任一项都可能让股价回调 15-30%。但 ¥1,050 亿真实净现金 + 国资委 64.4% 控股 + 桶油成本 $27.9 全球最低让破产概率为零，每股净资产 HKD 20 提供下行支撑。
