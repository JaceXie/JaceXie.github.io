本季必看 · 两个"看穿"：名义 vs 有机、GAAP vs 核心

宝洁这一季的利润表有两个必须"看穿"的地方，看不穿就会把一份"平淡但有拐点"的季报读成"高增长"。

看穿一：名义 +7.4% 里有约 4 个百分点是汇率水分，真实有机增长只有 +3%。 很多人只看到"营收 +7.4%"就以为宝洁突然加速了。但拆开看——有机销售增长仅 +3%（量 +2%、价 +1%、组合中性），名义增速被美元贬值带来的约 +4pt 汇率顺风推高。这也是为什么恒定汇率核心 EPS 只有 $1.54，与去年同期持平：汇率给了利润，但经营层面的每股盈利实质上没增长。真正值得记一笔的不是名义营收，而是"量增 +2%"——这是一年来公司整体销量首次转正，5 大分部里 3 个量增，是这份季报里最有含金量的信号。

模块 1 · 公司概览与背景

The Procter & Gamble Company（宝洁，NYSE: PG），总部辛辛那提。1837 年创立（蜡烛与肥皂起家），1890 年注册为公司，自此连续 136 年不间断派息、连续 70 年提高股息（2026 年 4 月宣布，"股息之王"中的股息之王）。财年为 7 月 1 日至次年 6 月 30 日。

核心叙事：宝洁是全球最大的日用消费品公司，在约 70 个国家经营，拥有 21 个"十亿美元级"领导品牌——Tide（汰渍）/ Pampers（帮宝适）/ Gillette（吉列）/ Olay（玉兰油）/ Oral-B / Head & Shoulders（海飞丝）/ Dawn 等。它做的是最不性感、却最刚需的生意：洗衣液、纸尿裤、剃须刀、牙膏、洗发水。护城河来自品牌心智 + 规模成本 + 零售货架掌控力三位一体，把"每天都要买的小东西"做成一台 49.5% 毛利率、22% 核心营业利润率、连续 70 年增息的现金机器。

五大业务分部（管理层报告口径）：

  • 织物与家庭护理（Fabric & Home Care）——最大分部，Q3 净销售 $7.40B（占 34%），Tide / Ariel / Dawn / Febreze，量价基本盘
  • 婴儿、女性与家庭护理（Baby, Feminine & Family Care）——$5.06B，Pampers / Always / Bounty / Charmin
  • 美容（Beauty）——$3.87B，本季有机 +7% 领涨，Olay / SK-II / Head & Shoulders / Pantene
  • 健康护理（Health Care）——$3.07B，Oral-B / Crest / Vicks / 个人健康
  • 男士修容（Grooming）——$1.61B，Gillette / Venus，利润率最高（净利率 20.6%）

管理层交接：Jon Moeller 于 2026 年 1 月 1 日卸任 CEO、转任执行董事长（Executive Chairman），Shailesh Jejurikar 接任总裁兼 CEO。故 Q1 FY2026 电话会由 Moeller 主持（其最后一季），Q2/Q3 FY2026 由新任 CEO Jejurikar 主持——这是理解本财年治理连续性的关键背景。

能力圈检验：日用消费品收费"必需品"生意极其清晰（看得懂的顶级好生意，一句话能说清）。两块需要盯住的慢变量：(1) 品类成熟 + 私有品牌（自有品牌）在通胀后期的份额侵蚀；(2) GLP-1 减重药对零食/部分个护品类需求的长期外溢影响、以及关税对成本端的持续冲击。这些不改变宝洁"卖得动"的本质，但决定它是低个位数还是中个位数增长。

模块 2 · 管理层评估
B+

Shailesh Jejurikar · 总裁兼 CEO（2026-01 至今）

宝洁 30 余年老将，曾任 COO，长期主导织物与家庭护理这一最大分部与"Supply Chain 3.0"供应链变革。2026 年 1 月接替 Moeller 出任 CEO。上任后两季（Q2/Q3 FY2026）延续"聚焦日用刚需品类 + 整合增长战略 + 生产率驱动"的既定路线，本季主动"加速投资以维持消费者动能"——在需求疲软期选择短期牺牲利润率换取长期份额。海图判断：路线稳健、内部提拔、无战略突变，但作为新任 CEO 执行记录尚短，且接手的是一个增长天花板明确、关税逆风加大的成熟盘，需再观察两三个财年才能定评。

A-

资本配置纪律 · "股息之王"的教科书

连续 70 年提高股息（2026-04 宣布）、连续 136 年不间断派息（自 1890 年注册）——这是全市场最稀有的资本返还记录之一，历经大萧条、二战、金融危机、疫情从未间断。
持续回购缩股：过去 3 财年回购合计 $188.6 亿，摊薄加权股数从 FY2023 的 24.84 亿降至 Q3 FY2026 季度口径的 24.17 亿。FY2026 计划分红约 $100 亿 + 回购约 $50 亿。
两个需留意点：① 回购多入库存股（美股常态，部分用于对冲股权激励），缩股力度温和（3 年累计仅约 -1.2%）；② 公司长期维持约 $25B 净负债、用发债支撑资本返还——对 AA- 评级、FCF 极稳的宝洁合理，但要清楚这不是"净现金公司"。

长期主义测试：✅ 宝洁管理层始终以"品牌建设 + 生产率 + 组合优化"的长期复利为主线，2025-06 宣布"投资组合与生产率计划（Supply Chain 3.0）"精简组合与组织，是典型的长期视角而非短期财报博弈。本季"加速投资维持消费者动能"、宁可 EPS 落区间下沿也要保份额，正是主人翁式取舍。坦诚度：电话会披露详尽（关税税后拖累从预期上调至约 $400M、毛利率 150bps 逐项拆解、明确指引"偏区间下沿"都主动说明），不粉饰。利益绑定：管理层持股比例不高（成熟大盘股常态），薪酬与有机销售、核心 EPS、现金回报强挂钩。

模块 3 · 商业模式深度解析

海图"一句话测试"：宝洁靠 21 个头部品牌，把牙膏、洗衣液、纸尿裤、剃须刀这些"每天都要用、用完就要买"的日用品，以品牌溢价 + 规模成本卖到全球 70 国的每一个货架，赚的是"高频刚需 + 心智垄断"的稳定过路费。

盈利飞轮：品牌广告投入 → 消费者心智占领 → 零售商必须进货（不进货货架就缺爆款）→ 掌控货架与议价权 → 规模摊薄采购/生产/物流/广告成本 → 更高毛利 → 再投入品牌与创新。这是一个自我强化的"重广告 + 重规模"循环，新进入者难以在同一品类里同时复制品牌心智与全球分销。

  • 规模效应：极强——全球生产/物流/广告网络边际成本低，生产率改善本季贡献毛利率 +210bps，部分抵消组合与关税拖累
模块 4 · 经济护城河分析（5 维）
1. 无形资产 / 品牌
宽

21 个十亿美元品牌 + 一个多世纪的广告心智沉淀，Tide/Pampers/Gillette 是各自品类的代名词。这是宝洁最核心的护城河。趋势：稳定（私有品牌是慢性侵蚀）。

2. 规模 / 成本优势
宽

全球最大日化采购/生产/分销体系，边际成本低。本季生产率贡献毛利率 +210bps。Supply Chain 3.0 持续挖潜。趋势：稳定/加宽。

3. 转换成本
窄

消费者随时可换牌子，切换成本几乎为零；靠品牌忠诚与习惯形成弱黏性。这是日化生意的天然短板。趋势：稳定。

4. 网络效应
窄 / 无

日用品本身无网络效应；唯一近似的是"零售货架掌控 + 供应链规模"形成的分销飞轮，让对手难以同时铺满全球货架。趋势：稳定。

5. 有效规模
中-宽

成熟日化品类只能容纳少数全球巨头（宝洁/联合利华/高露洁/金佰利），加上货架与广告门槛，新全球玩家几无空间。趋势：稳定。

10 年后护城河会更宽还是更窄？ 品牌 + 规模的核心护城河仍宽且持久，但两个慢变量决定宽窄边际：(1) 私有品牌 / 自有品牌——在通胀后期消费者预算收紧时，零售商自有品牌会蚕食中低端份额，宝洁靠创新与品牌溢价对冲；(2) 需求结构变化——GLP-1 减重药、人口结构、新兴市场消费升级等，会重塑部分品类的量增天花板。宝洁的应对是"聚焦刚需大品类 + 创新驱动量增 + 生产率省成本"，本季量增 +2% 拐点正是这套打法初见成效。结论：护城河宽而稳，但不是加宽型——它是一台守成的复利机器，不是扩张型成长股。

定价权：品牌带来溢价，但受消费者价格敏感度与私有品牌天花板压制。本季价格贡献仅 +1%，说明当前定价权处于阶段性温和区间。

5.5 所有者盈余（价值投资口径 · TTM 估算）

  3. 大额商誉/无形减值——概率 8% · 历史上曾对吉列计提减值 · GAAP 利润一次性冲击（不影响现金，但打击信心）· 股价短期承压

下行支撑：世界级品牌矩阵 + 规模护城河 + 连续 70 年增息 + FCF ~$14.5B + ~30% ROE 构成质量底。$130-135 是较硬的估值底（52 周低 $137.62 附近 + Forward P/E ~18x 下限 + 股息率升至 ~3.2% 提供支撑）。宝洁的"底"比多数股票稳，因为防御属性 + 股息之王地位在市场恐慌时反而吸引避险资金。

模块 12 · 股东回报分析

宝洁是"股息之王"的代名词——连续 70 年增息、136 年不间断派息。但要把"给了多少 → 给的方式好不好 → 能不能继续给"三个问题拆到可验证的颗粒度，尤其是回购的含金量。

Trailing Shareholder Yield ≈ FY2025 返还 $16.37B / 市值 $342B ≈ 4.8%（其中股息 ~2.9% + 回购 ~1.9%）。与"低股息大回购"的科技股不同，宝洁是"高股息 + 温和回购"的经典消费股结构——股息是主菜、回购是辅。连续 70 年增息（2026-04 宣布）是全市场最稀有的资本返还记录之一。

12.2 给的方式好不好？

  • 股息含金量最高：连续 70 年增息 + 136 年不间断派息，穿越所有周期从未削减——这是宝洁股东回报的核心，含金量无可挑剔
  • 回购含金量打折：美股回购多入库存股（treasury stock），部分用于对冲股权激励稀释，而非全额注销。摊薄加权股数 3 年趋势：FY2023 24.84 亿 → FY2024 24.72 亿 → FY2025 24.54 亿 → Q3 FY2026 季度口径 24.17 亿，3 年累计仅降约 1.2%——缩股力度温和，回购更多是"稳住股数 + 对冲 SBC"，而非大力增厚每股价值
  • 回购择时中性：宝洁常年平滑回购，不刻意择时；FY2026 计划回购约 $50 亿（较 FY2023 的 $73.5 亿收缩），显示管理层在关税逆风期偏保守、优先保股息与投资

12.3 能不能继续给、给多少？

  • 股息可持续性极强：股息 / 核心净利派息率约 60%，股息 / FCF 约 65-70%，留有安全垫；连续 70 年增息记录本身就是最强的可持续性背书
  • 未来指引明确：FY2026 计划分红约 $100 亿 + 回购约 $50 亿（合计约 $150 亿）· 资本返还优先级清晰：股息优先、投资次之、回购兜底
  • (股息 + 回购) / FCF 覆盖度：FY2026 计划返还 ~$150 亿 / 预期 FCF ~$14-15B ≈ 100% 出头——略超 FCF，靠稳定现金流 + 适度杠杆支撑，对 AA- 评级、FCF 极稳的宝洁完全可持续
  • 借债回购检验：宝洁长期维持约 $25B 净负债做资本结构优化，但净负债本季环比基本持平（-$24.95B → -$24.72B），并非"因回购持续加杠杆"——回购规模已主动收缩以匹配 FCF

模块小结：积极且高含金量（股息端），回购端含金量温和打折——连续 70 年增息 + 136 年派息的股息记录是全市场顶级、无可挑剔；但美股回购多入库存股、3 年缩股仅约 1.2%，回购的"增厚每股价值"作用有限。整体是一台以股息为核心的稳健资本返还机器，可持续性极强，唯一遗憾是回购力度温和、含金量不及港股强制注销型。

夜读手记 · 1150 字

价值投资里有一类生意，无聊到让人打哈欠，却能安安静静把股息发一辈子——宝洁就是。它不做惊艳的产品，只做你每天都要用的牙膏、洗衣液、剃须刀和纸尿裤，然后连续 70 年提高股息、连续 136 年不间断派息。Q3 营收 +7.4% 看着不错，可拆开一看，有约 4 个百分点是汇率顺风，真实有机增长只有 3%。好消息藏在别处：全公司销量时隔一年首次转正 +2%，这才是拐点。

宝洁是全球日用消费品之王——21 个十亿美元品牌铺满 70 国货架，靠"品牌 + 规模"双护城河，把最普通的日化用品做成一台连续 70 年增息的现金机器。Q3 FY2026 净销售 $21.24B（名义 +7.4%、有机 +3%）· 核心 EPS $1.59（+3%）· 毛利率 49.5%（-150bps）· ROE ~30% · FCF ~$14.5B。这是商业模式质量位居全球前列、但增长天花板明确的稳态复利机器。

几个研判要点

一、增长的"含汇率水分"要看穿。 Q3 名义 +7.4% 很漂亮，但其中约 4pt 来自美元贬值的汇率顺风，剔除后有机销售仅 +3%（量 +2、价 +1），恒定汇率核心 EPS 只有 $1.54、与去年持平。真正值得记一笔的是"量增 +2%"——这是一年来公司整体销量首次转正，5 大分部里 3 个量增，Beauty 靠创新领涨有机 +7%。对一家成熟到极致的巨头，量的拐点比名义增速更有含金量。

二、毛利率被三座大山压了 150bps。 报告毛利率降至 49.5%，拆开是不利组合 -180bps + 再投资 -100bps + 关税 -50bps，靠生产率 +210bps 部分抵消。管理层选择"加速投资维持消费者动能"，短期牺牲利润率换长期份额——这是防御龙头在需求疲软期的典型打法，也是全年 EPS 指引"偏区间下沿"的原因。

三、关税是今年最实在的逆风。 管理层把 FY2026 关税税后拖累上调到约 $400M，叠加大宗商品 $150M、利息税收 $250M，合计每股逆风约 $0.25，靠 $200M 汇率顺风只能对冲一部分。这不是护城河问题，是外部成本冲击，但足以让核心 EPS 卡在 $6.83-7.09 区间的下沿。

四、别把宝洁当"现金堡垒"——它是净负债。 很多人以为消费之王满手现金，其实它现金 $12.3B、有息负债 $37.0B，真实净负债约 -$24.7B，长期维持约 $25B 净杠杆，用 AA- 投资级信用支撑分红回购。对 FCF 极稳的公司，这种适度杠杆合理，但"净现金"的滤镜要摘掉。

五、股息之王的含金量在"能不能继续给"。 过去 3 年宝洁回馈股东 $470 亿（分红 $282 亿 + 回购 $189 亿），连续 70 年增息。FY2026 计划分红约 $100 亿 + 回购约 $50 亿，(分红+回购)/FCF 覆盖度约 100% 出头，靠稳定 FCF 支撑。唯一打折项：美股回购多入库存股，摊薄股数 3 年仅降约 1.2%，缩股温和——分红才是宝洁股东回报的主菜。

海图研判

评级：持有观望（顶级防御性股息之王 + 品牌规模双护城河 + 连续 70 年增息 + 量增拐点初现的组合，对垒关税税后 $400M 逆风 + 毛利率 -150bps + 有机增速仅 3% + Forward P/E 20.7x 无安全边际的成本与估值压力）。独立估值中位数约 $150，当前 $147 折价仅约 2%，远不足 25% 安全边际。12 个月概率加权目标价 $150（悲观 $128 / 基准 $152 / 乐观 $168），叠加 2.9% 股息 = 总回报约 5%——稳健但不激动。

操作建议：当前 $147 不在合理建仓窗口。机械首仓 $120（估值中位 ×80%，对应约 17x forward）、二仓 $105、三仓 $90 等深度回调再出手。止盈三档 $165 / $180 / $195 各减 25%，最后 25% 长期持有吃股息。建议总仓位 3-4%（防御压舱石 · 回调时分批建，不追高）。持有周期 5-10 年。关键纪律：现有持仓者继续让它复利吃股息，新买入者必须等价格给出安全边际——好生意也要好价格。

风险提示

关税持续侵蚀 / 毛利率承压 / 有机增速回落至 0-2% / 私有品牌与 GLP-1 对品类的慢侵蚀 / 满估值下的多重压缩——任一项都可能让股价回到 $130 下方。但 21 个头部品牌 + 规模成本护城河 + 股息之王地位构成质量底，$130-135（52 周低附近）是相对硬的支撑，股息率升至约 3.2% 时会吸引避险资金。宝洁的"底"比多数股票稳，防御属性在市场恐慌时反而是它的优势。

关键叙事："全球日用消费品之王 + 品牌规模双护城河 + 连续 70 年增息 + 量增拐点初现"的顶级防御资产，对垒"关税税后 $400M 逆风 + 毛利率 -150bps + 有机增速仅 3% + Forward P/E 20.7x 无安全边际"的成本与估值压力。宝洁不是给追求便宜或高增长的人——它是给愿意在回调时耐心收集、然后把股息一年年再投入、让复利慢慢滚雪球的长期持有者。下次催化剂：2026-07-29 FY2026 Q4 暨全年财报。
