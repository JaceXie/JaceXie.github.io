# Miniso 名创优品（HKEX: 9896 / NYSE: MNSO）Q1 2026 · 海图夜读

2026-05-26 Q1 财报，名创优品的标题数字是 GAAP 净利 +199.7%。一眼望去是涅槃；夜读财报的人会先翻到调整口径——剔除 MiniMax IPO 一次性 ¥8.75 亿、永辉权益法 +¥0.78 亿、FX 亏损 ¥0.83 亿，调整后剔 FX 净利只有 ¥6.33 亿、+8.1%。两个数字相差 ¥6 亿，全在"非经常项"和"汇兑"里。真正的主业增速是 +8%，不戏剧、但健康——同时还有一个新红旗在浮起。

名创是一家"主业稳健 + GAAP 被双层非经常项扭曲"的全球生活方式品牌。Q1 总营收 ¥56.88 亿、+28.5%、超指引上限；MINISO 中国 +29.6% **第 5 季加速**、海外 +21.9%、TOP TOY +51.4%、海外门店净增 34 家、TOP TOY 净增 21 家——经营层面延续 FY2025 的强势。但创始人叶国富 2024-09 用 ¥62.7 亿（其中 ¥40 亿借款）增持永辉超市 29.4% 的那道"是非题"，在 Q1 出现了第一个肯定的信号：权益法从 Q4 -¥5.5 亿反转为 +¥0.78 亿——重整开始兑现，但才一个季度，远未盖棺。

## 几个研判要点

**一、必须看穿 GAAP 利润的双重扭曲。** FY2025 GAAP 净利被永辉权益法亏损向下扭曲了 ¥8 亿；Q1 2026 又被 MiniMax 公允价值收益向上扭曲了 ¥8.75 亿；永辉本季的 +¥0.78 亿和 FX 的 -¥0.83 亿差不多互相抵消。把这些都剥掉，名创真实的主业增速是**调整后剔 FX 净利 +8.1%（Q1）/ +6.5%（FY25 全年）**——稳健，但绝不戏剧。

**二、主业是一门继续在变好的好生意。** 43.3% 毛利率、14.7% 调整剔 FX 营业利润率、调整 ROE 27%、OCF/净利 88.9%——消费股里少有的"高质量增长"组合。Q1 营收 +28.5% 超指引上限，中国同店 +29.6% 是连续**第 5 季加速**，海外门店净增 34 家、TOP TOY +51%。护城河虽窄但持续加宽——50+ 全球 IP 矩阵 + 8,565 家全球门店反向供应链。

**三、新红旗：销售费用 +44% 远超营收 +28.5%。** 这是 Q1 财报里最值得警惕的细节。销售费用 ¥14.71 亿，毛利率从 44.2% 滑到 43.3%（-90bps），销售费用率上升 3+ ppts。海外加速扩张 + IP 联名营销 + 数字化投入是边际承压主因。**管理层没给 FY2026 数字指引**，可能就是对销售费用率回稳的能见度不够强。后续 2-3 季能否回到 25% 内，是从"调整 +8%"走向"调整 +10-15%"的关键变量。

**四、永辉拐点信号——一上一下两道未盖棺的不确定性。** 永辉从 FY25 拖累 ¥8.1 亿 → Q1 2026 反转为 +¥0.78 亿，**重整开始兑现财务效应**，叶国富的"亲自下场"的胖东来式重塑出现第一个肯定信号。若 2027 前兑现到 +¥10 亿 / 年，单这一项就能让 GAAP 利润从 ¥12 亿涨到 ¥30+ 亿。但若销售费用率持续走高、海外扩张吃力，主业的"调整 +8%"可能向 +5% 退化——一上一下，对 SOTP 估值的影响在 ±20%。

**五、12 个月目标价 HKD 35，上行 +35%。** 悲观 HKD 24（-7%，销售费用持续走高 + 永辉重整放缓）、基准 HKD 35（+35%，主业 +25% 营收 + 调整净利 +10% + 永辉持续小幅贡献）、乐观 HKD 42（+62%，销售费用回稳 + 永辉明显兑现 + TOP TOY IPO）。**当前 HKD 25.96 已跌破首仓 HKD 28，进入二仓附近**——市场对"调整 +8% / 销售费用 +44% / 没给 FY26 指引"做出短期失望，反而打开了价值买点。

## 风险提示

1. **销售费用率持续走高**（Q1 新红旗）→ 概率 30%，调整净利增速从 +8% 退化到 +5%，股价跌至 HKD 22-24
2. **永辉重整反复 + 大额减值** → 概率 20%，¥55亿账面值减值，股价跌至 HKD 22
3. **中国消费深度衰退** → 概率 15%，主业增速腰斩
4. **TOP TOY 拆分搁浅 + 潮玩降温** → 概率 10%，第二曲线失速
5. **MiniMax 大幅减值** → 概率 15%，公允价值反向波动，GAAP 利润短期承压
6. **海外地缘 + 关税冲击** → 中长期估值压制

但 ¥104 亿净资产 + 调整 ROE 27% + FCF 持续为正 + 6.5% 股东总回报率，让 HKD 22-25 成为较硬的估值底。

关键叙事：**"中国零售出海龙头 + 调整剔 FX P/E 10.5x + 中国同店第 5 季加速 + 股东总回报率 6.5% + 距 52 周低 +2%"的组合，对垒"永辉大额收购悬而未决 + GAAP 利润被双重扭曲 + 销售费用 +44% 新红旗"的隐忧**。在多数优质消费品估值不菲的当下，名创是一笔"好生意被永辉阴云 + 销售费用新红旗双重压制 + 资本返还慷慨垫底"的标的——不是给只看 GAAP 标题数字的人，而是给愿意看穿调整剔 FX 净利、追踪销售费用率走势、理解永辉这盘牌局赔率的投资者。下次催化剂：2026-08（预）Q2 2026 财报 + 永辉 Q2 损益 + TOP TOY IPO 进展。
