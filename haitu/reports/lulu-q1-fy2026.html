本季必看 · +4% 营收表象下的 -38% 利润崩塌

Lululemon Q1 是"营收增长的表象掩盖利润崩塌的实质"——+4% 营收里藏着两个坏消息。

坏消息一：增长质量差。 +4% 报告营收里，+2 个百分点是人民币升值的汇率顺风，恒定汇率营收仅 +2%，全球同店 comps 恒定汇率 -2%（负）。更关键：美洲（占 66% 营收）营收 -3%、同店 -5%/-6%——核心市场首次转负，管理层指引 Q2 北美同店进一步恶化至"低双位数"下滑。仅靠中国大陆（+30%/comps +20%）与其他地区（+13%）撑场，但体量不足以对冲北美。

坏消息二：关税吞噬毛利。 毛利率 -410bps 至 54.2%，COGS 同比 +14.7% 远超营收 +4.3%。桥接：产品毛利 -270bps（其中 关税/折扣/存货拨备 -330bps，汇率 +60bps）+ 固定成本去杠杆 -140bps。叠加 SG&A 去杠杆 310bps（含"代理权争夺战"费用），营业利润率暴跌 730bps 至 11.2%，净利 -38%。

结果：下调全年指引——FY2026 营收 $11.0-11.15B（同比 -1% 至 0%）、EPS $10.95-11.15（较 FY2025 的 $13.26 下滑 16-17%）。但市场已经用"股价一年 -52%"提前定价了这份坏消息——当前 Forward P/E ~10.5x 是 LULU 上市以来最低区间之一。这是一只"跌落的成长股"，问题从"贵不贵"变成了"跌够了没"。

模块 1 · 公司概览与背景

Lululemon Athletica Inc.（NASDAQ: LULU，2007 IPO），总部加拿大温哥华，特拉华注册。1998 年由 Chip Wilson 创立，全球高端瑜伽/运动休闲（athleisure）服饰龙头——以"科技面料 + 社群文化 + 直营模式"打造高端品牌溢价。财年为 2 月前后结束的 52/53 周制。

核心叙事：Lululemon 是一门54-56% 毛利率、30% ROE、DTC 直营为主的高端品牌生意——不打折的定价权 + 女性瑜伽起家延伸到男装/鞋履/配件。816 家直营门店 + 强电商。FY2026 营收指引约 $11.1B。但本季暴露了增长引擎的转换困境：北美（66% 营收）品牌热度见顶、同店转负，增长全靠中国大陆（+30%）与国际（+13%）。叠加美国关税吞噬毛利、管理层动荡（临时联席 CEO + 代理权争夺），FY2026 是 Lululemon 上市以来首次营收零/负增长 + 盈利明显收缩的一年。

治理异动（本季关键新变量）：新闻稿署名为 Meghan Frank, Interim Co-CEO（临时联席 CEO），叠加"代理权争夺战（proxy contest）"相关费用——指向管理层过渡 + 股东行动主义压力，是本季相较此前的重大治理变化，需持续跟踪。

能力圈检验：品牌服饰生意相对清晰（看得懂）。但两块不确定：(1) 品牌热度是"周期性回调"还是"结构性见顶"——美国 athleisure 竞争加剧（Alo、Vuori 等新锐蚕食），需数季度验证；(2) 关税最终税率与消化能力，管理层假设 Q2 起增量关税 10%（从此前 20% 下调），不确定性仍高。

模块 2 · 管理层评估
B

Meghan Frank · 临时联席 CEO（原 CFO）· 管理层过渡期

本季新闻稿由临时联席 CEO 署名，叠加"代理权争夺战"费用——Lululemon 正处于管理层过渡 + 股东行动主义压力期，这是相较上次分析（Calvin McDonald 稳定掌舵）的重大治理变化。过渡期的战略执行力与新品把控能力存在不确定性。管理层本季承认"美国负面品牌舆情打击客流、部分新品不及预期"，坦诚但反映品牌运营出现问题。海图判断：治理动荡叠加基本面走弱，管理层维度本季从此前的 A- 下调至 B。

A-

资本配置纪律 · 零负债 + 持续回购（净现金堡垒）

Lululemon 一贯零有息负债 + 净现金 $1.51B（短借/长债/可转债均 $0，经两处独立核对）。资本返还 100% 通过回购（无股息）：本季回购 $358M（220 万股，均价 ~$163），剩余授权约 $1.0B，管理层称 FY2026 回购力度与去年持平。在股价腰斩、Forward P/E 10x 的低位持续回购，择时正确——但本季回购额 > 净利 + FCF，动用了账上现金（从年初 $1.81B 降至 $1.51B），需留意持续性。

长期主义测试：中——中国 +30% 增长证明国际化战略仍有效，但美国核心市场的品牌运营出现问题（新品乏力 + 舆情），管理层过渡期能否稳住品牌热度是关键考验。自救措施：2026 新品渗透率目标从 30% 提到 35%、快反 Chase 补货量提高 20%——方向对，但见效需时间。

模块 4 · 经济护城河分析（5 维）
1. 无形资产/品牌
中-宽（趋弱）

高端瑜伽品牌 + 社群文化曾是核心溢价。但美国品牌热度见顶、舆情负面、新锐（Alo/Vuori）蚕食——护城河正被侵蚀。中国仍强。趋势：美国侵蚀、中国加宽。

2. 转换成本
窄

服饰无技术转换成本，靠品牌认同 + 面料体验形成软黏性。竞争加剧削弱粘性。趋势：略侵蚀。

3. 成本优势/DTC
中

直营不打折 + 高端定价 = 54-56% 毛利率行业领先。但关税 + 去杠杆本季压毛利 -410bps。趋势：关税压制。

4. 有效规模
窄

运动服市场分散、竞争充分（Nike/Adidas/Alo/Vuori/lululemon 多强并存）。趋势：竞争加剧。

5. 网络效应
无

服饰无网络效应。社群活动是营销而非网络壁垒。趋势：N/A。

10 年后护城河会更宽还是更窄？ 美国偏窄、国际偏宽——Lululemon 的品牌护城河在美国正受结构性考验（新锐竞争 + 热度见顶），但在中国及国际市场仍在扩张。核心争议：美国是"周期性品牌回调"（可修复）还是"结构性见顶"（不可逆）——这决定了当前 10x Forward P/E 是"便宜的好公司"还是"价值陷阱"。中国 +30% 提供了对冲，但需美国至少企稳。

定价权：曾极强（不打折），本季因品牌热度下降 + 关税被迫在折扣/提价间权衡，定价权阶段性受损。

5.4 所有者盈余（价值投资口径 · FY2026 估）

所有者盈余 ≈ 净利 + D&A − 维护性 Capex ± 营运资金

FY2026 净利指引约 $1.27B（EPS $11 × 115M 股）· D&A 适中 · Capex $700-720M（含扩店/配送中心扩张性投入，维护性约一半）。

FY2026 所有者盈余（保守）≈ 净利 $1.27B − 扩张性 Capex 约 $0.35B + D&A ≈ ~$1.0-1.1B。

所有者盈余收益率 = ~$1.05B / $13.8B 市值 ≈ 7.6% · 剔除净现金后核心 = $1.05B / ($13.8B − $1.5B) ≈ 8.5%——对一个 54% 毛利率、30% ROE、零负债的品牌，若美国企稳、盈利不再恶化，8.5% 的核心所有者盈余收益率是有吸引力的估值。前提是美国品牌拐点出现。

  • 无股息政策：Lululemon 从不派息，资本返还 100% 回购 · 对成长股合理

  • 周期择时：当前股价历史低位、Forward P/E 10x，是历史最佳回购时机之一 · 管理层在低位加大回购是正确的逆向操作

关键叙事："净现金 $1.5B + 54% 毛利率 + 30% ROE + 中国 +30% 引擎 + Forward P/E 10x 历史最低 + 12% 回购收益率"的品牌质量与估值安全边际，对垒"美国同店 -6% 结构性走弱 + 关税吞噬毛利 + 临时 CEO/代理权争夺 + 品牌热度见顶疑虑"的真实恶化。Lululemon 不是给追求确定性的人——是给相信"美国能企稳、中国能复利、品牌未死"、愿意在腰斩后逆向分批建仓的耐心价值投资者。下次催化剂：2026-09 Q2 FY2026 财报，关注北美同店是否止跌。
