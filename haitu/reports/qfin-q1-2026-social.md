# 奇富科技 Qfin Holdings（NASDAQ: QFIN）Q1 2026 · 海图夜读

价值投资里最难的，不是发现一只 P/E 2 倍的股票，而是判断它是"被错杀的好公司"还是"逐渐熄灭的烟蒂"。奇富科技 Q1 2026 营收 -16.6%、净利 -51%、EPS -60%，FY26 指引 -34%，股价从 $46 跌到 $12（-74%）。但同一份财报里，管理层在用真金白银做着相反的事——FY25 退还股东 $880M（占净利 103%）、FY24-FY26 累计 $1.5B+ 资本返还、摊薄股数 3 年缩了 22%。

奇富是一家"中介工厂"——把中国持牌金融机构的资金，撮合到小微企业主 + 个人散户的借款需求上。Non-GAAP 净利率 24%、ROE 26%——商业模式本身没问题。问题在三件事的合力：中国消费信贷监管收紧、经济周期向下、行业格局重塑。

## 几个研判要点

**一、P/E 2 倍是"价值陷阱"还是"格雷厄姆式机会"？** 当前 P/E TTM ~2.1x、Forward 2.9x、P/B 0.5x、股息率 12.2%、**净现金占市值 75%、核心业务 P/E 仅 0.7x（剔净现金后）**——这是教科书级别的深度价值。但市场不傻——这么便宜的原因是"业务在结构性萎缩"。FY26 EPS 指引 $4.17（-34% YoY）已经印证了下滑趋势的延续。**这不是错杀，是真实风险定价**。

**二、管理层用真金白银证明"股价远低于内在价值"。** FY24-FY26 累计 $1.5B+ 股东回报——含 $1,050M 回购 + $399M 转债注销 + $305M 股息。**摊薄股数 3 年缩 22%**——留下来的股东每股权益持续增厚。FY25 派出率 103% 净利——已经在动用现金储备。这种"业务承压时用资本返还逆向加码"的纪律，在中概股里极罕见。海图判断：管理层不是在做营销，是在做正确的事。

**三、护城河窄 + 终局不确定，是为什么不能重仓。** 助贷行业的核心问题是**护城河本身在被结构性削弱**——监管让平台利润率持续被压、银行系互联网平台直接获客、AI 时代客户直连金融机构……奇富的"龙头位置"不能保证利润复苏。10 年后这门生意可能比现在更小。**这是不能用"等待业务回到 2023 年高点"的逻辑来投资的**。

**四、12% 股息 + 22% 缩股本 = 真实回报兜底。** 即使业务再下滑，股东也能拿到 12% 股息 + 持续回购增厚每股价值——按 FY26 指引 EPS $4.17，2-3 年内回购 + 分红可能消化 30-40% 净利。**这意味着即使股价不涨，留下来的股东也能拿到年 12-15% 的复合回报**。这是格雷厄姆"用低价买现金机器"的当代版本。

**五、12 个月目标价 $17，上行 +42% + 12% 股息 = 总回报 ~54%。** 悲观 $9（-25%，监管 / 退市 / 业务再降 50%）、基准 $17（+42%，业务延续指引 + 估值小修复）、乐观 $25（+109%，业务企稳 + 估值至 P/E 4x）。概率加权 $17。**当前 $11.93 已远低于机械首仓 $15.2**——是深度价值的标准买点。

## 海图研判

**评级：有条件买入**（P/E 2x + 净现金占市值 75% + 12% 股息 + FY25 退还 103% 净利 + 缩股本 22% 的极致组合，但业务持续萎缩 + 监管不确定 + ADR 残留风险）

12 个月概率加权目标价：**$17**（+42%），叠加 12% 股息 = 总回报 ~54%

- 乐观（25%）：$25 — 业务企稳 + 估值修复至 P/E 4x + 资本返还常态化
- 基准（50%）：$17 — 业务延续 FY26 指引 -34% + 估值小幅修复至 P/E 3x
- 悲观（25%）：$9 — 监管再收紧 / ADR 退市 / 业务再降 50%

**操作建议**（独立估值中位数 $17，加权公允 $17）：

当前价 $11.93 已远低于机械首仓 $15.2，是深度价值的标准买点：

- 首仓 **$15.2**（估值中位数 × 80%，距现价 +27%，已远过——可建仓）
- 二仓 **$13.3**（× 70%，距现价 +11%）
- 三仓 **$11.4**（× 60%，距现价 -4%，接近极端机会）

止盈三档：**$22 / $28 / $35**（每档减仓 25%，最后 25% 视业务恢复定）

建议总仓位 **1-3%**（小仓位投机性深度价值 · 反映价值陷阱 + 监管 + 业务萎缩三重风险）。这是一笔"现金机器 + 深度价值"标的——不是给追求成长的人，而是给愿意"用低价买现金回流机器"的格雷厄姆式投资者。**持有周期 1-3 年**，目标是"用股息 + 回购增厚每股价值穿越业务谷底"。关键纪律：不要因为便宜而重仓——业务持续恶化的尾部风险是真实的。

## 风险提示

1. **中国消费信贷监管再收紧（助贷新规严格落地）** → 概率 25%，股价跌至 $7-9
2. **ADR 退市风险升级** → 概率 10%，中概共性问题
3. **业务再降 50%+（中国经济深度衰退）** → 概率 15%，FY26 EPS 跌至 $2-3
4. **360 集团关联流量断裂** → 概率 5%，关联交易风险
5. **资产质量恶化 / D90+ 突破 5%** → 信用周期尾部风险
6. **管理层资本返还节奏放缓** → 估值底失去支撑

但净现金 $11.7 亿 + Non-GAAP 净利率 24% + 12% 股息率构成**硬底**，$7-9 是较硬的估值底（净现金 + 30% 业务残值）。

关键叙事：**"P/E 2x + P/B 0.5x + 12% 股息 + FY25 退还 103% 净利 + 摊薄股数 3 年缩 22%"的极致格雷厄姆式深度价值，对垒"FY25 净利首次下滑 + Q1 2026 -51% + FY26 指引 -34% + 中国消费信贷监管 + 业务结构性萎缩"的真实风险**。奇富不是一笔好成长股，是一只"现金机器 + 价值陷阱"组合——给愿意承受"留下来的股东持续变富，但市场可能永远不重估"的耐心投资者。下次催化剂：2026-08 Q2 2026 财报。
