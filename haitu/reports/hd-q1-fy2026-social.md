价值投资里有一种熟悉的两难——公司足够好，但宏观逆风与并不便宜的价格，让人下不去手。家得宝就是这样一台机器：全美最大的家居改善零售商，2361 家门店 + Pro 专业客户生态 + 25.4% 的 ROIC，可它的引擎正被高利率死死压住。房屋成交低迷、大额装修递延，Q1 可比销售只有 +0.6%，每股收益还在同比下滑。业绩挑不出大错，问题在于：这台机器现在既没顺风，也不便宜。

家得宝是"给专业施工队和 DIY 业主供货的家居改善收费站"——赚的是全美存量住宅每一次翻新、维修、扩建的钱。Q1 FY2026 净销售 $417.7 亿（+4.8%）· 可比销售 +0.6%（美国 +0.4%）· GAAP EPS $3.30（-4.2%）· 调整后 EPS $3.43（-3.7%）· 营业利润率降至 11.9%（上年 12.9%）。增长几乎全来自并购，内生需求接近停滞。

【几个研判要点】

**一、4.8% 的营收增长，几乎全是并购买来的。** 这 +4.8% 里，可比销售只贡献 +0.6%，其余大部分来自 SRS（约 $182 亿收购的专业建材分销）和 GMS 的并表，本季 GMS 约贡献 $13 亿。并购同时把毛利率从 33.8% 拉低到 33.0%（降约 75bp，GMS 是低毛利分销），营业利润率从 12.9% 压到 11.9%。家得宝在用并购买营收增长，代价是利润率结构性下移、每股收益同比下滑。这不是坏事，但要清楚：报表上的"增长"含金量，取决于 Pro 生态能否兑现协同。

**二、需求被利率锁住，没有明确的加速催化剂。** 逐月可比暴露了真实节奏——2 月 +0.7%、3 月 +2.0%、4 月 -0.5%。换厨房、翻新浴室这类大额可选装修仍被高利率和房屋低换手压制，大件商品可比只有 +0.8%。亮点是 Pro（专业客户）可比转正并跑赢 DIY、线上 +10% 以上连续第 4 季双位数。家得宝的困境不是自己做错了什么，而是它绑定的房地产周期还没转向——利率一天不下来，装修需求就一天回不来。

**三、别把"净现金"安在它头上——它是高杠杆净负债。** 很多人以为龙头零售商都是现金堡垒，家得宝恰恰相反。现金只有 $16 亿，有息负债却高达 $535 亿（短债 $35 亿 + 长债当期 $52 亿 + 长债 $448 亿），真实净负债 -$519 亿；算上经营租赁负债更接近 -$616 亿。股东权益仅 $139 亿——常年大额回购把账面净资产打得很薄，SRS/GMS 并购进一步推高杠杆。这是一家高杠杆公司，不是零负债神话。好在利息覆盖约 8 倍、FCF 强劲，杠杆尚在安全区。

**四、回购停了，这是信号。** 家得宝过去三年股息稳步增长（FY2023 $83.8 亿 → FY2025 $91.5 亿），但回购从 FY2023 的 $79.5 亿骤降到 FY2024 的 $6.5 亿，FY2025 和 Q1 FY2026 直接归零。原因是并购推高杠杆，管理层优先去杠杆。摊薄股数因此不降反升（FY2024 9.93 亿 → Q1 FY2026 9.96 亿），$150 亿授权基本没动。在杠杆回落、回购重启之前，EPS 少了一条重要的增长腿——这也是它同比下滑的原因之一。

**五、估值没有安全边际。** 独立估值给出的合理价中位数约 $300（相对 P/E、DCF、所有者盈余收益率、DDM 交叉验证）。当前 $343.30 不是折价，而是相对合理价溢价约 14%。Forward P/E 约 22.9x 对一个 EPS 还在下滑、利润率在压缩、回购暂停的公司偏高。反向 DCF 显示现价已隐含约 5.5-6% 的长期 FCF 增长——等于市场提前定价了一场尚未发生的房地产复苏。

【海图研判】

**评级：持有观望**（全美家居改善龙头 + Pro 生态 + 25.4% ROIC + 自 1987 年从未间断派息的顶级生意，对垒高利率锁死房屋成交 + 内生需求停滞 + 并购稀释利润率 + 回购暂停 + Forward P/E 约 23x 无安全边际）。12 个月概率加权目标价 **$305**（悲观 $265 / 基准 $305 / 乐观 $360），相对现价 -11%——预期回报为负，不在建仓窗口。

操作建议：独立估值中位数 $300。当前 $343.30 无安全边际，耐心等回调。**首仓 $240（中位数×80%）、二仓 $210（×70%）、三仓 $180（×60%）**，分批建立。止盈三档 $400 / $440 / $480，每档减 25%，最后 25% 长期持有。建议总仓位 3-5%（核心质量仓，回调时建，不追高）。持有周期 5-10 年，赌的是利率回落 + 房屋成交回暖 + Pro 生态兑现 + 回购重启。关键纪律：好公司也要好价格，尤其当它的周期还没转、回购还没回来时。

【风险提示】

高利率持续压制房屋成交与装修需求 / 并购整合不及预期、协同兑现慢 / 利润率进一步下移 / 消费衰退冲击大额可选支出 / 高杠杆下利率上行推高利息费用——任一项都可能让股价跌向 $290（52 周低 $289 附近）甚至更低。但全美龙头地位 + $1.2 万亿 TAM + 大量自有门店地产 + 连续 37 年派息记录构成质量底，**$280-290 是较硬的估值支撑**。家得宝的"底"比周期建材股高，因为龙头质量溢价难以完全消失。

关键叙事：**"全美最大家居改善零售收费站 + Pro 生态扩张 + 25.4% ROIC + 自 1987 年从未间断派息"的世界级龙头，对垒"高利率锁死房屋成交 + 内生需求停滞 + 并购稀释利润率 + 回购暂停 + Forward P/E 约 23x 无安全边际"的周期逆风与估值风险**。家得宝不缺质量，缺的是一个便宜的价格和一个转向的利率周期。它不是给追高的人——它值得在房市与估值同时给出安全边际时，耐心建仓，然后让一台顶级龙头慢慢滚雪球。下次财报 2026-08-18，届时重新审视需求节奏与去杠杆进度。
