# Veeva Systems（NYSE: VEEV）Q1 FY2027 · 海图夜读

市场对 SaaS 的爱恨从来都来得快去得也快。两年前 ServiceNow 50 倍 P/E 时大家追逐"AI 增长股"；两年后 Veeva 20 倍 P/E、+16% 增速、44.8% 利润率、$7.3B 净现金的组合，被市场以"+5% 盘后下跌"回应。这正是 Graham 说的"市场短期是投票机"——它有时会用情绪误判一台仍在加速的复利机器。

Veeva 是"用 SaaS 软件锁定全球生命科学行业从临床研发到商业化营销全链条 IT 需求"的行业垂直操作系统。Q1 FY27 营收 $882.9M（+16%）· 订阅 $730.2M（+15%）· Non-GAAP 营业利润 $395.4M（44.8% 利润率，创新高）· Non-GAAP EPS $2.24 大超指引 $2.13-2.14 · 净现金 $7.3B = 市值 24% · 上调全年指引至 $3.64B。Vault CRM Q1 新增 27 家客户，累计 150+ 上线，14/20 大型药企承诺迁移——这是 SaaS 21 世纪最大的颠覆故事在持续兑现。

## 几个研判要点

**一、Q1 大超指引 + 上调全年 = 业绩兑现，但市场反应反向。** Non-GAAP EPS $2.24 比指引中点 $2.135 高 5%，营收 $882.9M 比指引高 ~2%。全年指引上调 $25M、EPS 上调 $0.10。但盘后股价一度跌 5%——市场对 Q2 指引 $902-905M 反应"in line not beat"，忽视了 Q1 实际超出预期的力度。**这是"短期投票机 vs 长期称重机"的典型分歧**——基本面强劲，市场情绪暂时压制估值，是价值投资者的窗口。

**二、Vault CRM 战胜 Salesforce 是 SaaS 21 世纪最大的颠覆故事兑现。** 18/20 大型药企承诺 Vault CRM 替换 Salesforce、累计 150+ 客户已上线、Q1 新增 27 家。这是**史无前例的垂直 SaaS 反向替换通用 SaaS 的成功案例**。Salesforce 在生命科学 CRM 的统治地位被根本动摇。每完成一家迁移，Veeva 的网络效应 + 转换成本就增厚一层。10 年后 Veeva 在生命科学 IT 的地位将如同微软在 Office——事实标准 + 几乎不可被颠覆。

**三、44.8% Non-GAAP 营业利润率 + 净现金 $7.3B + 零债务 = 教科书级 SaaS 财务质量。** SaaS 同业中，Non-GAAP 营业利润率超过 44% 的公司不到 5 家（Adobe / Veeva / Atlassian 等顶级）。同时拥有 $7.3B 净现金（占市值 24%）+ 零负债 + OCF/营收 128% = **这是教科书级的"轻资产、高利润、强现金流、零债务"SaaS 模型**。这种组合在 SaaS 板块凋零的当下尤其稀缺。

**四、Forward P/E 20x + 核心 P/E 15x 是 5 年最低，被市场严重错杀。** 对一个 +16% 增长、44.8% 利润率、宽护城河、零负债的 SaaS 龙头，Forward P/E 20x 是 5 年最低。剔除净现金后核心业务 P/E 仅 15.2x——**这是高质量 SaaS 同业里最便宜的估值**。对比 Salesforce 24x / Adobe 28x / ServiceNow 50x / Workday 22x · 反向 DCF 显示市场已定价 ~8% 长期 FCF 增长，远低于历史趋势——这是市场情绪误判。

**五、12 个月目标价 $215，上行 +19%。** 悲观 $155（25%，Vault CRM 执行放缓 + SaaS 估值压缩）、基准 $215（50%，FY27 EPS $9.05 + 估值修复至 23x + Vault CRM 兑现）、乐观 $260（25%，Falcon 加速 + 估值至 28x）。概率加权 $215。**当前 $181.41 距首仓 $176 仅 3%——已在合理建仓窗口**。

## 风险提示

1. **Vault CRM 执行放缓（中型药企迁移滞后）** → 概率 15%，股价跌至 $155-165
2. **SaaS 估值多重压缩（AI + 利率上行）** → 整个板块连带影响
3. **大型药企 IT 预算削减（专利悬崖 + 关税）** → 营收增速降至个位数
4. **AI 智能体颠覆传统 SaaS 范式** → 概率 10%，长期估值重置
5. **Salesforce 价格战反击** → Vault CRM 增长放缓
6. **资本配置未启动股东返还** → 估值修复缺乏催化剂

但净现金 $7.3B（市值 24%）+ FY27 FCF $1.6B + Forward P/E 17x 下限 = $154 是较硬的估值底，**$155-165 是基本面 + 净现金 buffer 共同支撑区**。

关键叙事：**"生命科学 SaaS 龙头 + Vault CRM 战胜 Salesforce + 营收 +16% + Non-GAAP 利润率 44.8% 创新高 + 净现金 $7.3B 占市值 24% + Forward P/E 20x 5 年最低 + 主人翁型 CEO Gassner"的高质量组合，对垒"3 年零股东返还 + SBC 稀释 7% + AI 颠覆 SaaS 不确定性 + Vault CRM 执行风险"的真实折价**。Veeva 不是给追求 1-2 年高回报的人，是给愿意陪伴一台垂直 SaaS 复利机器的耐心投资者。下次催化剂：2026-08 Vault AI 全应用上线 + Q2 FY27 财报。
