# 青岛港国际（HKEX: 06198 / SH: 601298）FY2025 · 海图夜读

市场总是迷恋成长，冷落稳定。可在风浪频繁的年份里，一座收过路费的百年码头，往往比追风的故事更经得起夜读。青岛港 FY2025 营收 -0.7%、净利 +0.7%——一份平淡到几乎没有波澜的年报。但平淡之下，是 H股 P/B 0.87x（破净）、前瞻股息率 5.6%、净现金 104 亿、连续三年增息的一组扎实数字。

青岛港是"中国北方进出口货物的必经收费闸口"——靠区位垄断收装卸费、仓储费、增值服务费，是一门重资产、强壁垒、现金流极稳的过路费生意。FY2025 货物吞吐量 7.22 亿吨（+4.1%）、集装箱 3,420 万 TEU（+6.3%）、归母净利 52.72 亿、综合毛利率 36.7%（+1.2pct）、ROE 11.95%。这是一座稳定运转的现金机器。

## 几个研判要点

**一、H股 P/B 0.87x 破净 + 7.5x P/E，是看得懂的低估值红利标的。** 一个 ROE 12%、区位垄断、净现金占市值 26% 的港口，市场给的估值**低于其净资产**——这本身就是安全边际。剔除净现金后核心 P/E 仅 5.6x。更关键的是，**H 股较 A 股折价 31%**——同一份资产，港股是更便宜的入口。8 种估值法中位数 HK$9.2，对当前 HK$7.08 有 23% 折价。

**二、连续三年增息 + 派息率 42% + FCF 覆盖 73%，是高含金量的红利记录。** 每股股息 ¥0.2927→¥0.3141→¥0.3454，年化 +8.5%。纯现金分红、年内两次派息、FCF 完全覆盖、不靠举债——**这是红利投资者梦寐以求的可预期现金流**。叠加南向资金对高息破净红利股的偏好，估值修复有买盘支撑。

**三、利润高度依赖 QQCT 一家合营码头，是必须正视的集中度。** 联营合营投资收益 ¥15.33 亿，占税前利润 22%，其中 **QQCT 前湾集装箱码头一家就贡献 ¥11.9 亿（占 JV 投资收益 77%、占归母净利 23%）**。更要注意：账面投资收益 ¥15.33 亿，实际收到 JV 现金分红仅 ¥4.68 亿——约 1/5 的利润是"纸面利润"，短期不以现金回流。这要求在估值中适度折价。

**四、86% 现金存放关联财务公司，是最需要监控的治理点。** ¥124.66 亿货币资金（占 86%）存放在控股股东体系的"山东港口财务公司"。山东港口集团是强省属国资，违约风险低、信息已披露、青岛港也收取存款利息——**但这是重大流动性集中点**。一旦母公司体系出现流动性问题，这笔现金存在被占用风险。这是分析青岛港最需要持续盯住的项目，也是 AH 折价的部分原因。

**五、12 个月目标价 HK$8.9，上行 +26% + 5.6% 股息 = 总回报 ~32%。** 悲观 HK$6.5（-8%，腹地经济走弱）、基准 HK$9.0（+27%，估值修复至 P/B 1.0x + 增息）、乐观 HK$11.0（+55%，AH 溢价收敛 + 红利重估）。概率加权 HK$8.9。**当前 HK$7.08 已接近机械首仓 HK$7.4——进入合理建仓窗口**。

## 海图研判

**评级：买入**（H股破净 P/B 0.87x + P/E 7.5x + 净现金占市值 26% + 前瞻股息率 5.6% + 连续三年增息 + 区位垄断护城河的稳健组合，但利润依赖 QQCT 单一 JV + 86% 现金存放关联财务公司 + 费率受管制 + 国企小股东利益排序靠后）

12 个月概率加权目标价：**HK$8.9**（+26%），叠加 5.6% 股息 = 总回报 ~32%

- 乐观（25%）：HK$11.0 — AH 溢价收敛 + 港口整合提效 + 估值至 P/B 1.3x
- 基准（50%）：HK$9.0 — 利润稳健 + 估值修复至 P/E 9x / P/B 1.0x + 持续增息
- 悲观（25%）：HK$6.5 — 吞吐量下滑 + 腹地经济走弱 + 估值不修复

**操作建议**（独立估值中位数 HK$9.2，加权公允 HK$8.9）：

当前价 HK$7.08 已接近机械首仓 HK$7.4，进入合理建仓窗口：

- 首仓 **HK$7.4**（估值中位数 × 80%，距现价 +5%，已接近——可建仓）
- 二仓 **HK$6.4**（× 70%，距现价 -10%，回调加仓）
- 三仓 **HK$5.5**（× 60%，距现价 -22%，52 周低附近极端机会）

止盈三档：**HK$10.5 / HK$12.0 / HK$14.0**（每档减仓 25%，最后 25% 长期收息持有）

建议总仓位 **4-8%**（中等仓位 · 红利型防守标的 · 组合的现金流压舱石）。这是一座"区位垄断现金牛 + 持续高分红 + 破净修复"的红利压舱石——不是给追求成长的人，而是给在风浪年份里需要稳定现金流、愿意用耐心换收息复利、能容忍低增长的价值投资者。**持有周期 3-5 年**，目标是"收息 + 估值修复双驱动"。关键纪律：把它当"收息 + 估值修复"标的，不要期待成长爆发；持续监控关联现金安全 + JV 分红回款。

## 风险提示

1. **关联方现金集中（¥124.66 亿存放山东港口财务公司）** → 概率 10%，影响重大，股价或跌 30%+
2. **腹地经济与大宗需求下行（钢铁去产能 + 能源转型）** → 概率，吞吐量见顶
3. **JV 利润含金量下降（账面 ¥15.33 亿 vs 现金回款 ¥4.68 亿）** → 22% 利润依赖 QQCT 单一 JV
4. **国企治理与不利关联交易** → 小股东利益排序靠后
5. **港口费率受发改委管制** → 无自主提价权
6. **AH 折价持续 / 港股流动性折价** → H 股估值修复偏慢

但 H股 P/B 0.87x（破净）+ 净现金 ¥104 亿（市值 26%）+ 5.6% 股息率构成**硬底**，HK$5.5-6.0 是较硬的估值底（P/B ~0.7x + 股息率 6.5%+，南向红利资金会托底）。

关键叙事：**"H股破净 P/B 0.87x + P/E 7.5x + 净现金占市值 26% + 前瞻股息率 5.6% + 连续三年增息 + 全球前五大港区位垄断"的低估值红利组合，对垒"利润依赖 QQCT 单一 JV + 86% 现金存放关联财务公司 + 费率管制 + 国企治理"的结构性约束**。青岛港不是一笔成长股，是一座"区位垄断现金牛 + 持续高分红 + 破净修复"的红利压舱石——给在风浪年份里需要稳定现金流、愿意用耐心换收息复利的价值投资者。下次催化剂：2026-08 中期业绩 + 中期分红。
