本季必看 · 两个"看穿"：银行没有 FCF、EPS +25% 的三个来源

读银行的利润表，有两个必须"看穿"的地方，看不穿就会用错框架、误判增长质量。

看穿一：银行没有"自由现金流"，别拿制造业尺子量它。 很多人习惯性去算 BAC 的 OCF / Capex / FCF、或"现金 − 有息负债 = 净现金"——对银行这些数字全部不适用。银行的"原料"就是负债：$2.04 万亿存款 + 长短期借款不是"要还的债"，而是它赚利差的资金池；现金流量表也不反映经营实质。银行真正要看的是三样：利差质量（NIM 2.07% / ex-Markets 2.55%）、成本效率（效率比 61.2%）、风控（NCO 率 0.48%），偿付能力看资本（CET1 11.2%）与流动性（$960B），而非"净现金"。本报告全程用银行口径。

模块 1 · 公司概览与背景

Bank of America Corporation（NYSE: BAC），总部北卡罗来纳州夏洛特。源自 1904 年旧金山的意大利银行、1998 年 NationsBank 与 BankAmerica 合并成今日框架，2008-2009 危机中收购 Countrywide（住房贷款）与 Merrill Lynch（财富管理 + 投行），奠定"零售 + 财富 + 投行"三位一体版图。财年即日历年（12 月 31 日结束）。CEO 布莱恩·莫伊尼汉（Brian Moynihan，2010 至今）、CFO Alastair Borthwick。

核心叙事：BAC 是美国货币中心大行中"消费银行 + 财富管理"最强的关系型银行——总资产 $3.5 万亿（2026-03-31 末，美国第二）、美国消费者存款份额连续多年全美第一、小企业贷款连续 19 季全美第一。它不是一条腿走路的利差银行，而是四台引擎的组合体：

  • 消费银行 Consumer Banking——3,850 万支票账户（91% 为主账户）、连续 29 季净增，是低成本存款与循环卡息的基本盘；Q1 净利 $3.06B（+21%）、ROAC 27%
  • 全球财富与投资管理 GWIM——Merrill + Private Bank，客户余额 $4.6 万亿、AUM $2.1 万亿，费收驱动、抗周期；Q1 净利 $1.33B（+32%）、ROAC 24%
  • 全球银行 Global Banking——企业信贷 + 投行（Q1 投行费 $1.8B，+21%）；Q1 净利 $2.09B（+8%）、ROAC 16%
  • 全球市场 Global Markets——做市与交易，销售交易收入 $6.4B（+13%，连续 16 季同比增长）、股票交易 +30%"史上最佳单季"；Q1 净利 $2.01B（+3%）、ROAC 15%

股权与治理：单一类别普通股（无双重股权），期末普通股 7.13B 股（1Q25 7.56B → 4Q25 7.21B → 1Q26 7.13B，持续回购缩股）。优先股 $25.0B（分层）。治理成熟规范，董事会独立性高。巴克希尔系资本长期为其最大股东之一（本报告按品牌规范不展开该股东叙事）——机构持股集中、稳定。

能力圈检验：BAC 的生意可用两句话说清——用全美最庞大的低成本消费存款做资金池赚利差，再用 Merrill 财富平台 + 投行 + 做市赚手续费。清晰、可理解。两块需要盯的暗箱：(1) 巨额持有至到期（HTM）证券组合 $5,147 亿——2020-2021 低利率时买入、账面存在未实现损失（历史 AOCI 拖累），如今随到期滚动以高约 150-200bps 再投资，是未来数年 NII 的结构性顺风，但利率路径决定其修复速度；(2) 信贷周期位置——当前 NCO 0.48%、商业地产办公敞口在改善，但处周期低位，只有上行空间。

模块 2 · 管理层评估
A-

Brian Moynihan · 董事长兼 CEO（2010 至今）

危机后临危受命，用十五年时间把一家背着 Countrywide 诉讼、濒临崩溃的银行重塑为盈利稳定的关系型堡垒。核心战略是"负责任的增长"（Responsible Growth）——不追风口、不做不理解的业务、以客户关系深化（主账户、交叉销售、数字化）而非资产规模扩张为增长源。任内把消费者存款做到全美第一、支票账户连续 29 季净增、数字银行活跃用户 5,000 万。海图判断：这是一位把"活下来 + 慢慢变好"刻进企业基因的守成型掌舵人，风格与激进扩张相反，正是危机后大行最需要的性格。CFO Borthwick 沉稳，指引记录可信。

A-

资本配置纪律 · 回购三级跳 + 连续增息

持续大额回购缩股：回购规模三年三级跳（FY2023 $4.58B → FY2024 $13.10B → FY2025 $21.43B），摊薄股数从 FY2022 的 81.7 亿降至 1Q26 的 74.2 亿（累计缩约 9%）。2025-07 新批 $40B 普通股回购授权（2025-08-01 生效）+ 同步上调股息 8% 至 $0.28/季。
危机式并购眼光：2008-2009 在别人恐惧时收购 Countrywide + Merrill Lynch，虽背了多年诉讼包袱，但 Merrill 财富平台成为今日最抗周期的利润引擎——事后看是顶级的逆周期资本配置。
一个纪律观察点：FY2025 合计返还 $29.5B ≈ 当年归属普通股净利的约 100%，1Q26 单季返还 $9.3B 更超当期盈利，靠释放超额 CET1 支撑（本季 CET1 环比降 14bp）——这对资本充裕的银行是合理的超额资本释放，但不是"用赚的钱返还"，是模块 12 的关键检验点。

长期主义测试：✅ Moynihan 的"负责任增长"本质是长期主义——常年维持超额资本缓冲、不为平滑短期 EPS 而牺牲风控、危机中出手而非退缩。坦诚度：电话会详尽，主动披露分部 ROAC、NCO 细项、利率敏感度（远期曲线再降 100bp → 未来 12 个月 NII 减少约 $2.0B），并在业绩最好的季度仍提示"对不断演变的风险保持警惕"。利益绑定：管理层持股比例不高（成熟大盘股常态），薪酬与 ROTCE / 负责任增长指标挂钩，结构合理。历史兑现：4Q25 首次给出 FY2026 NII +5~7% 指引，1Q26 即因超预期上调至 +6~8%——指引偏保守、兑现度高。

模块 3 · 商业模式深度解析

海图"一句话测试"：美国银行是一台"存款引擎 + 费收引擎"的双缸机器——用全美最大的低成本消费存款池赚利差（NII，占营收 52%），再用 Merrill 财富管理、投行、做市交易赚不占用信用风险的手续费（占 48%），两缸互补、穿越周期。

营收模型（Q1 FY2026 · 扣息后）：净利息收入 NII 与非利息收入近乎一半一半，这是 BAC 相对纯利差银行的抗周期优势——降息压 NII 时，财富/投行/交易费可对冲；市场清淡压费收时，存贷利差是压舱石。

  • 对存款人议价力：强——消费者存款份额全美第一，3,850 万支票账户（91% 主账户），黏性极高、成本极低，是 NII 的护城河源头

  • 对监管：零议价力——资本要求（CET1）、压力测试、Basel 规则是这门生意唯一不可谈判的成本；BAC 曾长期受"沃尔克规则 + 危机后监管"约束
  • 规模与网络：数字银行活跃用户 5,000 万、综合卡消费 $2,450 亿/季（+7%）——数字化把服务边际成本压低，是效率比持续改善的引擎
模块 4 · 经济护城河分析（5 维 · 金融业适配）
1. 成本优势（低成本存款）
宽

美国消费者存款份额全美第一、$2.04 万亿存款、3,850 万支票账户（91% 主账户）。极低资金成本是 NIM 与 ROTCE 的根基。趋势：稳定偏加宽（数字化 + 主账户深化）。

2. 转换成本
宽

支票账户 + 房贷 + 卡 + Merrill 财富账户深度绑定，账户迁移摩擦大。GWIM 客户余额 $4.6 万亿黏性极高。趋势：稳定。

3. 规模/有效规模
中-宽

$3.5 万亿资产、四大 GSIB 之一，全国分行 + 数字网络规模效应显著（效率比改善 170bp）。但美国大行是"寡头竞争"而非独占，JPM 份额更强。趋势：稳定。

4. 无形资产/监管牌照
中-宽

百年品牌信任 + 全国银行牌照 + GSIB 地位构成极高准入壁垒。但同一监管地位也带来资本要求、压力测试、Basel 加码的"税"。趋势：监管压制。

5. 网络效应
中

支付、Zelle、财富平台有一定网络属性，但弱于卡组织/交易所。银行护城河主要来自成本 + 转换成本而非网络效应。趋势：稳定。

10 年后护城河会更宽还是更窄？ 核心判断：核心存款护城河更宽，但"税"更重、体系外渗漏加剧。头部化是银行业的长期物理规律——每一轮危机（2008、2023 区域银行危机）都让存款与人才向 BAC/JPM 这样的大行集中。但三个侵蚀变量：(1) 私募信贷把最优质的企业信贷从银行资产负债表撬走；(2) 金融科技 / 稳定币 / 支付新轨道分流支付与低成本存款；(3) 监管资本加码（Basel III Endgame）不侵蚀份额但压 ROTCE 天花板。定价权：存款端强（份额第一、低息揽储）、贷款端中（面对私募信贷竞争）、费收端中-强（财富/投行份额稳定）。

5.4 现金流与资本生成（银行版所有者盈余）

所有者盈余收益率 ≈ $29B / 市值 $423B ≈ 6.8%——对一家 ROTCE 16%、盈利结构性改善的大行，这个收益率谈不上便宜，但明显优于同业中估值最高的 JPM（约 5.4%）：BAC 是货币中心大行里"质量改善 + 估值相对合理"的组合，而非"顶级质量 + 顶级估值"。

12.2 给的方式好不好？

  • 真实缩股 · 含金量高：美股回购多入库存股（treasury stock），检验含金量的硬指标是摊薄股数——BAC 年度摊薄股数 FY2022 8,167.5M → FY2023 8,080.5M → FY2024 7,935.8M → FY2025 7,680.9M → 1Q26 单季 7,417.5M，累计缩约 9% 且在加速；期末普通股 1Q25 7.56B → 4Q25 7.21B → 1Q26 7.13B。回购规模远超股权激励稀释，不是"替 SBC 接盘"，是真金白银的每股价值增厚——这也是 EPS +25% 快于净利 +16.6% 的重要来源
  • 股息纪律干净：2025-07 上调股息 8% 至 $0.28/季（年化 $1.12），派息率仅约 25% 净利，留足信贷周期缓冲——银行股息可持续性看的正是"低派息率 + 高覆盖"
  • 回购择时是观察点：FY2025-1Q26 回购放量恰逢股价与 P/TBV 走高，1Q26 的 $7.2B 买在约 2.0x TBV（自身高位区）。相比 JPM 在 3.1x TBV 满价回购，BAC 的 2.0x 还算合理，但已非"低估回购"——用格雷厄姆的语言，公司在略高于内在价值处替股东回购

12.3 能不能继续给、给多少？

  • 授权额度：2025-07-23 董事会批准全新 $40B 普通股回购授权（2025-08-01 生效，取代旧计划）。自生效至 1Q26 已执行约 $18B（3Q25 部分 + 4Q25 + 1Q26 $7.2B），估算剩余约 $20B（约占市值 4.7%；此为推算、非一手逐笔核对，供参考），按每季约 $5-7B 节奏可再持续约 3-4 季
  • 股息指引：现行 $0.28/季（年化 $1.12），前瞻股息率约 1.9%；以 FY2026E EPS $4.47 计派息率仅约 25%，增息空间充足
  • 覆盖度（银行版）：FCF 覆盖度指标不适用（金融业），替代检验：FY2025 返还 $29.5B ≈ 归属普通股净利约 100%、1Q26 单季返还 $9.3B 更超当期盈利——返还已用满甚至略超当期盈利，靠释放超额 CET1（本季环比降 14bp）支撑。这不同于 JPM 的 82% 净派出率仍有余量：BAC 的返还节奏更接近"打满"，可持续性更依赖 CET1 缓冲厚度（11.2% 对下限约 +50-120bp）与 Basel 走向
  • 不是被动借债回购：返还来自超额资本释放而非举债，资本充裕度仍远高于监管下限；但"返还超盈利"意味着 CET1 会缓慢下行，若 Basel 加码或信贷成本上行，回购是第一个被调节的阀门

模块小结：积极且高含金量，但节奏已近"打满"——三年返还 $62B、股数真实缩减约 9% 且加速、约 7% 的 trailing 股东收益率高于 JPM、派息率低留有缓冲、$40B 授权支撑未来数季。唯一需盯的是返还已达/略超当期盈利、靠 CET1 缓冲，可持续性对 Basel 与信贷周期更敏感——不是含金量问题，是"打满后没有多少加码空间"的问题。

五个研判要点

一、EPS +25% 快于净利 +16.6%，差额来自三处叠加。 缩股（摊薄股数一年缩 4.5%）、正经营杠杆（营收 +7.2% 快于费用 +4.3%、效率比降到 61%）、拨备回落 + 本季 17.5% 的一次性税率折抵。前两项是可持续的结构性来源，税率是一次性的——把税率还原到 ~19-20%，"干净"的 EPS 增速仍在 +18-20%，依然强劲。别被 +25% 的表象带跑，缩股 + 经营杠杆这台复利机器才是重点。

二、NII 指引上调，是这季最重的一块。 NII（FTE）$15.9B（+9%）超公司自己的预期，管理层据此把 FY2026 增速指引从 5-7% 上调到 6-8%。背后是一个结构性顺风：2020-2021 低利率时买入的巨额证券组合，正以每季 $12-15B 的速度到期，再投资收益率高约 150-200bps——这是未来数年 NII 与 ROTCE 的自动抬升器。它的唯一天敌是美联储激进降息（曲线每下移 100bp，未来 12 个月 NII 约减 $2.0B，升息却只增不足 $5 亿）。

五、估值：市场给的隐含 ROTCE，几乎等于它实际的 ROTCE。 现价 $59.25 = 2.05x TBV，反向推算隐含市场定价约 15.8% 的永续 ROTCE——而 BAC 实际 Q1 就是 16%。这与 JPM 被定价"永续 22%"（远高于实际 20%）形成鲜明对比：BAC 的估值最"诚实"，没把峰值当永续，但也没有折价。八种估值法加权公允约 $60，概率加权 12 个月目标 $60，与现价几乎持平——上行 +15%、下行 -19%，情景比 JPM 对称，但当前没有安全边际。

评级：持有观望（"消费银行之王 + 证券再投资的结构性 NII 顺风 + 约 7% 股东收益率"的改善型堡垒，对垒"P/TBV 2.05x 估值高位 + 返还已超当期盈利 + 信贷周期晚期"）。12 个月概率加权目标价 $60（+1%），叠加约 1.9% 股息，预期总回报约 +3%——稳健，但不激动。

操作建议：当前 $59.25 逼近 52 周高、远高于机械首仓 $48，不在建仓窗口。耐心等信贷恐慌、NII 逆风或宏观转弱：首仓 $48（约 1.6x 前瞻 TBV）、二仓 $42、三仓 $36。已持有者不必因估值公允而卖出核心仓：止盈三档 $68 / $75 / $82，各减 25%，最后 25% 长期持有。建议总仓位 3-5%，持有周期 3-5 年以上，穿越一轮信贷周期。

风险提示

信贷周期转向、美联储激进降息逆转 NII 顺风、交易收入从纪录高位回落、Basel 资本加码压 ROTCE——任一项都可能把股价打回 $48-50；$44.75（52 周低，约 1.55x TBV）是第一道较硬支撑。但 CET1 $1,997 亿 + 拨备对不良覆盖约 2.5 倍 + 流动性 $960B，意味着 BAC 的"生存问题"不存在，风险全部集中在盈利预期与估值层面。

关键叙事："消费银行之王 + 结构性 NII 顺风 + 约 7% 股东收益率 + ROTCE 结构性改善"的改善型堡垒，对垒"P/TBV 2.05x 自身估值高位 + 返还已超当期盈利 + 信贷周期晚期"。美国银行是四大行里最接近合理价的一个——它不像摩根大通那样把最好的年景当成永续，但它自己也没打折。放进观察清单，等市场先生在某个信贷恐慌或降息落地的夜里，给出那 25% 的安全边际。下次财报：2026-07-14，就在三天后。
