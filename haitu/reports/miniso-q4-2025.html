模块 1 · 公司概览与背景

公司全称：名创优品集团控股有限公司 / MINISO Group Holding Limited
上市：NYSE: MNSO（2020-10-15 IPO）+ HKEX: 9896（2022-07-13 二次上市）
总部：广州
注册地：开曼群岛
财年：1 月 1 日 - 12 月 31 日（2023 年从原 6 月底财年制变更为日历年）
主营：全球生活方式产品零售（家居、文具、美妆、零食、玩具）——以加盟 / 经销为主、自营少量旗舰店；旗下两大品牌：MINISO（全球 8,151 家门店，主品牌）+ TOP TOY（334 家，潮玩 / 盲盒 / 收藏品集合店）。

核心叙事：MINISO 是"东方小杂货 + 全球 IP 联名"的零售范式——它把宜家的"低价好看"、无印良品的"性冷淡风"、迪士尼的"IP 内容"做了一次中国式重组，靠加盟扩张 + 全球供应链反向定制，把 SKU 数量、价格带、上新速度都压到极致。FY2025 营收 ¥214 亿（+26%）、调整后净利 ¥29 亿（+6.5%）。两条第二曲线：(1) 国际化——海外 MINISO 营收已占品牌的 44.2%（¥86 亿），美国同店 Q4 录得低双位数；(2) TOP TOY——潮玩集合店模式 +95% 增长，且已传出 2026 年港股拆分 IPO 计划。最大的争议：2024-09 公司动用 ¥62.7 亿（含 ~¥40 亿银行借款）增持永辉超市 29.4% 股权，押注"胖东来"式重塑大卖场——FY2025 永辉权益法亏损 ¥8.1 亿，让 GAAP 利润暴跌 -54%。

简史与里程碑：

1. 2013 年广州创立——叶国富（前"哎呀呀"创始人）联合日本设计师三宅顺也共创，定位"全球十元店"
2. 2015-2020 加盟扩张 + 全球开店——靠加盟 + 标准化 SKU 高速复制，进入 100+ 国家
3. 2020-10-15 NYSE 上市——IPO 募资约 $6.8 亿，市值约 $80 亿
4. 2022-07-13 港股二次上市——HKEX: 9896
5. 2023 起 IP 战略提速——与 Chiikawa、三丽鸥、迪士尼、NBA、宝可梦、芭比等签长期 IP 合作
6. 2023-07 启动股息政策——派息 ≥ 调整净利 50%，开启系统性资本返还
7. 2024-09-23 增持永辉超市 29.4%——RMB 62.7 亿（部分银行借款融资），CEO 亲自挂帅永辉重整
8. 2026-01-09 MiniMax 港股 IPO——名创早期投资市值随之兑现公允价值收益
9. 2026-03-31 FY2025 财报——营收 +26%、调整净利 +6.5%、GAAP -54%（永辉拖累）

股权结构（2025-12-31 末）：

叶国富 + 杨云云夫妇（创始人）——通过 YGF Trust 持有全部 B 类股（每股 3 票超级投票权），经济权益约 62%，牢牢掌握控制权
其他机构与公众——其余约 38%
注：双层股权（dual-class）结构 + 创始人深度控盘——好处是决策果断、长期一致；坏处是小股东对永辉这种大额非主营投资的制衡能力有限。

模块 2 · 管理层评估
B+

叶国富 · 创始人 / 董事长 / CEO（2013 至今）

1977 年生，湖北人，前"哎呀呀"饰品连锁创始人。2013 年与日本设计师三宅顺也共创 MINISO，是公司的绝对灵魂人物。优点：12 年深耕同一行业、对零售供应链与全球加盟体系有深刻直觉；2023 年起主导 IP 战略升级 + 调整后净利持续增长，证明经营能力；2024 年起亲自挂帅永辉重整，"All-in" 长期主义底色明显。扣分项：2024-09 永辉 ¥62.7 亿+ 借款的大额非主营投资偏离了"专注主业"的纪律，是一次有争议的资本配置赌博；双层股权下小股东对此几乎无制衡能力。

A-

杨云云 · 联合创始人 / 总裁

叶国富之妻，公司联合创始人，主管运营与门店体系。低调、与叶国富搭档稳定。夫妻档共同控盘 + 长期持股——决策一致性高，长期主义可信。

B+

张靖京（Eason Zhang）· 副总裁 / CFO（2023-01 起）

普华永道出身，CFA。任内主导了股息政策制定、多次回购计划、永辉收购的财务结构设计。对资本市场沟通职业、披露透明度高——但永辉收购的债务融资也在他任内显著抬升财务杠杆。

B

资本配置纪律 · 慷慨返还 + 一次有争议的大额收购

慷慨返还：FY2025 派息 ¥13.6 亿 + 回购 ¥5.5 亿 = ¥19 亿（占调整净利 66%）；股息政策明确 ≥ 50% 调整净利；FY2025 末再公告 HK$1.8 亿自动回购计划。
有争议的大手笔：2024-09 用 ¥62.7 亿（含 ~¥40 亿银行借款）增持永辉超市 29.4%——把一家本来"净现金充裕、生意聚焦"的公司，变成了"轻度净负债 + 携带大型权益法亏损"的复合体。
结论：核心主业的资本配置纪律是 A 级（高比例返还 + 主业稳健再投资），但永辉收购把整体评分拉到 B——这次收购对错要看 5-10 年。详见模块 12 股东回报分析。

长期主义测试：叶国富 12 年坚持"全球生活方式品牌"愿景未动摇——IP 战略 5 年酝酿 + 海外 7 年扩张 + 永辉 5-10 年押注，说话与行动一致。但长期主义与"赌性"只有一线之隔——永辉是这条线的考验。

薪酬与利益绑定：创始人持股 62%、双层股权，与公司利益深度绑定。这是创始人控盘型公司的典型治理——做对了能很好，做错了纠错难。

模块 3 · 商业模式深度解析

海图"一句话测试"：名创优品做的是"低价 + 高频上新 + IP 联名"的生活方式杂货零售——靠加盟（贡献门店增长）+ 自营反向供应链定制（贡献低成本）+ IP 内容（贡献溢价）三件套，赚 45% 毛利、17% 调整后营业利润率的薄利但快周转生意，单店投资回收周期约 1.5-2 年。

护城河来源（详见模块 4）：(1) 规模优势——全球 8,485 家门店带来供应链反向定制能力；(2) 无形资产——MINISO 品牌 + Chiikawa/三丽鸥/迪士尼等 50+ IP 长期合作权益；(3) 有限的转换成本——客户对零售品牌粘性弱，但 IP 内容形成"必去的种草点"。

商业模式风险：(1) 加盟模式的单店收入依赖客流而非黏性；(2) IP 联名是双刃剑——Chiikawa 之后的"下一个 Chiikawa"能否持续？(3) TOP TOY 直接对垒 Pop Mart（IP 自有 vs IP 授权 ≈ 苹果 vs 安卓），护城河浅一档。

成本优势窄最实在的护城河——8,485 家全球门店 + 反向定制供应链让单品成本低于多数零售对手；但任何规模到一定的零售商都能复制（Decathlon、Daiso 等都有）
无形资产窄MINISO 品牌全球知名度（IPO 后加速）+ 50+ 全球 IP（Chiikawa、三丽鸥、Disney、NBA、宝可梦、芭比等）长期授权——属于"租来的护城河"，授权可续可不续
有效规模窄低线城市、海外新兴市场存在"先发优势"——某些海外地区已不容易再容下第二家同类大型连锁；但中国一二线城市竞争充分

综合判断：窄护城河，但持续加宽中。MINISO 的护城河不像高毛利消费品（贵州茅台、可口可乐）那样宽阔，但在"低价生活方式杂货"这个细分赛道，MINISO 是全球少数能 8,000+ 店规模的公司——规模 + IP 矩阵 + 品牌认知三件套，让对手追赶成本越来越高。

护城河趋势：缓慢加宽。理由：(1) IP 矩阵从单一 Chiikawa 走向 50+ 多元化，单一 IP 失效风险下降；(2) 海外门店密度上升带来反向供应链优势放大；(3) TOP TOY 进入潮玩这条更有 IP 经济学的赛道。5-10 年护城河会更宽，但永远不会成为"宽护城河"——零售是个相对薄的生意。

12.2 回购的"含金量"：库存股 vs 注销

名创回购的"含金量"是中等偏低——这是个需要拆细看的点：

1. 回购股份的处理：根据公司公告，名创回购的股份多数作为库存股保留（部分用于股权激励计划），而非全部立即注销。这与港股《上市规则》原则上"回购后注销"的精神并不完全一致——名创的 HK 法律结构允许暂存为库存股。
2. 摊薄股数趋势：FY2023 流通股 ~12.50 亿股 → FY2024 ~12.45 亿 → FY2025 ~12.38 亿。3 年净减少约 1.2%——确实在缩股本，但幅度被股权激励（SBC）部分抵消，真实"净回购率"仅 ~0.4%/年。
3. 双层股权下的特殊性：B 类股不参与回购，所以回购只稀缺度只影响 A 类股，对叶国富控股比例几乎无影响。

结论：名创的回购是"真在花钱、但更像对冲 SBC 稀释 + 信号意义"，含金量比"全额注销"低一档。但派息（占总返还约 70%）是高含金量——直接到股东账户。综合看：股东回报"高派息 + 中等回购"组合，整体含金量中上。

12.3 已授权但未执行的回购额度

2024 回购计划：HK$2 亿，2024-08-30 批准，12 个月——已于 FY2025 大部分执行。
2025-Q4 末新计划：HK$1.8 亿自动回购计划（automatic share repurchase plan），用于在 FY2026 黑色窗口期持续回购——这是首次采用 ASP 形式，约束力强于普通授权。
剩余可用额度：HK$1.8 亿，约占市值 0.5%——力度温和但持续。
执行可信度：过往 3 年公司对授权额度兑现度 80%+，非空头支票型。

12.4 未来股息 + 回购指引

股息政策明确：自 2023-07 起承诺≥50% 调整后净利派息。FY2025 实际 ~70%（含特别股息）——超额兑现。
偏好次序：管理层在电话会明确"派息 > 回购 > 再投资 > 还债"——这是典型成熟期消费股的资本配置思路。
FY2026 预期：若调整净利达共识 ¥33 亿，按 50% 派息率 → 派息 ¥16.5 亿 + 回购 ¥5-8 亿 = 总返还 ¥22-25 亿，对应股东总回报率约 7-8%。

12.5 股东回报可持续性

当前股东总回报率（trailing Shareholder Yield）：股息 ¥13.6 亿 + 回购 ¥5.5 亿 = ¥19.1 亿，市值 ¥315 亿，~6.1%——属于港股零售较慷慨的一档。
覆盖度健康：(股息 + 回购) ¥19 亿 / FCF ¥15.8 亿 = 120%——FY2025 实际"超额返还"，超出部分来自现金储备而非借债。不可持续的部分是"超额"，但回归至 80-90% 覆盖（FY26 预期）仍属于慷慨稳健。
借债回购？名创的 ¥40 亿借款明确用于永辉收购，不是为了回购股东——没有"借债回购"问题。
择时：FY2025 回购均价 HK$30-45 区间——在股价回落至 HK$28 后启动 ASP，表明管理层认为当前估值有吸引力。

海图
夜读手记 · 1150 字

财报里最容易骗人的，往往是"利润"本身。名创优品 FY2025 GAAP 净利 ¥12.1 亿、同比 -54%——标题数字像是经营崩了；几个月后 Q1 2026 业绩快报又称净利 +200%，仿佛突然涅槃。两个数字都不是真的。真的，藏在调整后净利 ¥29 亿（+6.5%）、海外门店净增 465 家、TOP TOY +95% 这些不那么戏剧化的数字里。

名创是一家正在"双线作战"的全球生活方式品牌。主业稳健：8,485 家门店、45% 毛利率、调整 ROE 27%、海外营收占品牌 44%、TOP TOY 高速增长。同时，创始人叶国富 2024-09 用 ¥62.7 亿 + ¥40 亿银行借款，增持永辉超市 29.4%——押注"胖东来"式重塑中国大卖场。这笔投资在 FY2025 通过权益法吃掉 ¥8.1 亿账面亏损，是 GAAP 净利"暴跌 -54%"的全部原因。

几个研判要点

一、必须看穿 GAAP 利润的双重扭曲。FY2025 GAAP 净利被永辉权益法亏损向下扭曲了 ¥8 亿；Q1 2026 又被 MiniMax 公允价值收益向上扭曲了 ¥8.7 亿。把这两层都剥掉，名创真实的主业增速是调整后净利 +6.5%（FY25 全年）/ +7-10%（Q1 2026 核心）——稳健，但绝不戏剧。看穿这层，是分析名创不犯错的第一关。

二、主业是一门继续在变好的好生意。45% 毛利率、17% 调整后营业利润率、27% 调整 ROE、OCF/净利 88.9%——这是消费股里少有的"高质量增长"组合。FY25 营收 +26% 是过去 4 年最快增速；中国同店 Q4 中双位数（8 季度最佳）+ 海外 +29% + TOP TOY +95% 三条曲线同时加速。护城河虽窄但持续加宽——50+ 个全球 IP 矩阵 + 8,000+ 全球门店反向供应链，让 Daiso、Pop Mart 等单点对手都难以全维度对抗。

三、资本返还是确定性的红利。FY25 派息 ¥13.6 亿 + 回购 ¥5.5 亿（历史新高）= ¥19 亿 = 调整净利的 66%；股息政策承诺 ≥50% 调整净利；FY26 末期股息 + HK$1.8 亿自动回购 ASP 已生效——股东总回报率 6.1% 在港股零售里是慷慨的一档。当前 HKD 27.74 已贴近 52 周低，意味着每一笔回购都在估值低位下手。

四、永辉是头顶的剑，也是手里的牌。这是 Miniso 评级被压制在"有条件买入"的根本原因。永辉 FY25 拖累 ¥8.1 亿、Q1 2026 转正 ¥2.87 亿（94% YoY 增长，多年来首次单季盈利）——重整在生效，但还没有"完成"。若叶国富的胖东来式重塑在 2027 前兑现，权益法损益将由 -¥8 亿 / 年转为 +¥10 亿 / 年——一进一出 ¥18 亿，单这一项就能让 GAAP 利润从 ¥12 亿涨到 ¥40 亿。但若失败，¥55 亿账面值面临减值。这是一道有明显赔率（甚至偏正）但胜负不可知的牌局。

五、12 个月目标价 HKD 35，上行 +26%。悲观 HKD 24（-13%，永辉重整缓慢 + 消费疲软）、基准 HKD 35（+26%，主业 +20% 营收 + 调整净利 +10% + 永辉缓慢转正）、乐观 HKD 42（+51%，永辉明显兑现 + TOP TOY 拆分 IPO + 海外提速）。当前 HKD 27.74 已逼近首仓 HKD 28 附近——这是合理的建仓窗口。海图的判断：这是一笔"好生意 + 合理估值 + 一个明确悬念"的投资——质量没问题，价格不贵，就看叶国富的"永辉这一手"能不能打出来。

海图研判

评级：有条件买入。主业增长真实 + 资本返还慷慨 + 估值合理偏便宜 + 创始人深度绑定的组合，对垒"永辉大额非主营收购 + GAAP 利润被双重扭曲"的隐忧。12 个月概率加权目标价 HKD 35（+26%）。建议首仓 HKD 28（×80%，已到）、二仓 HKD 24.5（×70%，-12%）、三仓 HKD 21（×60%，-24% 极端机会）。止盈三档 HKD 38 / 45 / 55，每档减仓 25%，最后 25% 作为"中国零售出海龙头"长期持有。建议总仓位 3-7%（中等仓位）。持有周期 3-5 年。优先 HKEX: 9896。等 5-26 Q1 完整业绩 + 永辉 Q2 数据再加仓至上限。

风险提示

永辉重整失败 + 大额减值 / 中国消费深度衰退 / TOP TOY 拆分搁浅 + 潮玩降温 / MiniMax 大幅减值 / 海外地缘 / 关税冲击——任一项都可能让股价回调 15-25%。但 ¥107 亿净资产 + 调整 ROE 27% + FCF 持续为正 + 6%+ 股东总回报率，让 HKD 22-25 成为较硬的估值底。

关键叙事："中国零售出海龙头 + 调整 P/E 10.7x 合理偏便宜 + 调整 ROE 27% + 股东总回报率 6.1% + 距 52 周低 1%"的组合，对垒"永辉大额非主营收购悬而未决 + GAAP 利润被双重扭曲"的隐忧。在多数优质消费品估值不菲的当下，名创是一笔"好生意被永辉阴云压制 + 资本返还慷慨垫底"的标的——不是给只看 GAAP 净利标题数字的人，而是给愿意看穿调整后净利、理解永辉这盘 5 年牌局赔率、并有耐心等永辉持续兑现信号的投资者。下次催化剂：2026-05-26 Q1 2026 完整业绩 + 永辉 Q2 进展。
