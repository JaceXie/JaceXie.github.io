模块 1 · 公司概览与背景

公司全称：新华文轩出版传媒股份有限公司 / Xinhua Winshare Publishing and Media Co., Ltd.
上市：HKEX: 0811（2007-05-30 香港上市）+ SH: 601811（2016-06-09 A 股上市）
总部：四川省成都市
主营：出版（图书+电子出版物+数字出版）+ 发行（教材教辅+一般图书+电商）+ 印刷+物资贸易+教育服务+物流

核心叙事：新华文轩是中国最大的省级出版发行集团，依托四川省教材专营权和 6,500+ 家新华书店渠道，覆盖近 500 万学生（仅四川省）+ 全国出版分销。这是一家"政策牌照护城河 + 渠道网络 + 高股息防御"三位一体的国企——FY25 营收 -4.84% 因教材教辅减少 ¥3.46 亿（出生人口下降的结构性逆风），但归母净利润仍 +1.53% 显示成本控制和投资收益对冲能力。资产负债率 33.24%（行业最低）+ 累计分红 ¥47.38 亿（A股发行 ¥15 亿，分红覆盖 3 倍）+ H股 PE 7.31x / PB 0.73x / 股息率 6.40%——这是港股出版传媒中"破净 + 高股息 + 国资委背书"组合最稀有的标的。

简史与里程碑：

1. 2005 年成立——四川出版集团 + 新华书店集团合并改制
2. 2007-05-30 港股上市——HKEX: 0811，发行价 HKD 4.34
3. 2016-06-09 A 股上市——SH: 601811，发行价 ¥9.20，募集 ¥15 亿
4. 2018 年图书市占率全国第 11、地方第 7——稳居出版头部
5. 2020-2024 教材专营权续签——四川省教育厅授权延续
6. 2024 年累计分红超 ¥40 亿——成为 A 股出版股分红最稳健的之一
7. 2025-2026 数字化转型——电商占一般图书 34.75% / 电子书+有声书 1,000+ 种
8. 2026 Q1 业绩趋稳——营收降幅 -4.84% → -0.16% 大幅收窄

股权结构（2025-12-31 末）：

四川省国资委（实际控制人）——通过新华文轩集团持有约 67% 股权（A 股+H 股穿透）
香港公众股东（H 股）——~36% H 股流通（4.42 亿股）
A 股公众股东——~33% A 股流通（7.92 亿股）
总股本 12.34 亿股 = A 股 7.92 亿 + H 股 4.42 亿
这是典型的"地方国资委监管 + AH 双上市"治理结构，四川省政府关于教育、出版的"基础公共服务"代理人

模块 2 · 管理层评估
B+

何志勇 · 董事长（地方国资轮换制）

新华文轩管理层属于四川省国资委轮换体系——董事长/总裁 5 年一换，没有"创始人主义"。但出版主业、教材专营权、分红纪律、资产负债率控制都在管理层轮换中保持一致。海图判断这是"制度优于个人"的治理结构——任何 CEO 上任后都要执行"教材专营 + 主业稳健 + 高分红回报"三重要求。这是一类"政策代理人"型公司，管理层个人空间有限，但风险也有限。

A-

资本配置纪律 · 国企稀有标杆

FY2025 派息率 47.99%、累计分红 ¥47.38 亿——这是出版传媒行业"最高分红率国企"之一。
过去 9 年股息保持稳定（中期 + 末期合计），FY25 派息率从 ~46% 提升至 ~48%。
A 股发行 ¥15 亿，分红已覆盖 3 倍（¥47.38 / ¥15）—— 真正"善待股东"的国企。
Capex 长期保持 ¥6-8 亿区间（FY25 ¥6.69 亿），未启动股票回购，仅靠股息回报股东。
不足之处：在二级市场上未见过任何主动护盘动作，AH 折价 26% 长期未受管理层关注。

B

战略执行能力 · 防御 > 进攻

FY25 营收 -4.84% 主要因教材教辅减少 ¥3.46 亿（出生人口结构性逆风）+ 一般图书 -2.59%。管理层通过成本控制和投资收益对冲，让归母净利润仍 +1.53%。这是典型的"防御型国企"——在主业承压时通过财务工具维持股东回报。新业务（数字化、电商）增速良好但占比仍低（一般图书电商 ¥20.42 亿 / 占一般图书 34.75%）。海图评价：管理层能守住基本盘，但缺乏"二次曲线"。

长期主义测试：3 年前（FY22 财报）管理层承诺"分红率不低于 40% + 教材专营权续签 + 数字化转型推进"——3 年后每条都兑现：分红率 FY22 41% → FY25 48%（+7pp）、教材专营权连续续签、数字化产品 1,000+ 种。这是国企运营中"言行一致"的代表。

薪酬与利益绑定：管理层薪酬遵循国企"限薪令"，董事长年薪 ~¥80-100 万 + 业绩奖金。激励机制极弱，但战略执行力稳定。无管理层持股或股权激励——这是典型的"治理型国企"问题。

单位经济（uPodučn Economics）：教材教辅按学生人数定价（受出生人口和学位数双重影响）。一般图书按销售折扣定价（普通 60-70% 出版社折扣）。出版分部毛利率约 50%（内容版权高利润），发行分部毛利率约 30%（渠道+物流薄利），合并毛利率 35%。

产业链定位：

上游：作者+造纸厂+印刷厂+电子出版商
中游（公司）：出版分部（自有内容 + 引进版权）→ 发行分部（教材+一般图书）→ 销售网络（书店 + 电商 + 馆配）
下游：四川 + 全国学校 / 个人读者 / 图书馆 / 政府采购 / 教育机构
议价能力：上游议价能力中等（造纸价格波动）；下游对学校议价能力极强（教材专营牌照），对读者议价能力弱（电商比价）

关键商业模式特点：

1. 政策牌照护城河：四川省教材专营权（6,000+ 学校 / 500 万学生）由省教育厅授权，每 5 年续签一次。这是"准公共服务"性质，竞争对手无法进入。
2. 物理渠道网络：6,500+ 家新华书店是中国最大的出版发行物理渠道，覆盖四川 + 周边省份。在电商时代仍有价值（馆配+学校采购+教辅）。
3. 现金流稳定 + 高分红：教材业务订单可预测、现金回款好。FY25 OCF ¥10.99 亿 + ¥1.30 亿税款退税显示现金流质量优秀。
4. 净现金垫：货币资金 ¥85 亿 + 投资资产 ~¥50-60 亿，合计净金融资产超过 ¥130 亿——这是市值 ¥150 亿股票的超大安全边际。
5. 成长性弱：受出生人口下降影响，主业难有 5%+ 高增长。增长来自数字化（电子书 + 有声书 + 教育服务）但占比仍低。

模块 4 · 经济护城河分析（5 维）
A

1. 无形资产（牌照）· 宽护城河

四川省教材发行专营权——由省教育厅授权，每 5 年续签一次。这是新华文轩最强护城河：覆盖 6,000+ 学校 / 近 500 万学生 / 教材+教辅业务约 ¥43 亿 / 占总营收 36.7%。竞争对手即便资金充裕也无法进入——这是"准垄断"型护城河，与中国移动 5G 频谱牌照、中海油海上石油专营权同类型。
持久性：连续续签 20+ 年，未来 5-10 年大概率持续。

B+

2. 成本优势（渠道规模）· 窄护城河

6,500+ 家新华书店是中国最大物理书店网络。规模效应让单店配送成本显著低于其他出版物流公司。但电商时代物理渠道边际优势在缩小——一般图书 -2.59% YoY 显示电商挤压持续。教材专营仍受益渠道，但一般图书会逐步从物理向电商迁移（电商占比已 34.75%）。
持久性：未来 3-5 年仍有价值，但 10 年后可能边缘化。

B

3. 转换成本（C 端弱、B 端强）· 窄护城河

对个人读者：转换成本极低（电商比价、京东+当当随时切换）。对学校 B 端：转换成本极高（每个省内的教材发行体系都与教育厅深度绑定，学校无法跨省采购）。综合判断：B 端护城河强，C 端护城河弱。教材+教辅业务 ¥43 亿是"高黏性"，一般图书 ¥58.78 亿是"低黏性"。

C+

4. 网络效应 · 无

出版业本身没有网络效应——读者数量增多并不让出版物对其他读者更有价值。这是新华文轩最弱的护城河维度。Amazon Kindle 有微弱网络效应（评论+推荐），但新华文轩无。教育服务可能有弱网络效应（更多学校用 → 更多内容 → 更多学校用）但占比小。

B

5. 有效规模（地理垄断）· 窄护城河

四川省内出版发行行业有"自然垄断"特征——一个省一个新华文轩。但全国市场有 30+ 个新华系（中信 / 凤凰 / 北方 / 上海 / 山东等）—— 各省互不竞争。这是地理 + 政策双重垄断。新华文轩在四川省的有效规模优势明确，但跨省竞争力不强。
持久性：未来 5-10 年地理护城河持续，10 年后教育数字化可能打破地理边界。

护城河趋势 · 整体微微侵蚀（教辅压力 + 电商挤压）但牌照仍稳：5 大维度综合评分 = 1A + 2B+ + 1B + 1C+ ≈ 窄至中护城河。无形资产（牌照）极强，成本优势中，转换成本中，网络效应弱，有效规模中。10 年后会更窄还是更宽？海图判断：会"略变窄"—— 教材业务受益人口下降会缩水（-3% 至 -5%/年），但渠道护城河和成本优势稳定。这是一家"护城河窄但极稳"的公司，不会被颠覆但也不会爆发增长。

5.3 杜邦分析（FY2025）

ROE = 净利率 × 资产周转 × 权益乘数

= 13.35% × (¥117.32 / ¥235) × (¥235 / ¥157)
= 13.35% × 0.499 × 1.497
= 10.32%

解读：ROE 由 3 项构成——净利率 13.35%（中等偏好）+ 资产周转 0.499（出版业典型，慢于消费品快于地产）+ 权益乘数 1.50（极保守，反映低杠杆）。提升 ROE 的关键在权益乘数（杠杆）和资产周转——但国企不会加杠杆，所以 ROE 长期稳定在 10-12% 区间，难有突破。

货币资金 ¥85.09 亿——充裕

5.5 现金流质量

OCF/NI = ¥10.99 / ¥15.68 = 70%——略低于 100%（投资收益不产生现金）
FCF/OCF = ¥4.30 / ¥10.99 = 39%——偏低，因 Capex 占 OCF 60%
FCF Yield = ¥4.30 / ¥150 = 2.87%——一般水平
维护性 Capex 估算 ¥4-5 亿，扩张性 Capex ¥2-3 亿——后者主要投向数字化和物流仓储
评价：现金流质量中等。投资收益（¥3.8 亿）不产生现金，所以 OCF 略低于 NI，但仍是"稳定可预测"的现金流。

5.6 所有者盈余计算（核心）

所有者盈余 = 净利 + 折旧摊销 - 维护性 Capex ± 营运资金变动

= ¥15.68亿 + ¥4亿 (折旧摊销估算) - ¥4.5亿 (维护性Capex)
= ¥15.18亿

OE Yield = ¥15.18 / ¥150 = 10.12%——非常优秀

这是"长期债券替代品"的核心论据——10% 的所有者盈余收益率（vs 10 年期国债 4%、银行理财 3%、A 股大盘 5-6%），且管理层愿意以 48% 派息率分给股东（即净 4-5% 现金股息）。如果你能拿 10 年，这相当于一个 10% 收益率 + 通胀对冲的债券。

夜读手记 · 1100 字

市场永远在用"增长"的有色眼镜看公司。当一家公司营收 -4.84%、教材教辅减少 ¥3.46 亿，市场就把它当成"夕阳出版商"折价。但读懂这个数字背后的资产结构——¥132 亿净金融资产 + ¥7.53 亿分红 + 教材专营权——你会发现这是一家"低估的债券型股票"。

FY2025 营业收入 ¥117.32 亿（-4.84%）、归母净利 ¥15.68 亿（+1.53%）、扣非净利 ¥14.57 亿（-12.11%）——主业承压但仍微增。但 Q1 2026 营收降幅从 -4.84% 收窄到 -0.16%，扣非净利从 -12.11% 收窄到 -0.17%，说明结构性下滑已经被市场充分定价，主业已基本企稳。市场对新华文轩的悲观（H 股 PE 仅 7.31x、PB 0.73x、股息率 6.40%）与公司的真实资产质量（净金融资产占市值 88%、教材专营权牌照、累计分红 ¥47.38 亿）形成鲜明反差。

几个研判要点

一、SOTP 加总告诉你这是极端低估。市值 ¥150 亿 - 净金融资产 ¥132 亿 = 市场对纯运营业务的估值仅 ¥18 亿。对应 ¥15.68 亿净利的"核心 P/E 仅 1.15x"——这是不可思议的低估。即便假设 FY26-30 主业每年下滑 5%，5 年后净利 ¥12 亿，对应 ¥18 亿核心估值的 P/E 仅 1.5x，仍是极端便宜。市场在用"主业下滑"的故事掩盖"净金融资产价值"的事实。

二、H 股 PE 7.31x + 股息率 6.40% = 港股出版传媒中最便宜。同行：凤凰传媒 PE 14x / 股息率 3.5%，中国出版 PE 14x / 股息率 3%，中信出版 PE 15x / 股息率 2%。新华文轩 H 股是行业 P/E 最低、股息率最高的标的。这意味着即便股价 5 年不涨，仅靠股息复利就能获得 30%+ 累计回报。配合 AH 折价 26%，港股投资者的赔率显著优于 A 股。

三、教材专营牌照是"准公共服务"型护城河。四川省教材发行专营权由教育厅授权，每 5 年续签一次，连续 20 年从未变更。这是与中国移动 5G 频谱牌照、中海油海上石油专营权同类型的"政策护城河"。覆盖 6,000+ 学校、近 500 万学生、约 ¥43 亿教材业务——这部分业务的现金流在 5-10 年内确定性极高，不可能被任何竞争对手攻破。即便出生人口下降，教材业务也只是缓慢萎缩（每年 -3-5%），不会"断崖式"消失。

四、AH 折价 26% 是港股投资者的免费赔率。A 股 ¥13.33 = HKD 14.49（按 1 HKD = 0.92 RMB），H 股 HKD 10.75，H 折价 A 26%。同样资产，港股投资者花同样的钱可以多买 26% 的股份。配合 6.40% 股息率（vs A 股 4.50%），H 股的"持有期回报"显著优于 A 股。这是国资委双上市政策给港股投资者的"免费午餐"。

五、12 个月目标价 HKD 13.50，上行 +26%。悲观 HKD 8（-26%，主业下滑加速 + 减值）、基准 HKD 13.50（+26%，主业持平 + 派息率 50%）、乐观 HKD 16（+49%，数字化贡献 + 派息率 60%）。当前价 HKD 10.75 距首仓 HKD 9.50 仅 12% 下行空间，是合理建仓窗口。海图的判断：未来 3-5 年预期年化回报 8-12%（含股息），优于绝大多数大盘股，且波动性极低（PB 0.73x 提供下行支撑）。

风险提示

出生人口持续下降（教材业务每年 -5%）/ AI+ 短视频教育颠覆传统教材 / 教材专营权改革放开 / 国资委要求停止分红做新业务投资 / 大规模交易性金融资产减值 / 一般图书电商挤压加速——任一项都可能让股价回调 15-30%。但 ¥132 亿净金融资产 + 四川省国资委 67% 控股 + 资产负债率 33.24% 让破产概率为零，每股净资产 HKD 13.83（H 股）提供下行支撑。
