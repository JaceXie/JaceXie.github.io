# 携程集团 Trip.com（NASDAQ: TCOM / HKEX: 9961）Q4 2025 + 全年 · 海图夜读

财报里最危险的数字，往往是看起来最漂亮的那个。携程 FY2025 GAAP 净利 ¥334 亿、增长 94%、TTM P/E 只有 7 倍——一眼望去像捡钱。但夜读财报的人会先问一句：这 ¥334 亿里，有多少是真的赚来的？答案是：¥199 亿来自投资收益。看穿这一点，才算真正读懂了携程。

FY2025 净营收 ¥624 亿（+17%）、住宿 +21%、交通 +11%、调整后 EBITDA ¥189 亿（利润率 30%）、Q4 营收 +21%。这些是干净的经营数字，扎实而强劲。但 GAAP 净利 ¥334 亿里塞进了 ¥199 亿投资收益（持有的 MakeMyTrip、同程等股权公允价值变动，FY24 这一项才 ¥11 亿）。**所以 TTM P/E 7.1x 是估值假象——按核心经营算，真实 P/E 在 17x 左右**。市场对携程的悲观（股价距 52 周高 -37%、接近 52 周低）与公司扎实的核心经营形成反差，但这个反差没有"7 倍 P/E"看起来那么夸张。

## 几个研判要点

**一、必须看穿 GAAP 利润的"投资收益假象"。** 携程是一家"OTA 主业 + 投资组合"的复合体。¥199 亿投资收益是真实的资产增值，但它**不可预测、不可持续，不应计入主业估值**。真实的携程，要用调整后 EBITDA ¥189 亿、核心经营净利约 ¥130 亿来衡量。看穿这层，你会发现携程不是"7x 白菜价"，而是"核心 17x、剔净现金后 11x 的合理优质成长股"。这个认知差，是分析携程不犯错的第一关。

**二、这是一门真正的好生意。** 80.7% 毛利率、30% 调整后 EBITDA 利润率、Capex 占营收仅 2.4%——**在线旅游撮合是商业模式的优等生**。携程的护城河来自网络效应（双边平台）+ 规模优势 + 中国 OTA 寡头地位三重叠加，是中概互联网里护城河较深、较稳的标的。梁建章 + 孙洁的"原班人马"团队极稳定，疫情低谷坚持国际化战略，FY25 完全兑现。生意质量这一项，携程不输 Booking、Airbnb 这些全球巨头。

**三、双增长引擎仍在加速。** 出境游已恢复并超过疫情前——中国中产的消费升级是结构性顺风；Trip.com 国际平台在亚太高速扩张——这是携程从"中国 OTA"变成"亚洲 OTA"的第二曲线。**营收 +17%、Q4 +21% 的增速，在全球 OTA 中是最快的**（Booking +9%、Airbnb +11%、Expedia +6%），但估值（核心 17x）反而低于它们。这个差，是中概折价 + 反垄断不确定性造成的。

**四、反垄断调查是头顶的剑。** 财报披露携程正接受反垄断调查。这是评级无法给到"买入"、只能给"有条件买入"的根本原因。**参照过往中国平台反垄断——多以罚款 + 经营整改了结，少有结构性处罚**，但在结果落地前，这把剑就悬着。如果监管限制"二选一"、强制压低佣金率，携程核心盈利能力会受损。这是必须用仓位来对冲的风险。

**五、12 个月目标价 $67，上行 +34%。** 悲观 $40（-20%，反垄断重罚）、基准 $67（+34%，反垄断温和了结 + 营收双位数 + 国际化持续）、乐观 $88（+76%，反垄断无重大影响 + 国际平台爆发）。**当前价 $49.89 已到首仓 $50 附近**。海图的判断：这是一笔"好生意 + 合理估值 + 一个明确悬念"的投资——质量没问题，价格不贵，就看反垄断这只靴子怎么落地。

## 风险提示

1. **反垄断重罚 + 佣金率受限** → 概率 20%，股价跌至 $38（-24%）
2. **中国消费深度衰退** → 概率 15%，股价跌至 $40（-20%）
3. **抖音等内容平台颠覆旅游预订** → 概率 12%，中长期估值压制
4. **投资组合大幅减值** → 概率 10%，GAAP 利润账面亏损冲击情绪
5. **中概股大规模退市** → 概率 5%，股价跌至 $35（-30%）
6. **出境游放缓 / 地缘政治** → 概率 10%，增速回落

但净现金 ¥751 亿 + 80.7% 毛利率 + 宽护城河让破产概率为零，每股净资产 $38.08 + 净现金 $17/股提供下行支撑，$38-40 是较硬的估值底。

关键叙事：**"中国 OTA 龙头 + 80.7% 毛利率 + 营收 +17% 全球最快 + 净现金占市值 34% + 核心 P/E 17x 合理偏低"的组合，对垒"反垄断调查 + GAAP 利润被投资收益扭曲"的隐忧**。在多数优质平台估值不菲的当下，携程是一笔"好生意被中概折价 + 反垄断阴云双重压制"的标的——不是给只看 7x P/E 表象的人，而是给愿意看穿 GAAP 利润、理解核心经营价值、并能承受反垄断不确定性的耐心投资者。下次催化剂：2026-05-25 Q1 2026 财报 + 反垄断调查进展。
