# 富途控股 Futu Holdings（NASDAQ: FUTU）Q4 + 全年 2025 · 海图夜读

财报里最便宜的数字，往往藏着最需要追问的前提。富途 FY2025 净利 +100%、营收 +68%、P/E 只有 12 倍——一眼望去像捡钱。但夜读财报的人会先问一句：这份盈利，有多少是公司赚的，有多少是牛市给的？答案是：FY2025 全年交易量 +89%，是一个不折不扣的峰值年。

富途是中国互联网券商出海最成功的代表——moomoo 在海外、富途牛牛在港澳，靠交易佣金（46%）、利息（46%）、财富管理（8%）三块赚钱。FY2025 入金客户 337 万（+40%）、客户资产 HK$1.23 万亿（+66%）。这是一门轻资产、49.5% 净利率、28% ROE 的好生意——但它带着三重折价。

## 几个研判要点

**一、12x P/E 是"12 倍峰值盈利"。** FY2025 是港股 IPO 大年 + 美股牛市 + 港股通活跃的多重叠加，交易量 +89%。券商佣金与市场情绪强相关——牛市暴增、熊市骤降。**用中周期正常化盈利看，富途的真实 P/E 在 16-18x**——仍不贵（对 +25%+ 结构性增长），但远没有"12x 白菜价"那么诱人。看富途，必须把"结构性用户增长"和"周期性交易放大"分开。

**二、商业模式正在从"靠佣金"转向"靠利息 + 客户资产"。** FY2025 利息收入 HK$104 亿首次与佣金 HK$106 亿几乎持平。利息（融资融券 + 闲置资金利差）比佣金稳定得多，随客户资产规模增长而增长——**这是富途盈利质量提升的关键**，让它没那么"靠天吃饭"。

**三、2022 年的伤疤，变成了全球化的契机。** 2022 年底中国证监会禁止富途拓展内地新客，市场一度认为故事终结。3 年后，富途用 moomoo 在美、新、日、马、澳、加的扩张，把营收做到 HK$228 亿。**被堵死内地后，反而逼出了一个更大、更分散、监管风险更低的全球客户基础**——这是管理层最被低估的执行力。

**四、首次资本返还是"零的突破"，但别当主逻辑。** 2026-04 富途首次派特别股息 $2.6/ADS（约 $365M）+ 启动 $500M 回购。这标志一家成长公司开始有"还钱给股东"的意识。**但特别股息是一次性的、回购刚启动**——含金量待验证。买富途，赌的还是用户增长 + 全球化，不是收息。

**五、12 个月目标价 $160，上行 +28%。** 悲观 $100（-20%，熊市 + 监管）、基准 $160（+28%，增速放缓 + 正常化估值）、乐观 $210（+69%，市场活跃 + 估值重估）。概率加权 $160。**当前 $124.50 已低于机械首仓 $128——进入合理建仓窗口**。但这是一只高 Beta 的券商股，建议小仓位起步、回调加仓。

## 海图研判

**评级：有条件买入**（12x 表观估值 + 49.5% 净利率 + 28% ROE + 全球化兑现 + 首次资本返还，但盈利含牛市峰值成分 + 中概监管 + Tencent 减持 + 券商周期性）

12 个月概率加权目标价：**$160**（+28%）

- 乐观（30%）：$210 — 市场维持活跃 + 全球化加速 + 资本返还常态化 + 估值重估至 16x
- 基准（45%）：$160 — 增速放缓至 +25% + 交易量正常化 + 估值 13-14x 正常化盈利
- 悲观（25%）：$100 — 港美股熊市 + 交易量腰斩 + 中概监管 / Tencent 减持冲击

**操作建议**（独立估值中位数 $160，加权公允 $160）：

当前价 $124.50 已低于机械首仓位 $128，进入合理建仓窗口：

- 首仓 **$128**（估值中位数 × 80%，距现价 +3%，已到附近——可建仓）
- 二仓 **$112**（× 70%，距现价 -10%，回调加仓）
- 三仓 **$96**（× 60%，距现价 -23%，熊市极端机会）

止盈三档：**$185 / $210 / $250**（每档减仓 25%，最后 25% 视全球化进展决定去留）

建议总仓位 **3-6%**（中等偏低 · 反映券商周期性 + 中概监管 + Tencent 减持）。这是一笔"高 Beta 成长 + 价值"标的——建议先小仓位建仓，跌到二仓 / 三仓再加。**持有周期 2-4 年**，目标是"穿越一轮牛熊后的用户复利兑现"。关键纪律：不在牛市峰值用峰值盈利买入、不因周期性回调恐慌割肉。

## 风险提示

1. **港美股大幅熊市（交易量腰斩、佣金大跌）** → 概率 25%，股价跌至 $90-100
2. **中概监管 / 美国金融限制升级** → 概率 15%，全球化逻辑受损，股价跌至 $85
3. **Tencent 大额清仓式减持** → 概率 15%，33% 持股是巨大供给压力
4. **融资融券坏账 / 风控事件** → 概率 5%，极端市场下爆仓 / 穿仓
5. **券商盈利周期性回落** → FY2025 峰值盈利不可外推
6. **ADR 退市尾部风险** → 中概共性问题

但净利率 49.5% + 即便熊市仍盈利（利息压舱）+ 每股净资产 ~$37 提供下行支撑，$90-100 是较硬的估值底（52 周低 + P/B ~2.5x）。

关键叙事：**"中国出海最成功券商 + 营收 +68% + 净利率 49.5% + 客户资产 HK$1.23 万亿 + 12x 表观 P/E + 首次资本返还"的强势组合，对垒"牛市峰值盈利 + 中概监管 + Tencent 减持 + 券商周期性"的三重折价**。富途是一笔"好生意被周期性 + 中概身份双重打折"的标的——不是给追求确定性的人，而是给愿意看穿峰值盈利、能承受高波动、并理解全球化长期价值的逆向投资者。下次催化剂：2026-05-28 Q1 2026 财报。
