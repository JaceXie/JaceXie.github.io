本季必看 · 两个"看穿"：会员费才是利润引擎、毛利率 -21bps 别误读

Costco 的利润表有两个必须"看穿"的地方，看不穿就会把它误读成一家"3% 净利率的普通超市"。

看穿一：会员费才是真正的利润引擎，商品零售基本"以成本价卖货换客流"。 很多人看到 Costco 净利率只有约 3%，就以为它是薄利的普通零售商。真相是——会员费仅占营收 1.9%，却贡献了约 49% 的营业利润，且几乎 100% 落入利润。剔除会员费后，商品零售的经营利润率只有约 2%。Costco 的本质是"用近乎成本价的商品供养一家会员费订阅公司"，$31.57 亿递延会员费更是一笔类似保险浮存的无息负债。

看穿二：报告毛利率 -21bps 看着走低，真相是"经营杠杆压过了毛利微降"。 报告口径商品毛利率 11.04% 同比 -21bps，容易被误读成"利润率恶化"。但拆开看：-21bps 主因是油价拖累（低毛利、高单价的加油业务稀释毛利率），剔除油价后反而 +1bp；真正反映商品经营的 core-on-core 仅 -9bps（生鲜/食品杂货毛利走低 + 油价推高运输成本），LIFO 还贡献 +14bps 利好。同时 SG&A 率压降 20bps 体现清晰的经营杠杆——于是经营利润仍 +11.3%、净利 +15.2%、EPS +15.2%。营收与 EPS 增速连续三季加速（营收 +8.2%→+9.1%→+11.6%；EPS +11.4%→+13.9%→+15.2%），这是一台运转极顺的复利机器，而非利润率恶化的普通超市。

模块 1 · 公司概览与背景

Costco Wholesale Corporation 好市多（NASDAQ: COST），总部华盛顿州 Issaquah。前身 Price Club（1976）与 Costco（1983）于 1993 年合并，是全球最大的会员制仓储量贩零售商。财年截至 8 月最后一个周日，FY2026 止于 2026-08-30；本报告为 Q3 FY2026（12 周截至 2026-05-10）。

核心叙事：Costco 的生意可以用一句话说清——它几乎以成本价把海量精选商品卖给会员，只为收取一年一交的会员费，再靠 92% 的续费率把这笔会员费变成一台"浮存收费机"。截至发布日 931 家门店（美国及波多黎各 639、加拿大 115、墨西哥 43、日本 37、英国 29、韩国 20、澳大利亚 15、台湾 14、中国 7 等），付费会员 8290 万、持卡人总数 1.49 亿。这是一门商品毛利率被死死压在约 11%、净利率仅约 3%、却靠会员费 + 极高周转 + ~30% ROIC 实现长期复利的独特零售模式。

三大增长引擎：

  • 同店销售（Comp）——全公司 comp +9.8%（剔除油价/汇率 +6.6%），客流 +2.4% + 客单 +7.3% 双轮驱动，是基本盘
  • 会员费（Membership）——+10.7% 至 $13.73 亿，行政会员 +9.6%、续费率 92.2%，是高毛利现金流核心
  • 数字化 / 电商——数字化 comp +21.5%、站点/App 流量 +37%、AI 搜索三位数增长，给实体护城河装上新引擎

股权与治理：单一 A 类普通股结构，无双重股权，摊薄股数常年稳定在约 4.445 亿股。2019 年已回购台湾子公司少数权益，故全部净利归属于 Costco。治理稳健、无关联交易疑点、无 VIE 结构（美股直接持股）。

能力圈检验：会员制仓储零售是极清晰、极易理解的顶级好生意（一句话能说清怎么赚钱）。唯一的"黑箱"不在生意本身，而在价格——市场长期给予 Costco 40-50x 的市盈率，任何对"该给多少倍"的判断都带有主观性。此外，Section 301 关税退款、油价波动对毛利率的短期扰动，是需持续跟踪的次要变量。

模块 2 · 管理层评估
A-

Ron Vachris · CEO（2024 年 1 月至今） + Gary Millerchip · CFO

Vachris 1982 年从加油站员工起步、40 余年内部晋升至 CEO，是 Costco"从内部培养、文化极稳"传统的化身，接替传奇 CEO Craig Jelinek。CFO Millerchip 2023 年由 Kroger 加入。管理层务实、克制、不喜促销式沟通——电话会坦诚披露 core-on-core 毛利走低、付费会员增速"正常化"至 +4.1%、门店下调等中性信息，不粉饰。战略上专注"性价比飞轮 + 会员价值 + 有节奏的全球开店（每年净新开 30+ 家目标）+ 数字化补强"，几十年如一日不追风口。海图判断：这是一支把"守住会员信任"置于短期财报之上的经理人团队。

A-

资本配置 · 高 ROIC 再投资 + 克制回购 + 周期性特别股息

再投资优先：把绝大多数现金投入高 ROIC（~30%）的新店扩张与供应链，FY2026 资本开支约 $65 亿，这是最好的资本用途。
回购极其克制：过去三年摊薄股数几乎不变（4.445 亿股），回购规模仅够抵消 RSU 稀释——Costco 刻意不在高估值下大额回购自家股票，这是纪律而非缺陷。
分红为主 + 特别股息：常规季度股息刚从 $1.30 上调至 $1.47（+13%），并有派发大额特别股息传统（2024 年 1 月派 $15/股，约 $67 亿）。当现金堆积时以特别股息一次性返还，而非高位回购——教科书式的资本配置克制。

长期主义测试：✅ Costco 是长期主义的标杆——数十年坚持"把省下的钱还给会员"的低毛利飞轮，宁可牺牲短期毛利也要维护会员信任（Q2 曾主动承诺将 Section 301 关税退款返还会员）。坦诚度：电话会披露详尽，主动说明毛利结构、增速正常化、门店节奏调整。利益绑定：管理层持股比例不高（成熟大盘股常态），但内部晋升文化 + 长期薪酬与经营指标挂钩，价值观高度一致。

模块 3 · 商业模式深度解析

海图"一句话测试"：Costco 几乎以成本价把精选商品卖给会员——商品零售只赚约 2% 的经营利润率，真正的钱来自一年一交、续费率 92% 的会员费，这笔近乎 100% 毛利的"浮存收费"贡献了约一半营业利润。

飞轮机制：低价 → 吸引会员 → 会员费 + 巨大采购量 → 向供应商压价 → 更低价 → 更多会员。Costco 把商品加价率硬性封顶（多数 ≤14%、Kirkland 自有品牌更低），主动放弃商品毛利，用"极致性价比"锁住会员，再从会员费和规模周转里赚钱。SKU 精简（约 3,800 个 vs 沃尔玛数万个）+ 大包装 + 寻宝式陈列带来极高的单店周转和存货效率（存货 $194 亿、周转极快）。

模块 4 · 经济护城河分析（5 维）
1. 成本/规模优势
极宽

约 $2,880 亿年采购量 + SKU 精简 + Kirkland 自有品牌 → 全行业最低进货价，别人无法在同等价格下盈利。趋势：加宽（规模仍在增长）。

2. 转换成本 / 会员黏性
宽

92% 续费率 + 会员费沉没成本 + "回本心理"驱动多消费。会员一旦习惯即极难离开。趋势：稳定偏加宽（数字化提升黏性）。

3. 无形资产 / 品牌
宽

"Costco = 极致性价比 + 品质可信"的品牌认知 + Kirkland 已成独立强品牌。信任是数十年让利积累的结果。趋势：稳定。

4. 网络效应
中

会员规模 → 采购议价 → 更低价 → 更多会员的"准网络效应"，但弱于平台型双边网络。趋势：稳定。

5. 有效规模
宽

仓储会员制赛道在多数市场只能容纳少数玩家（美国 Costco/Sam's Club/BJ's），Costco 单店效率碾压。趋势：稳定。

10 年后护城河会更宽还是更窄？ 大概率更宽。成本优势随采购规模扩大而增强，会员黏性随数字化（个性化推荐带 ~$50 亿电商、转化率 3 倍）而加深，Kirkland 品牌力持续上行。与许多零售商被电商颠覆不同，Costco 的"寻宝式线下体验 + 极致低价 + 会员费商业模式"很难被亚马逊等纯电商复制——亚马逊可以更便利，但难以更便宜，而 Costco 把"便宜 + 品质"做到了极致。真正的慢变量是海外扩张（中国、日本仍处早期）能否复制美国的单店经济。

定价权：独特——Costco 的"定价权"体现在克制不涨价上（主动让利换黏性），会员费涨价谨慎（2024 年 9 月美加涨价，约贡献会员收入增长的 1/4 强，剔除后仍 +7%）。这种"反向定价权"正是其护城河最深的地方。

5.5 所有者盈余（价值投资口径 · FY2026E）

所有者盈余 = 净利润 + 折旧摊销 + SBC − 维护性 Capex ± 营运资金变动

FY2026E 净利 ~$9.1B + D&A ~$2.6B + SBC ~$1.05B − 维护性 Capex ~$2.5B（总 Capex ~$6.5B 中约 $3.7B 为扩张性新店）± 营运资金 ≈ 所有者盈余 ~$9.5-10.0B。这明显高于报告 FCF ~$8.8B——差额正是被"高 ROIC 扩张性 Capex"消耗的部分。

所有者盈余收益率 = ~$9.5B / 市值 $405B ≈ 2.35%——这是一个"顶级质量 + 极致估值"的收益率。2.35% 的收益率对一个 +12% 营收、~30% ROIC、会员浮存护城河的公司，反映市场已把未来十年近乎完美的执行提前定价。换句话说：Costco 的问题从来不是生意好不好，而是价格贵不贵——当前 2.35% 的所有者盈余收益率意味着几乎没有安全边际。

  • 新进入者：低（规模采购 + 会员信任 + 单店经济需数十年积累）
  • 替代品：中（亚马逊/沃尔玛便利，但难更便宜；电商难复制寻宝体验）
  • 供应商议价：极低（Costco 巨量采购 + Kirkland 自有品牌拥有绝对议价力）
  • 买家（会员）议价：低（Costco 主动让利，会员黏性极高、续费率 92%）
  • 同业竞争：中（Sam's/BJ's 存在，但 Costco 单店效率碾压，理性竞争）

下行支撑：世界级生意 + ~30% ROIC + 净现金 $14.2B + 会员浮存 + 自有约 80% 地产（隐性资产）构成质量底。$700-745 是内在价值支撑区（对应 ~31-33x FY26 EPS，接近历史正常premium下限）。但要注意：Costco 的"底"比多数股票高，因为市场对其质量的溢价难以完全消失——这既是保护，也意味着"便宜"的机会很稀少。

模块 12 · 股东回报分析

Costco 的股东回报有一个独特结构：回购极其克制（仅抵消稀释），真正的返还靠分红——常规增息 + 周期性大额特别股息。理解这一点，才能正确评估它的"含金量"。

12.2 给的方式好不好？

  • 回购含金量打折：摊薄股数 FY2023 444,452k → FY2024 444,759k → FY2025 444,803k → Q3 FY2026 444,430k——常年几乎不变。回购规模仅够抵消 RSU 稀释，Costco 并不通过回购缩股，本质是"用现金对冲 SBC 稀释"，而非真实减少股本。这一点上，回购的含金量确实打折。
  • 但克制是纪律，不是缺陷：关键在于——Costco 刻意不在 40x+ 的高估值下大额回购自家股票。FY2025 回购均价 $945、Q3 回购均价 $997.47 都在高位小额进行。对一家股价常年高估的公司，"少回购、把现金投入高 ROIC 新店 + 用特别股息返还"是更聪明的资本配置，避免了高位回购摧毁股东价值。
  • 股息才是主菜：常规股息累进增长（+13%）+ 周期性大额特别股息（$15/股 in 2024、历史多次），这部分是真金白银、含金量高。分红型返还 + 高 ROIC 再投资，是 Costco 返还结构的本质。

12.3 能不能继续给、给多少？

  • 可持续性极强：常规股息年化约 $2.6B vs FCF ~$8.8B——(股息+回购)/FCF 覆盖度仅约 40%，覆盖极其充分，增息与特别股息空间巨大。净现金 $14.2B 是特别股息的"弹药库"。
  • 非借债回购：净现金 +$14.2B，返还完全来自内生 FCF 与现金储备，绝非举债——与"杠杆化返还"的公司截然不同，安全度极高。
  • 回购授权（约束力有限）：剩余授权 $1,359M（总授权 $4,000M，2027 年 1 月到期）——额度不大，也印证 Costco 并不把回购当主要工具。真正的"大招"是特别股息。
  • 周期择时优：把现金留到堆积后以特别股息一次性派发，而非在高位持续回购，择时纪律优秀。

模块小结：积极且高含金量，但结构特殊——分红为主、回购象征性。常规年度股东收益率偏低（~0.76%），回购仅抵消稀释（含金量打折），但这恰是"不在高估值下摧毁价值"的资本配置纪律；真正的返还靠常规增息（+13%）+ 周期性大额特别股息 + 高 ROIC 再投资，且 FCF 覆盖度仅约 40%、净现金 $14.2B、无任何借债——可持续性在全市场居前列。对价值投资者而言，这是一份"克制、诚实、可持续"的资本配置答卷。

海图
夜读手记 · 1150 字

价值投资里最难的一课，不是看懂烂生意，而是面对一门好到极致的生意时，忍住不为它付任何价格。好市多就是这样一台机器：它几乎以成本价把货卖给你，只为收你一年一百多美元的会员费——而全球有 8290 万个家庭心甘情愿地续着，续费率 92%。Q3 营收 +11.6%、EPS +15.2%，连续三个季度加速，数字化 +21.5%，手握逾 140 亿美元净现金。业绩挑不出任何毛病。问题，永远只在价格。

好市多是全球最大的会员制仓储零售商。它的生意可以用一句话说清：用极致低毛利（商品加价率被死死压在约 11%）换取会员的绝对忠诚，再靠一年一交的会员费当"浮存收费机"，赚走近一半的营业利润。Q3 FY2026 净销售 $691.5 亿（+11.6%）、会员费 $13.73 亿（+10.7%）、经营利润 $28.15 亿（+11.3%）、GAAP 净利 $21.92 亿（+15.2%）、摊薄 EPS $4.93。

几个研判要点

一、会员费才是利润引擎，别被 3% 的净利率骗了。 好市多商品零售的经营利润率只有约 2%——它基本是"以接近成本价卖货换客流"。真正赚钱的是会员费：仅占营收 1.9%，却贡献了约 49% 的营业利润，且几乎 100% 落到利润。$31.57 亿递延会员费是一笔无息"浮存"，加上应付账款大于存货的负营运资金，等于供应商和会员在为它的运营免费融资。理解好市多，要把它看成一家"用零售流量供养的会员费订阅公司"。

二、毛利率 -21bps 别误读，真相是经营杠杆压过了毛利微降。 报告口径毛利率 11.04% 同比 -21bps 看着走低，但主因是油价拖累——剔除油价后 +1bp，核心 core-on-core 仅 -9bps。同时 SG&A 率压降 20bps 体现经营杠杆，于是经营利润仍 +11.3%、EPS +15.2%。营收与 EPS 增速连续三季加速（营收 +8.2%→+11.6%；EPS +11.4%→+15.2%），这是一台运转极顺的复利机器，而非利润率恶化的普通超市。

三、这是"净现金"公司，且资本配置克制得罕见。 剔除会员浮存与租赁后，好市多仍手握逾 140 亿美元净现金。但它几乎不用回购缩股——过去三年摊薄股数稳定在 4.445 亿股几乎不变，回购规模仅够抵消 RSU 稀释。它的返还主要靠分红：常规季度股息刚上调 13% 至 $1.47，外加周期性大额特别股息（2024 年 1 月派过 $15/股）。管理层把绝大多数现金再投入高 ROIC（约 30%）的新店扩张，而不是在 40 倍估值下回购自家昂贵股票——这恰恰是资本配置纪律的体现，而非缺陷。

四、护城河在加宽，不是在收窄。 规模采购 + 会员锁定 + Kirkland 自有品牌 + "寻宝式"体验构成宽护城河。数字化 comp +21.5%、站点/App 流量 +37%、个性化推荐带来约 $50 亿电商销售（转化率三倍）、AI 搜索三位数增长——数字化正在给这条实体护城河装上新引擎。行政会员 +9.6% 至 4120 万，续费率 92.2% 环比还在 +10bps。亚马逊可以更便利，但难以更便宜；而好市多把"便宜 + 品质"做到了极致。

五、内在价值约 $745，现价 $914——溢价约两成，负安全边际。 我用 8 种方法独立估值（DCF 基准 $763、相对 P/E $770、SOTP $685、所有者盈余收益率 $655……），加权中位约 $745。当前 46x TTM 市盈率 / 40x 前瞻 / 2.2% FCF 收益率——这是把"近乎完美的十年执行"提前定价的水平。反向 DCF 显示现价隐含约 13-14% 的所有者盈余增速要持续十年，容错空间极薄。股价虽已从 $1,096 的高点回落 17%，但对价值投资者仍不够便宜。

海图研判

评级：持有观望（全球会员制零售之王 + 92% 续费率的浮存收费机 + 高 ROIC 复利 + 逾 140 亿净现金的顶级组合，对垒 46x TTM 市盈率、2.2% FCF 收益率、现价高于内在价值约两成的极致估值）。12 个月概率加权目标价 $845（−8%），叠加 0.64% 股息，预期总回报为负——业绩会继续好，但价格已透支。

操作建议：当前 $913.94 不在合理建仓窗口。以内在价值中位 $745 为锚，首仓 $596（×80%）、二仓 $522（×70%）、三仓 $447（×60%）——耐心等一次真正的估值回归或市场恐慌。止盈三档 $1,020 / $1,120 / $1,220，最后 25% 长期复利持有。建议观察仓位 0-2%，现有持仓者可继续持有让它复利，新买入者必须等安全边际。持有周期 5-10 年。关键纪律：好生意也要好价格，好市多尤其如此——它极少便宜。

风险提示

消费降级 / 油价与生鲜毛利波动 / 关税 / 会员增速放缓至 +4% 的"正常化" / 最重要的——满估值下任何增速放缓都可能触发多重压缩，股价回落 $700 附近并不夸张。但净现金 $14.2 亿美元、强劲 FCF、会员浮存与自有约 80% 地产构成较硬的质量底，$700-745 是内在价值支撑区。好市多的"底"比多数股票高，因为市场对其质量的溢价难以完全消失——这既是保护，也意味着"便宜"的机会很稀少。

关键叙事：一门几乎无可挑剔的会员制复利生意，对垒一个几乎无可辩护的估值。好市多的问题从来不是生意好不好，而是价格贵不贵——它极少便宜，而现在依然不便宜。它不是给追求便宜货的人，而是给愿意在回调时耐心建仓、然后让一台顶级复利机器慢慢滚雪球的长期投资者。下次催化剂：2026-09-25 前后 Q4/FY2026 财报。
