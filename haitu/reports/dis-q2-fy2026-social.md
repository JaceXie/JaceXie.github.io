# 华特迪士尼 DIS · Q2 FY2026 海图夜读手记

价值投资里最考验耐心的，不是烂生意配低价格，而是好资产配着一堆待解的问号。迪士尼现在就是这样：全球最强的 IP 宝库、创纪录的乐园、终于赚钱的流媒体，可股价却趴在 52 周低点 $95 附近，前瞻市盈率只有 13.9 倍——市场把它当成了一家衰退的传统媒体，而不是一台正在换挡的印钞机。

迪士尼靠一件事赚钱：把米老鼠、漫威、星战、皮克斯、ESPN 这些独一无二的 IP 创造一次，然后在流媒体、影院、乐园、邮轮、消费品上反复变现。这个"IP 飞轮"里，乐园与体验是利润引擎（Q2 贡献 57% 分部利润），流媒体是刚扭亏的新增长极，线性电视则是正在退潮的旧钱袋。

## 几个研判要点

**一、流媒体真的转正了。** 娱乐 SVOD（Disney+/Hulu）本季经营利润 $5.82 亿、同比 +88%，利润率首次上双位数到 10.6%，营收 +13%。这不是昙花一现——管理层指引全年 SVOD 利润率至少 10%。当年那个"烧钱换订户"的故事，正在变成"利润率爬坡"的故事，逻辑和奈飞如出一辙。

**二、乐园还是那台印钞机。** Experiences 本季营收 $94.9 亿、利润 $26.2 亿双双创 Q2 历史新高，国内人均消费 +5%。新邮轮 Disney Adventure 在新加坡下水、预订强劲。虽然国内客流 -1%、且新项目开业前费用拖累约 2 个百分点，但需求底子健康，管理层预期 Q3 客流环比改善。

**三、别被 GAAP 吓到，也别被它骗到。** GAAP 摊薄 EPS $1.27、同比 -30%，吓人——但去年同期含一笔 +$1.02/股的一次性税务和解利好，是高基数作祟。看调整后 EPS $1.57、+8% 才是真相。反过来，别忘了迪士尼是净负债公司：现金 $56.8 亿 vs 有息负债 $473.6 亿，真实净负债约 $417 亿，不是"现金堡垒"。

**四、自由现金流在重投资周期里被压扁了。** H1 经营现金流 $76.5 亿、同比降 $23 亿（高额税款 + 内容支出），FCF 只剩 $26.6 亿（去年 $56.3 亿），主因资本开支飙到 $49.9 亿——邮轮、新景点、$600 亿十年扩园计划正在花钱。这是"为未来花钱"的成长性 capex，但短期确实吃掉了现金，也让资本返还暂时超过 FCF。

**五、便宜，但要的是耐心不是勇气。** 前瞻市盈率 13.9 倍，对一家拥有全球最强 IP + 乐园护城河、流媒体刚转正的公司，明显不贵；分析师平均目标价 $129.67 也远在现价之上。但独立估值中位数约 $108，距现价只有约 12% 空间——够便宜到"有意思"，还不够便宜到"安全边际 25%"的买入门槛。叠加 CEO 刚换届（D'Amaro 三月接任）、重 capex 周期、线性衰退，我不给它"买入"，只给"有条件买入"。

## 海图研判

**评级：有条件买入**（IP 飞轮 + 创纪录乐园 + 流媒体扭亏为盈的一流资产，对垒线性电视衰退 + 重资本周期压 FCF + CEO 换届未验证 + 估值未达 25% 安全边际）。12 个月概率加权目标价 **$108**（+13%），叠加 ~1.6% 股息。

操作：独立估值中位数 $108，机械首仓 = $108×80% ≈ $86，二仓 ×70% ≈ $76，三仓 ×60% ≈ $65。当前 $95.62 在首仓上方——**建仓的"条件"有二：等回调至 $86 附近给出安全边际，或等 FCF 回升 + 流媒体利润率兑现的确认信号**。已持有者可穿越 capex 周期继续持有。止盈三档 $125 / $145 / $165，最后 25% 长期持有。建议仓位 3-5%（换挡期的一流资产，宜小仓起步、确认加仓），持有周期 3-5 年。

## 风险提示

线性电视加速衰退、乐园遭遇消费衰退、Sports 版权费上升挤压 ESPN 利润（Q3 指引 -14%）、重 capex 拖累 FCF 更久、CEO 换届执行不及预期——任一项都可能把股价压回 $82 附近。但全球最强 IP + 创纪录乐园 + $417 亿资产净值托底，**$85-90 是较硬的估值底**（52 周低 $92.19 + 前瞻 P/E 11x 下限）。

关键叙事：**一台"IP 飞轮 + 乐园印钞机 + 流媒体扭亏"的一流复利机器，正在为线性衰退、重投资周期与新帅换届支付"转型折价"——这折价里，藏着耐心投资者的机会**。迪士尼不是给追热点的人，它是给愿意在低位分批、留足安全边际、然后陪它把多引擎慢慢跑顺的长期投资者。下次催化剂：约 2026-08-05 Q3 FY2026 财报。
