模块 1 · 公司概览与背景

公司全称：Amazon.com, Inc.（亚马逊公司）
上市：NASDAQ: AMZN（1997-05-15 上市）
总部：华盛顿州西雅图
主营：全球电商 + 云计算 + 广告 + 订阅 + AI 基础设施的复合体

核心叙事：亚马逊是过去 30 年技术史上最成功的"飞轮型"公司——从在线书店 → 全品类电商 → 云计算（AWS）→ 广告业务 → 自研芯片 → AI 基础设施。关键差异化：AWS 占营收仅 21% 但贡献集团 60% 营业利润，是真正的"利润引擎 + 现金机器"。Q1 2026 AWS 重新加速到 +28%（15 季度最快），结合营业利润率 13.1% 历史新高 + 广告 +24%，亚马逊正在从"电商公司"完成最后一步重估为"AI 基础设施 + 高利润率平台"。

简史与里程碑：

1. 1994 年成立——Jeff Bezos 在西雅图车库创立，1995 年上线
2. 2002 年启动 AWS——内部基础设施外化为商业产品
3. 2007 年 Kindle + 2014 年 Echo / Alexa——硬件入口
4. 2016 年 Prime 会员破亿 + 2017 年收购 Whole Foods $13.7B
5. 2021 年 7 月 Andy Jassy 接任 CEO，Bezos 转任执行主席
6. 2023 年 ChatGPT 时刻——AWS 增速从 +12% 见底，开始恢复
7. 2024-2025 年 Trainium 自研芯片放量——成本比 H100 低 40%
8. 2026 Q1 AWS +28%——15 季度最快增速，AI 红利真实兑现

股权结构（2026Q1 末）：

Jeff Bezos（创始人/前 CEO）——~9% 股权（持续减持）
Vanguard——~7.5%
BlackRock——~6%
Andy Jassy（CEO）——~0.02%
这是典型的"分散持股 + 职业经理人"治理结构，Jeff Bezos 仍是最大单一股东但已转入"半退休"状态

模块 2 · 管理层评估
A

Andy Jassy · CEO（2021-07 至今 · 5 年）

1968 年生，1997 年加入 Amazon，2003 年创立 AWS 团队，2021 年接任 Bezos。Jassy 是 AWS 之父——把 AWS 从内部基础设施变成 $150B+ 的全球第一公有云。任 CEO 后他做了三个关键决定：(1) 2022-2023 大规模成本优化（裁员 2 万 +）→ 2024 营业利润率从 4% 跳升到 11%；(2) 2024 加速自研芯片 Trainium → 2026 Q1 +100% YoY；(3) 2025-2026 大幅 Capex 投入 AI 基础设施 → 撑起 AWS +28% 加速。每一步都领先竞争对手。

A

Brian Olsavsky · CFO（2015 至今 · 11 年）

科技业最受推崇的 CFO 之一。资本配置纪律严格——Capex 上修每次都附详尽的需求论据（Q1 称"AWS 客户排队等算力"）。指引兑现度连续 16 个季度 100%——这是科技股中最高的。

A-

资本配置纪律 · 顶级（但有争议）

不分红、不回购——亚马逊把每一分钱都再投入业务（仓储、物流、AWS、AI 芯片）。
过去 5 年累计 Capex $400B+（FY26 单年就 $180-200B）。
关键并购：MGM $8.45B (2021)、One Medical $3.9B (2022)、iRobot 已撤销、Anthropic $8B 战略投资 (2023-24)。
每一笔大额并购/投资都为长期战略服务，没有盲目多元化。
争议：Q1 2026 单季 Capex $43.2B 是激进赌注。如果 AWS 增速回落，FCF 会负。

长期主义测试：3 年前（FY23 财报）Jassy 承诺"成本优化 + AWS 重回 +20% 增速 + 广告业务高速增长"——3 年后每条都兑现并超额：成本优化让营业利润率从 4% 升至 13.1%（创新高）、AWS 从 +12% 加速到 +28%（15 季度最快）、广告 +24%。这是少有的"言行一致 + 大规模执行力"组合。

薪酬与利益绑定：Jassy 年薪 ~$30M（基本 $1M + $29M 股权激励，10 年归属周期）。Bezos 持股 9% + Jassy 长期激励让管理层与小股东利益绑定良好。

商业模式核心特征：

1. "低利润率高周转"零售 + "高利润率"AWS/广告——Q1 整体营业利润率 13.1% 但 AWS 单独 37.7%
2. "飞轮"商业模式：低价吸引用户 → 用户聚集 → 第三方卖家进入 → SKU 增多 → 低价更便宜（成本摊薄）→ 循环加深
3. AWS 60% 利润占比：Q1 AWS $14.16B / 整体 $23.9B = 59% 营业利润占比
4. 广告业务隐藏价值：$17.2B 季度 = $69B 年化运行率，毛利率 70%+，是真正的"印钞机"

单位经济（Q1 2026）：

营收 → 毛利率 ~50%（含 AWS 高毛利）
毛利 → 营业利润率 13.1%（历史新高）
营业利润 → 净利率 16.7%（含投资收益）
净利 → OCF ~5x（应付占款充足，1P 模式现金特征）
OCF → FCF 1%（被 Capex 严重压缩）

模块 4 · 经济护城河分析（5 维）
1. 网络效应
宽

双边电商网络效应：用户越多 → 卖家越多 → SKU 越多 → 用户更愿意来。AWS 网络效应：客户基数大 + 数据中心规模 = 单位成本最低 + 服务最齐全。趋势：加宽中。

2. 转换成本
宽

Prime 会员（2 亿+）+ AWS 长期合同（3-7 年）+ Trainium/Inferentia 芯片技术栈深度整合。企业从 AWS 切到 Azure/GCP 需要数百万美元 + 6-12 月迁移成本。这是亚马逊最深的护城河之一。趋势：稳定。

3. 成本优势
宽

全球 1,800+ 物流中心 + 自有运输车队 + 自研芯片让单包裹/单 AI 训练成本低于行业 30-40%。Trainium 芯片比 NVIDIA H100 训练成本低 40%。趋势：稳定+。

4. 无形资产
宽

Amazon 品牌（全球 #1 电商）+ Prime（2 亿粘性会员）+ Alexa（4 亿激活设备）+ AWS 品牌（B2B 云第一名）。趋势：稳定。

5. 有效规模
窄

云计算市场 CR3 = AWS 30% + Azure 24% + GCP 17% = 71%——寡头市场但非垄断。AI 领域更激烈（Anthropic 自家、Mistral、xAI 竞争）。趋势：略竞争加剧。

护城河综合评估：亚马逊在 5 维护城河上 4 项宽 + 1 项窄。整体属于"宽护城河 + 持续加宽"型公司，与 GOOGL、MSFT、AAPL 同档。

10 年后的护城河会更宽还是更窄？—— 海图判断略加宽。理由：(1) AI 时代企业对"全栈一站式"需求增加（亚马逊提供端到端：Trainium 芯片 + Bedrock 模型 + AWS 基础设施）；(2) Prime 会员体系继续加深用户粘性；(3) 广告业务的"封闭花园"在 cookie deprecation 时代价值更高。但要警惕：监管（FTC 反垄断诉讼）+ Anthropic/OpenAI 等独立模型公司的竞争。

5.3 杜邦分析

FY2025 TTM ROE 22% 拆解：
净利率（10.5%）× 总资产周转率（1.18x）× 财务杠杆（1.78x）= 22.0%

对比 FY2022（ROE -2%）：
净利率从 -0.5% 升至 10.5%（→ AWS 利润率扩张 + 成本优化 + 广告高速增长）
总资产周转率从 1.10x 升至 1.18x（→ 资产利用率改善）
财务杠杆从 2.0x 降至 1.78x（→ 现金积累快于负债）
ROE 大幅改善的核心是"营业利润率从 2.4% → 11.6%"——这是过去 4 年最大的转折。

5.6 所有者盈余计算（价值投资核心估值法）

LTM 所有者盈余 = $79B（GAAP 净利）+ $50B（折旧摊销）+ $25B（股权激励）- $80B（维护性 Capex 估，约总 Capex $147B 的 54%）+ 营运资金 -$8B = $66B（约 $66B）

注：亚马逊 Capex 中约 50-55% 是 AI 扩张性 Capex（数据中心新建 + 芯片研发），约 45-50% 是维护性 Capex（仓储更新 + 现有 AWS 容量维护）。

所有者盈余收益率 = $66B / $2,790B = 2.4%

对比无风险利率 4.3%，略低于 1.9 个百分点。这意味着：

1. AMZN 估值已 price in 5 年 EPS CAGR 22% 持续兑现——这与共识一致
2. 如果 AWS +28% 增速持续，2027-2028 所有者盈余收益率会回升到 3-4%
3. 这是"用今天的高价换未来 5 年高确定性增长"的经典权衡

7.2 DCF 三情景

关键假设：FY27 起 5 年 FCF CAGR 15-25%（基准 20%），永续增长率 2.5-4%（基准 3%），WACC = 8.5%（科技龙头）。FY27 起步 FCF 假设 $60B（恢复至 FY24 水平 + AI 红利初步兑现）。

悲观（20%）：5 年 FCF CAGR 15%，永续 2.5% → DCF 估值 $240/股（AWS 增速回落到 +20% + Capex 持续高位）

基准（55%）：5 年 FCF CAGR 20%，永续 3% → DCF 估值 $310/股（基准情景）

乐观（25%）：5 年 FCF CAGR 25%，永续 4% → DCF 估值 $400/股（AWS 持续 +28%+ + Trainium 占领 AI 训练 30%+ 份额）

概率加权 DCF：$240 × 20% + $310 × 55% + $400 × 25% = $319/股

7.3 所有者盈余收益率法

LTM 所有者盈余 = $66B
合理收益率（基准）= 4%（科技龙头 + AI 增长 + 优质护城河）
隐含合理市值 = $66B / 4% = $1,650B... 等等，这低于市值。

用前瞻收益率（5 年 EPS CAGR 22% 假设）：
FY2030 所有者盈余 = $66 × (1.22)^4 = ~$146B
隐含合理市值 = $146B × 22x = $3,212B → $303/股（+11%）
评估：用前瞻法更合理，因为亚马逊当前在 Capex 投入期，所有者盈余暂时被压缩。

夜读手记 · 1100 字

2022 年的亚马逊曾被市场宣判"AI 时代落伍者"——AWS 增速从 30% 跌到 12%，营业利润率被压到 2%。3 年后，Q1 2026 财报像一记响亮的反击：AWS +28%（15 季度最快）、营业利润率 13.1%（历史新高）、EPS 大超预期 68%。Andy Jassy 这句话是关键："we are still in the very early innings of AI"——这不是一份"恢复"的财报，是一份"重生"的财报。

Q1 2026 营收 $181.5B（+17%）、净利 $30.3B、EPS $2.78（vs 共识 $1.65 大超 68%）——每一项都超预期。但这场季报的真正主角是三个"加速"信号：AWS +28% 远超 +24% 共识、Trainium 芯片 +100% YoY 突破 $20B 运行率、营业利润率 13.1% 历史新高。三个数字讲的是同一个故事——亚马逊从"AI 时代受益者"完成最后一步重估为"AI 紧缺资产 + 高利润率平台"。

几个研判要点

一、AWS +28% 是真正的拐点。从 Q4 25 +19% 到 Q1 26 +28%，加速 9 个百分点。这是 15 季度最快增速。更重要的是 AWS 营业利润率 37.7%、季度营业利润 $14.16B（占集团 59%）——AWS 是真正的"利润引擎 + 现金机器"。Jassy 在电话会上明确："we are still in the very early innings of AI"——意味着 AWS 增速可能维持 +25-30% 至 FY27。这是与 GOOGL Cloud +63%、Azure +40% 的竞争中证明"AWS 仍是龙头"的最强证据。

二、Trainium 芯片是被严重低估的护城河。Q1 财报中最被低估的数字：Trainium 业务年化 $20B+ 运行率、+100% YoY 增长。这意味着 Trainium 已是仅次于 NVIDIA 的第二大 AI 训练芯片。Anthropic / Apple / 多个 LLM 公司都在用 Trainium。这种"自研芯片"在 AI 时代不仅降低成本（比 H100 低 40%），更重要的是建立了"应用 + 模型 + 芯片"全栈一体化——这是 GOOGL/MSFT 都没完全做到的。

三、营业利润率 13.1% 是新平台期，不是峰值。从 FY22 2.4% 跌底到 Q1 26 13.1%——4 年涨 5x 倍。零售业务运营杠杆（成本优化 + 库存管理 + 物流自动化）+ AWS 高毛利双轮驱动。海图判断这是新平台期 13-14%，不是峰值。如果 AWS 继续提份额、广告 +24% 持续、国际首次盈利持续——FY28 营业利润率有望达 16-18%。

四、$43.2B 单季 Capex 是必须的"军备竞赛"。Q1 Capex $43.2B 是史上最大单季投入，FY26 全年指引 $180-200B。FCF 已从 $30B 跌至 LTM $1.2B（-95%）——短期股价对"FCF 折价"敏感。但 Olsavsky 明确："FY27 Capex 增速会回落"——意味着 2027 是 FCF 拐点。如果你愿意忍受 1-2 年 FCF 平台，FY28 起 FCF 会爆发性增长（基础上 AWS +25% 持续 + Capex 持平 = FCF $80-100B 年化）。

五、估值合理但 PEG 略高。当前 $273 vs 加权公允 $316——14% 安全边际。Forward FY27 P/E 26x（vs 5 年中位 30x，略低于历史）+ PEG 1.24（"成长合理估值"略偏贵）。FCF Yield 0.04% 短期偏低（被 Capex 压缩）。如果回调到 $245-255（200 日均线附近），是绝佳建仓窗口。如果继续上涨突破 $290 高点，可耐心等待 Q2 财报（2026-07-31）后的回调。

风险提示

AI 泡沫破裂导致 AWS 增速骤降 / FTC 强制分拆 / Anthropic 完全独立 + 转向其他云 / Capex 持续高位压制 FCF / 美国宏观放缓拖累电商业务——任一项都可能让股价回调 15-25%。但真实净现金 $39B + 4 大引擎多元化 + Prime 2 亿会员 + AWS 30% 市场份额让破产概率为零。

关键叙事：从"AI 时代受益者"升级为"AI 时代基础设施"。Q1 2026 之后，AMZN 不再是"投资 AI 的电商公司"，而是"AI 全栈基础设施 + 现金机器"。在 GOOGL/MSFT 同样估值合理 + Trainium 芯片是独有差异化的当下，AMZN 是大型科技股中"成长 + 估值 + 多元化"组合最佳的之一。下一个催化剂：2026-07-31 Q2 财报。
