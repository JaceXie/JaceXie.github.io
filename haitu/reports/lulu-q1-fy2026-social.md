# Lululemon（NASDAQ: LULU）FY2026 Q1 · 海图夜读

价值投资里最考验人的时刻，是一只曾经的明星成长股跌落神坛——股价一年腰斩，业绩下滑，估值便宜到不像它。这时最难的判断是：这是"错杀的好公司"，还是"逐渐熄灭的品牌"？Lululemon Q1 FY2026 营收 +4% 的表象下，藏着利润 -38% 的崩塌、美国同店 -6% 的转负、和下调的全年指引。但同一份财报里，股价已从 $242 跌到 $116（-52%），Forward P/E 压到 10 倍——安全边际首次出现。

Lululemon 是全球高端瑜伽运动服龙头——54% 毛利率、30% ROE、816 家直营门店、净现金 $1.5B、零负债的品牌生意。Q1 FY2026 营收 $2.47B（+4% 报告 / +2% 恒定汇率）· 美洲 -3%（同店 -6%）· 中国 +30%（同店 +20%）· 毛利率 54.2%（-410bps）· 净利 $195M（-38%）· EPS $1.69（-35%）。公司下调全年指引至 EPS $11（从 $13.26）。

## 几个研判要点

**一、+4% 营收表象掩盖 -38% 利润崩塌，美国是病灶。** +4% 里 +2pp 是汇率，恒定汇率仅 +2%、全球同店 -2%（负）。**美洲（66% 营收）营收 -3%、同店 -6%**——核心市场首次转负，管理层指引 Q2 北美进一步恶化至"低双位数"下滑。新锐 Alo、Vuori 在蚕食美国高端份额，品牌热度见顶疑虑是最大红旗。这决定了 10x 估值是"便宜的好公司"还是"价值陷阱"。

**二、关税吞噬毛利，利润率暴跌 730bps。** 毛利率 -410bps 至 54.2%（关税 -330bps 为主犯），叠加 SG&A 去杠杆 +310bps（含代理权争夺费用），营业利润率暴跌 730bps 至 11.2%。关税是外部冲击，品牌减速是内部问题——两者叠加是本季利润崩塌的根源。

**三、中国 +30% 是唯一强引擎，也是最大对冲。** 中国大陆营收 +30%、同店 +20%，管理层维持全年 +20% 预期；其他地区 +13%。**国际化逻辑没有坏——坏的是美国**。中国 + 国际提供了穿越美国困境的缓冲，若美国仅企稳（不需复苏），公司整体就能重回增长。

**四、净现金 $1.5B + 低位回购是下限支撑。** 零有息负债、净现金占市值 11%、本季回购 $358M（均价 $163）、摊薄股数缩 4.4%、回购收益率 12%+。**管理层在股价腰斩的低位积极回购，是最好的逆向资本配置**。财务风险几乎为零，风险全在盈利与需求端。

**五、12 个月目标价 $135，上行 +16%。** 悲观 $95（30%，美国继续恶化）、基准 $135（45%，美国企稳 + 中国 +20% + 估值修复至 12x）、乐观 $175（25%，品牌回暖）。概率加权 $135。**当前 $115.92 已接近机械首仓 $108**——反向 DCF 显示市场已定价近零长期增长、无视中国引擎，若美国仅企稳当前价就偏低。

## 海图研判

**评级：有条件买入（维持）**（净现金 $1.5B + 54% 毛利率 + 30% ROE + 中国 +30% 引擎 + Forward P/E 10x 历史最低 + 低位回购的组合，对垒美国核心市场同店 -6% 结构性走弱 + 关税吞噬毛利 + 管理层动荡 + 品牌热度见顶疑虑）

12 个月概率加权目标价：**$135**（+16%）

- 乐观（25%）：$175 — 美国品牌回暖 + 新品成功 + 估值至 15x
- 基准（45%）：$135 — 美国企稳 + 中国 +20% + 估值修复至 12x
- 悲观（30%）：$95 — 美国继续恶化 + 关税加码 + 估值压至 8.5x

**操作建议**（独立估值中位数 $135，加权公允 $135）：

当前价 $115.92 已接近机械首仓 $108：

- 首仓 **$108**（估值中位数 × 80%，距现价 -7%，可分批建仓）
- 二仓 **$95**（× 70%，距现价 -18%，52 周低附近加仓）
- 三仓 **$81**（× 60%，距现价 -30%，黑天鹅级机会）

止盈三档：**$160 / $190 / $230**（每档减仓 25%，最后 25% 视美国拐点）

建议总仓位 **2-4%**（中低仓位 · 反映美国品牌拐点未验证 + 管理层动荡 · 分批建仓、等企稳信号加仓）。这是一笔"跌落成长股的逆向下注"——不重仓、分批建、等美国同店止跌的企稳信号再加仓；美国品牌若结构性见顶，10x 也可能是价值陷阱。**持有周期 2-4 年**，目标是"等美国企稳 + 中国复利 + 估值修复"。关键纪律：这是逆向下注，不重仓。

## 风险提示

1. **美国品牌结构性见顶（同店 -6%，新锐蚕食）** → 概率 25%，股价跌至 $85-95，变价值陷阱
2. **关税吞噬毛利（Q1 压 280bps，FY26 -90bps）** → 增量关税税率不确定
3. **管理层动荡（临时联席 CEO + 代理权争夺）** → 战略执行不确定
4. **美国消费/宏观放缓** → 高端可选服饰衰退敏感
5. **中国增长意外失速** → 失去唯一引擎
6. **回购超 FCF** → 靠动用净现金，可持续性依赖盈利恢复

但净现金 $1.5B（市值 11%）+ 54% 毛利率 + 零负债 + 持续回购构成质量底，**$95-104 是较硬的估值底**（52 周低 + 8.5x Forward P/E + 净现金）。

关键叙事：**"净现金 $1.5B + 54% 毛利率 + 30% ROE + 中国 +30% 引擎 + Forward P/E 10x 历史最低 + 12% 回购收益率"的品牌质量与估值安全边际，对垒"美国同店 -6% 结构性走弱 + 关税吞噬毛利 + 临时 CEO/代理权争夺 + 品牌热度见顶疑虑"的真实恶化**。Lululemon 不是给追求确定性的人——是给相信"美国能企稳、中国能复利、品牌未死"、愿意在腰斩后逆向分批建仓的耐心价值投资者。下次催化剂：2026-09 Q2 FY2026 财报，关注北美同店是否止跌。
