关键数据洞察 · 必须看穿 12x P/E 的"牛市峰值盈利"：

(1) FY2025 营收 +68%、净利 +100%、入金户 +40%、客户资产 +66%、交易量 +89%——这是全球互联网券商里最凌厉的增长之一；(2) 但 FY2025 是港股 / 美股交易的大牛市——交易量 +89% 是周期高点，券商佣金 + 利息收入对市场情绪高度敏感。12x P/E 是"12 倍峰值盈利"，若 2026 市场降温，这个倍数会被动抬高；(3) 商业模式正在从"靠佣金"转向"靠利息 + 客户资产"——FY2025 利息收入 HK$104 亿首次与佣金 HK$106 亿几乎持平，这部分（融资融券 + 闲置资金）更稳定、更黏；(4) 2026-04 首次派发特别股息 $2.6/ADS（~$365M）+ $500M 回购授权——从纯成长股迈向"成长 + 资本返还"；(5) 海图提醒：富途是一门高增长 + 高利润 + 便宜估值的好生意，但它带着中概监管 + Tencent 减持 + 券商周期性三重折价——便宜是有原因的。

看穿盈利的"周期性"：富途 Q4 2025 净利率 52.3% 是惊人的数字，但要清醒——FY2025 是港股 IPO 大年 + 美股牛市 + 港股通活跃的多重利好叠加，交易量 +89%。券商的佣金收入与市场情绪高度正相关：牛市时交易频繁、佣金暴增；熊市时交易萎缩、佣金骤降。所以富途的盈利能力要用"中周期正常化"来看，而不是用 FY2025 这个峰值年外推。利息收入（占 46%）相对稳定，是商业模式的"压舱石"。

富途的成长曲线是"用户复利 + 牛市放大"的双重叠加——入金客户从 2022 年的约 153 万增至 2025 年的 337 万（3 年 +120%），客户资产 +66%，这是结构性的复利增长（全球化获客）；而 FY2025 营收 +68% / 净利 +100% 中，有相当部分来自牛市交易量 +89% 的周期性放大。看富途要把"结构性用户增长"和"周期性交易放大"分开——前者是长期价值，后者会随市场波动。

模块 1 · 公司概览与背景

公司全称：富途控股有限公司 / Futu Holdings Limited
上市：NASDAQ: FUTU（2019-03-08 IPO，1 ADS = 8 类 A 普通股）
总部：香港 + 深圳
财年：1 月 1 日 - 12 月 31 日 · 财报本币 HKD
主营：互联网券商 + 财富管理平台——经纪交易（港股 / 美股 / A 股通 / 期权 / 期货）+ 融资融券 + 财富管理（基金 / 理财）+ 企业服务（ESOP / IPO 分销 / IR）。海外品牌 moomoo，港澳品牌 富途牛牛。

核心叙事：富途是中国互联网券商出海最成功的代表——由腾讯系出身的工程师李华（Leaf Hua Li）2012 年创立，腾讯持股约 33%。它把"互联网产品体验"带进了传统券商行业（社区 + 行情 + 一站式交易），在港澳建立优势后，从 2021 年起全力全球化：moomoo 进入美国、新加坡、澳大利亚、日本、马来西亚、加拿大。FY2025 入金客户 337 万、客户资产 HK$1.23 万亿、营收 +68%、净利 +100%——增长极其凌厉。但富途的故事有一道伤疤：2022 年底中国证监会认定其跨境券商业务违规，富途被迫下架内地 App、停止拓展内地新客——这逼迫它彻底转向香港 + 海外，而它把这场危机变成了全球化的契机。

简史与里程碑：

1. 2012 年深圳创立——李华（前腾讯第 18 号员工）创办，腾讯领投
2. 2014 年富途牛牛上线——港股互联网券商，社区 + 行情 + 交易一体
3. 2019-03-08 纳斯达克 IPO——发行价 $12
4. 2021 年 moomoo 全球化启动——进入美国、新加坡
5. 2022-12 中国证监会监管——认定跨境券商违规，下架内地 App、停拓内地新客
6. 2023-2024 全球化加速——日本、马来西亚、澳大利亚、加拿大相继落地
7. 2025 全年爆发——港股 IPO 大年 + 美股牛市，营收 +68% / 净利 +100%
8. 2026-04 首次特别股息 $2.6/ADS + $500M 回购——资本返还元年

股权结构（2025 末附近）：

李华（创始人 / 董事长 / CEO）——通过 B 类超级投票权股控制公司
腾讯（Tencent）——约 33% 经济权益，但近期持续减持套现
机构与公众——其余
注：富途采用双层股权结构，李华通过 B 类股保持控制权。腾讯既是早期投资人也是战略股东，但 2024-2026 多次减持——这是股价的一个持续性供给压力。

模块 2 · 管理层评估
B+

李华（Leaf Hua Li）· 创始人 / 董事长 / CEO

前腾讯第 18 号员工、技术背景，2012 年创办富途。产品力是富途最强的标签——把社区 + 行情 + 交易做成中文互联网券商体验天花板，moomoo 在海外也以产品体验取胜。李华通过双层股权牢牢控盘，长期主义底色浓。扣分项：2022 年的中国监管危机暴露了早期"打监管擦边球"的扩张方式；管理层在合规上交了学费。

B+

全球化执行团队 · 把危机变成转机

2022 年中国监管重击后，管理层迅速把战略重心转向香港 + 全球——3 年内 moomoo 在美国、新加坡、澳大利亚、日本、马来西亚、加拿大相继落地并贡献增量。这是一次教科书级的"危机转型"：被堵死内地市场后，反而逼出了一个更大、更分散、监管风险更低的全球客户基础。执行力 B+。

B+

资本配置 · 从纯成长到首次资本返还

过去 13 年富途几乎把所有利润再投入获客 + 全球化——不分红、不回购，符合高速成长期的逻辑。
2026-04 转折点：首次派发特别股息 $2.6/ADS（合计约 $365M）+ 启动 $500M ADS 回购授权——从"纯成长股"迈向"成长 + 资本返还"，标志公司进入更成熟的现金生成阶段（详见模块 12）。
整体看：资本配置从"全投入"到"开始返还"的转变是积极信号，但首次返还的可持续性仍需观察（FY25 是峰值年）。

长期主义测试：3 年前（2022 年监管危机）市场一度认为富途"故事终结"——内地市场被关闭、股价腰斩。3 年后富途用全球化把营收做到 HK$228 亿、净利 HK$113 亿、客户资产 HK$1.23 万亿，完全证明了"出海"战略的成功。管理层在危机中的韧性 + 转型执行力，是这家公司最被低估的资产。

利益绑定：李华通过 B 类股控制 + 持有大量经济权益，与公司深度绑定。但腾讯持续减持——虽然腾讯减持不改变富途经营，但反映出"早期战略股东在高位套现"，对其他股东是情绪和供给上的压力。

模块 3 · 商业模式深度解析

海图"一句话测试"：富途靠一个产品体验领先的互联网券商 App，把全球散户（尤其华人 + 亚太）吸引进来交易港美股，从三个口袋赚钱——交易佣金（46%）、利息（46%，借钱给客户做融资融券 + 客户闲置资金的利差）、财富管理（8%）——FY2025 营收 HK$228.5 亿，净利率 49.5%，是一门轻资产、高利润、但与市场周期强相关的平台生意。

商业模式的演化——这是关键洞察：(1) 利息收入崛起为"压舱石"——FY2025 利息收入 HK$104 亿首次与佣金 HK$106 亿几乎持平。利息（融资融券利差 + 客户闲置资金）比佣金更稳定、更黏，不完全依赖交易频率，随客户资产规模（HK$1.23 万亿）增长而增长；(2) 佣金是"周期性引擎"——牛市暴增、熊市萎缩；(3) 财富管理是"第三曲线"——把客户的"交易账户"升级成"理财账户"，提升 ARPU 和黏性。

单位经济：富途是极致的轻资产平台——获客成本（CAC）一次性投入，之后每个入金客户持续贡献佣金 + 利息 + 财富管理收入。客户资产越大、留存越久，LTV 越高。但券商的本质是"市场的杠杆"——牛市时富途比大盘更亢奋，熊市时比大盘更萧条。这是它估值长期被压在 10-20x P/E 的根本原因。

模块 4 · 经济护城河分析（5 维）
护城河来源评级评估
网络效应窄富途/moomoo 的投资社区（牛牛社区）有弱网络效应——用户多 → 内容多 → 更吸引用户。但不如社交平台强
转换成本窄转户有一定摩擦（资产转移 + 习惯 + 持仓），但散户切换券商门槛不高；客户资产越大、黏性越高
成本优势窄自研技术栈 + 互联网获客效率高于传统券商；但与 Tiger、IBKR、Robinhood 比无绝对成本优势
无形资产窄moomoo / 富途牛牛 品牌 + 多地券商牌照（港、美、新、澳、日等）——牌照是真实壁垒；产品口碑是软资产
有效规模窄互联网券商是充分竞争行业——Tiger、IBKR、Robinhood、传统券商、银行都在抢。无寡头保护

综合判断：窄护城河（5 维全窄）。富途的护城河不深——它的优势是"产品体验 + 多地牌照 + 投资社区"的组合，而非任何单一的宽护城河。这意味着富途必须靠持续的产品迭代 + 全球化获客来维持增长，而不是躺在垄断地位上收租。10 年后护城河会更宽还是更窄？取决于：(1) 客户资产能否持续做大（资产黏性 = 真护城河）；(2) 财富管理 / 资管能否从"交易工具"升级成"财富平台"（提升转换成本）；(3) 全球牌照网络能否扩张。这是一门好生意，但不是一门有宽护城河的生意——所以估值上不该给科技龙头的倍数。

③ 现金流与资本（券商无传统 Capex / FCF 概念）

富途是轻资产金融平台——几乎没有传统意义的资本开支（主要是技术 + 办公投入），所以"FCF = OCF - Capex"框架对它意义不大。对富途，真正的现金衡量是"净利润 ≈ 所有者盈余"——FY2025 GAAP 净利 HK$113 亿，几乎全部是可分配现金（这也是它能首次派息 + 回购的底气）。券商现金流的特殊性在于大量现金是客户隔离资金（HK$1,134 亿）+ 融资融券占用——这些不是公司可自由支配的钱。

关键比率：ROE ~28%（净利 HK$113 亿 / 权益 HK$403 亿）——高资本回报；净利率 49.5%（财务平台典型高利润）；毛利率 87.1%；自有现金充裕、借款主要服务融资融券业务（匹配资产端）。财务质量优秀——这是一份高利润、高 ROE、轻资产的资产负债表。

所有者盈余：净利润 HK$113 亿 + 少量非现金（SBC + 折旧）− 极小维护性投入 ≈ 所有者盈余约 HK$115 亿/年（约 $14.8 亿）。按市值 $17.4B 计，所有者盈余收益率 ~8.5%——对一个 +68% 增长的平台，这个收益率很有吸引力，但要打"周期性峰值"的折扣。

12.2 给的方式好不好？

富途首次资本返还的"含金量"需要拆开看：

① 注销 vs 库存股：$500M ADS 回购计划——美股回购通常注销或入库存股，富途作为开曼公司回购的 ADS 大概率注销。但回购刚启动，实际执行额尚小，含金量待执行验证。
② 摊薄股数趋势——硬指标：富途历史上股本相对稳定（SBC 适中），不是高稀释公司。$500M 回购（约占市值 2.9%）若执行，可实质减少股本。
③ 特别股息 vs 经常性股息：这次是"特别股息"——一次性，不是承诺的年度分红。这对追求稳定现金流的投资者要打折扣：它告诉你"公司现金多了"，但没告诉你"每年都会给"。

结论：富途的首次资本返还象征意义 > 实际金额——它标志一家成长公司开始有"还钱给股东"的意识和能力（积极信号）；但"特别股息 + 刚启动的回购"还谈不上高含金量、可持续的股东回报架构。

12.3 能不能继续给、给多少？

① 已授权未执行额度：$500M ADS 回购授权（约占市值 2.9%）——刚启动，剩余额度大。约束力中等（董事会授权，非强制）。富途首次回购，没有历史执行记录可参考，需观察实际节奏。
② 未来股息 + 回购指引：管理层未承诺将特别股息转为经常性分红。富途仍处高速成长期，资本返还优先级低于"全球化获客 + 业务再投资"——这是合理的，但意味着股东回报的可持续性不确定。
③ (股息 + 回购) / 净利润覆盖度：FY2025 净利 $1.45B，特别股息 $365M + 回购 $500M = $865M，占净利约 60%——完全覆盖得起（券商轻资产，净利接近自由现金）。即便牛市盈利回落，富途也付得起适度返还。
④ 不是借债回购：富途自有现金充裕，资本返还来自留存利润，不靠举债。

模块小结：象征性回报起步——首次特别股息 + 首次回购授权，标志从纯成长转向"成长 + 返还"。含金量待执行验证，可持续性取决于公司是否把特别股息常态化。对富途，股东回报是"加分项"而非"投资主逻辑"——买富途主要赌的还是用户增长 + 全球化，不是收息。

夜读手记 · 1150 字

财报里最便宜的数字，往往藏着最需要追问的前提。富途 FY2025 净利 +100%、营收 +68%、P/E 只有 12 倍——一眼望去像捡钱。但夜读财报的人会先问一句：这份盈利，有多少是公司赚的，有多少是牛市给的？答案是：FY2025 全年交易量 +89%，是一个不折不扣的峰值年。

富途是中国互联网券商出海最成功的代表——moomoo 在海外、富途牛牛在港澳，靠交易佣金（46%）、利息（46%）、财富管理（8%）三块赚钱。FY2025 入金客户 337 万（+40%）、客户资产 HK$1.23 万亿（+66%）。这是一门轻资产、49.5% 净利率、28% ROE 的好生意——但它带着三重折价。

几个研判要点

一、12x P/E 是"12 倍峰值盈利"。FY2025 是港股 IPO 大年 + 美股牛市 + 港股通活跃的多重叠加，交易量 +89%。券商佣金与市场情绪强相关——牛市暴增、熊市骤降。用中周期正常化盈利看，富途的真实 P/E 在 16-18x——仍不贵（对 +25%+ 结构性增长），但远没有"12x 白菜价"那么诱人。看富途，必须把"结构性用户增长"和"周期性交易放大"分开。

二、商业模式正在从"靠佣金"转向"靠利息 + 客户资产"。FY2025 利息收入 HK$104 亿首次与佣金 HK$106 亿几乎持平。利息（融资融券 + 闲置资金利差）比佣金稳定得多，随客户资产规模增长而增长——这是富途盈利质量提升的关键，让它没那么"靠天吃饭"。

三、2022 年的伤疤，变成了全球化的契机。2022 年底中国证监会禁止富途拓展内地新客，市场一度认为故事终结。3 年后，富途用 moomoo 在美、新、日、马、澳、加的扩张，把营收做到 HK$228 亿。被堵死内地后，反而逼出了一个更大、更分散、监管风险更低的全球客户基础——这是管理层最被低估的执行力。

四、首次资本返还是"零的突破"，但别当主逻辑。2026-04 富途首次派特别股息 $2.6/ADS（约 $365M）+ 启动 $500M 回购。这标志一家成长公司开始有"还钱给股东"的意识。但特别股息是一次性的、回购刚启动——含金量待验证。买富途，赌的还是用户增长 + 全球化，不是收息。

五、12 个月目标价 $160，上行 +28%。悲观 $100（-20%，熊市 + 监管）、基准 $160（+28%，增速放缓 + 正常化估值）、乐观 $210（+69%，市场活跃 + 估值重估）。概率加权 $160。当前 $124.50 已低于机械首仓 $128——进入合理建仓窗口。但这是一只高 Beta 的券商股，建议小仓位起步、回调加仓。

风险提示

港美股大幅熊市（交易量腰斩、佣金大跌）/ 中概监管或美国金融限制升级 / Tencent 大额减持 / 融资融券风控事件 / ADR 退市尾部风险——任一项都可能让股价回调 20-30%。但净利率 49.5% + 即便熊市仍盈利（利息压舱）+ 每股净资产 ~$37 提供下行支撑，$90-100 是较硬的估值底。
