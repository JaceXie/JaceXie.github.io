### 本轮修掉的自身缺陷（都是实测发现，非推断）
1. qc.mjs 把 `<style>` 里的 `[data-rating="买入"]` 选择器当成正文评级 → 每份合规报告都会误判不一致。
2. qc.mjs 按非空白字符数判社媒长度，中英混排虚高约 1.7 倍 → 改为只数中日韩汉字。
3. 抽取语料 CSS 时**丢掉了 @media 包裹**，把 nvda 的移动端规则变成无条件规则排在最后 →
   桌面端所有网格塌成单列。已删除并在注释里写明成因。
4. grid 轨道写 `1fr` 而非 `minmax(0,1fr)`，canvas 固有宽度把轨道撑到 568px → 375px 下整页横向滚动。
5. report-charts.js 只判 `d.type==='line'`，图表级 line 类型的数据集拿到 borderWidth:0 → 只有点没有线。
6. 骨架/正文用到 37 个组件类（.stock-snap/.moat-card/.risk-card/.score-card/.ec-* 等）
   在样式表里不存在 —— 因为 CSS 抽自旧 JD 模板、骨架用的是新世代类名。已补齐并加同步警告。
